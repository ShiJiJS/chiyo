# S3 — 信息库与资料阅读

## S3-L01：固定职责的三栏

左栏放目录范围、常用标签快捷入口及回收站；中栏保留结果列表、关键词、类型/标签小菜单、分组/排序和新建；右栏展示选中资料。模板插件只在设置，不常驻左下角。各栏独立滚动，固定操作与滚动正文分开，滚动条在点击区右侧保留轨道。

统一列表以种类明确的引用包含信息及凭据，不在数据库里合并安全模型。凭据默认遮蔽，仅专用 Owner 控件提供查看/更换；列表和搜索不加载秘密或文件正文。文件资料仍能放同一目录，用途/格式/版本比“受保护原件”更有帮助。

## S3-L02：简单查询与稳定选择

目录＋关键词＋一个类型＋一个标签取交集；信息可标多个标签，但筛选UI不做多条件构造器。关键词按空白拆分且全部匹配名称、说明、类型显示名和标签；不搜索字段正文、密钥、附件内容或内部备注。类型/标签菜单选择立即生效，支持清空。标签不分私人/公开，Agent也能默认发现标签并用于查找。

分组只有不分组、按类型、按目录；排序只有最近更新、名称。分组不写回分类。排序有稳定 ID 作为平局规则，分页在全局排序/分组之后进行，不按当前一页伪造总组数；目录数量含后代，列表显示实际命中数量。

切目录保留显式关键词/类型/标签；“全部资料”清目录并清筛选；“清除筛选”清关键词/类型/标签但保留目录。查询变化回第一页，旧选中项仍在结果中则保留，否则选择首项或显示空态。异步旧查询结果不得覆盖新结果。

点击结果不清条件；关联跳转若目标不在结果中，仅清除阻挡它的条件并显示当前位置变化，提供返回原查询与滚动位置。目标仍在范围时保持条件。后台刷新不抢焦点、不重置整个页面动画。被删目录/标签失效时移除对应条件并提示，不保留不匹配的旧详情。

## S3-L03：资料详情类型

| 类型 | 默认阅读 | 必须可完成的操作 |
| --- | --- | --- |
| 通用信息/旧资料 | 名称、用途、字段章节 | 编辑、归属调整、修订、回收、相关授权 |
| 服务器 | 连接事实、说明、主机身份、服务/文档/凭据关联 | 修改事实、核对主机、跳转关联与申请使用 |
| 应用/服务 | 入口、用途、运行位置、文档和凭据 | 创建/修改、关联服务器、返回原结果 |
| 个人档案 | 基本信息、教育/工作等重复章节 | 添加/排序/修改条目、按叶字段审批 |
| 文档 | 可阅读正文、关联及版本 | 编辑、修订对比、申请指定字段 |
| 普通文件 | 文件名、格式、大小、用途、版本及支持的预览 | 导入、替换、另存、版本恢复、受管领取 |
| 托管凭据 | 用途、形式、适用目标、关联、使用记录 | 新建/更换/撤销、发起使用流程；不普通读取 |

文档首版支持纯文本及安全 Markdown（不执行 HTML/脚本或自动请求远程图片）；PDF提供只读预览，其他格式明确显示类型卡及用本机程序打开。预览失败保留元数据和打开入口，不用伪造的简历纸面代替真实文件。预览资源沿用受管临时副本及清理机制，不另落永久明文缓存；该界面只向 Owner 展示，Agent仍需独立附件授权。

“仅有文件的信息”可以使用宿主内置文件模板，但本质仍是一项普通信息的文件字段；混合文字/文件的信息不能被文件列表丢弃其他字段。文件名、格式与用途说明可能是公开元数据，录入时须明确审阅；不自动提取敏感正文写进说明。

## S3-L04：分类与兼容流程

目录树内新建/子目录/更名/移动/空目录删除，继续复用 #54 的防环、重名和失败保稿语义。目录名不是斜线分隔路径。标签独立管理并显示影响数量；删除只移除标记。详情、新建及编辑共用同一个归属选择流程。

完整保留“查看修订 → 对比 → 恢复”、回收 → 恢复/永久清理、附件交付记录等入口。原型未展开的长流程先按 S5 的补充画面规则明确，再实现，不删成一个无行为按钮。
