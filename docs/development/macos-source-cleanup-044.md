## 软件修改

App 动态模板现在包含独立部署的命名、入口与主机关联例子，以及 Mac／Windows
设备配置如何单独保存并关联应用的例子。文件模板说明何时保留独立原件，凭据
模板明确只有已知采用密码登录才安排补填，并统一使用“用户”和具体凭据名称。
例子由当前 App 模板返回，Skill 和 CLI 没有另一份固定清单。

实际操作发现“存为独立资料”只查询插件包，遗漏内置文件模板，导致正常安装中
显示没有可用模板。现改为与 CLI 共用当前 App 的模板目录；保留启用状态和类型
检查。原测试人为提供了文件插件，掩盖了缺口，已改为真实内置目录的界面回归。

实际操作还发现“编辑信息”将凭据交给普通资料编辑器，保存被拒绝。现按记录类型
打开已有的凭据编辑器；只改说明时保留材料版本、身份和使用代际。删除额外字段的
修改摘要优先采用修改前的字段名称，不再泄漏内部键。
