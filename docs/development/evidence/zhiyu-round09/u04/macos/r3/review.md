# U04 r3旧资料采用：自行检查

用户任务是把现有内容用合适模板组织好，并核对哪些继续对应、哪些单独保留。沿用冻结R07/R08、信息库对象菜单和共享弹窗/控件。旧入口无采用流程；现在从同一资料选择目标、逐字段映射、预览到同一记录读回。没有按名称猜含义；“自动采用”缺少依据，选择先预览再明确确认。映射/新值保留，失败不重做输入；未知先查原计划回执。

实际Widget检查从菜单、目标模板、来源选择/同义决定、预览、明确采用到结果阅读与保留字段编辑；同时检查附件形态错误/调整、版本冲突、失败保存、未知结果/失败查询/正负回执、关闭/取消晚到读取。已有Mac预览隔离守卫增加真实控件采用/原实例身份保持/重置，仍断言零网络、生产通道和个人路径。源契约检查普通字段/经历身份、同名原值、未知复合值、附件原版本/替换/布局恢复、预算、重复映射、模板变化和凭据边界。

逐一查看5张实际Flutter Widget图：1440明亮映射/采用预览/结果/未知，1280黑暗200%附件形态冲突。初看发现步骤切换沿用滚动位置，已将步骤容器按步骤身份重置；映射仍保留。错误改为固定标题区，保留内容提前展示，空目标值压缩成行内说明。删除重复字段标签和重复“未填写”段落；200%主体可以滚动，底部确认/返回可达，没有靠缩小字或隐藏错误换取通过。保留共享120/150/180ms控件、切换和弹窗反馈，没有新风格或设计规范。
