# U04 r5整票收尾：自行检查

用户任务是把资料采用新模板后继续正确阅读/编辑原关系，并在编辑冲突时看清当前内容与草稿，再决定如何继续。沿用冻结R07/R08和现有信息库对象菜单、正式Flutter控件；同类已有版本比较和凭据核对流程提供阅读/确认习惯，本轮复用其分隔、字号、弹窗和返回保护，没有新风格或设计规范。

采用后的概览原先直接用目标章节标题，可能把原文档关系叫作指向服务器，且漏掉目标布局未列出的原关联。现在按实例保留含义显示同key关系，补出其他原关联；来源、候选、关系页和共用编辑器不产生另一套边。新检查走真实详情/编辑保存，断言原边及目标定义保持。

原表单冲突保存被禁用但无就地核对入口。现在从当前表单读取版本/元数据/关联摘要，比较将保存的可编辑草稿；返回/失败不丢输入。结构/字段及经历叶身份一致才可明确保留草稿推进核对基线；变更后的当前版本仍需再次保存、再次核对expectedVersion，不把比较当提交。结构/身份/分类变化时，旧值不能塞进新含义；只有明确清空载入才重建表单。没有自动合并正文或静默最后写入胜出。同名关联目标必要时显示资料标识，以免两个不同目标因显示名相同漏报差异。

初测发现下层“正在读取”忙态在比较弹窗已经打开后仍动画，导致界面不能稳定，已分开读取/比较锁定并停止多余忙态动画。初看200%比较页发现重复解释与空名称留白，已压缩说明并呈现未填写；经历内容改用名称/时间/说明，不展开内部fieldId。共享120/150/180ms控件、弹窗与内容反馈保留，没有新增动画规范或正常速度视频。

查看4张实际Widget图：1440明亮100%的编辑比较、经历身份变化比较、补出的保留关联，1280黑暗200%的新建结构变化核对。长内容可滚动，当前/草稿、返回、清空载入及明确继续可达；不会缩小字掩盖空间问题。保留关联图是滚动到补充关系处的截面，原同key关系名称由实际Widget断言及相同详情组件覆盖，不声称单图包含整张长页。

新增1项同名关联比较检查和5项Widget检查；既有Mac隔离守卫补冲突比较/再次保存及原身份保持。最终定向17、相关220、带截图定向17连续通过，严格分析和固定路径Mac预览构建通过。原生入口三文件摘要与已验版本一致；只有桥接桩/守卫、Widget渲染和编译，没有新Cocoa运行、OS输入/输入法/触控板/辅助功能、完整S5、视频或独立评审（用户禁止子Agent）。

完整接口交接覆盖包、主机、采用、旧模板和指引的读取/操作/失败/未知事实与释放，真实Owner事务、fieldId/固定授权失效、完整备份、重启和持久租约由全部七项UI后F01接入。本轮不读个人库/Keychain/hooks，不运行SSH/通知/系统选择器或Windows CI。#65仅收口可自动状态、隔离和接口交接到6/7，完整S5仍OPEN，继续U05–U07。
