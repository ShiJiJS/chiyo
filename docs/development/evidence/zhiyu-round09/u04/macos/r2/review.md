# U04 r2主机身份自行检查

沿用冻结R07/R08和现有设置工作区，不重新探索风格。用户从服务器详情直接核对同一端点身份，或在服务器插件设置集中维护。原来详情入口只切设置页，未选包/主机；现在一次点击指定对象，查看结果后保留信息库查询/选择。未采用自动信任方案，用户提供的连接资料不能证明新指纹真实性。

已逐一查看5张实际Flutter Widget PNG：1440明亮设置、已确认、未知；1280黑暗200%变化及停用撤销。沿用线性分隔、120/150/180ms共享按钮/切换/弹窗反馈，没有新增卡片系统或颜色字体。1280大字下主体内容滚动，底部动作Wrap换行，按钮可达；未通过缩小字体掩盖内容。图中均为集中合成资料和真实控件渲染。未新增正常速度视频、Cocoa运行、真实OS键盘/输入法或完整S5，不能由截图推断这些通过。

代码自查覆盖：宿主注册能力、外部包不能占用面板；DNS/IP规范化与端口；同端点跨资料一致；旧端点保留维护；观察/确认/撤销与资料版本分开；确认不授予凭据能力；未知原意图/回执校验；关闭和晚到读取。相关回归发现服务器回收时主机读取在Widget下一帧前失败，会产生未处理异步错误。将主机投影读取立即封装为结果，读取失败与空结果仍分开，并复跑既有回收/恢复/永久清理检查。

新增页面文案保留核对依据、状态及凭据许可区别；未额外添加装饰性文字，初稿未另删文案。新主机流程没有独立评审（用户禁止子Agent），不提供独立评分。没有真实known_hosts导入成功提示，也没有把Demo指纹当真实密钥。

详细输入、错误/回执和F01现有全局known_hosts快照映射见docs/development/zhiyu-macos-plugins.md。手工集中验收仍保留开放，接着实现旧资料采用模板，不把人工门槛变成开发停点。
