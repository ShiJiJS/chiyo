# U04 r4旧版兼容：自行检查

逐一查看5张实际Flutter Widget图：1440明亮100%的旧版目录、转换预览、Agent制作指引，1280黑暗200%的附件转换限制与共享录入表单。长内容保留滚动，错误与操作可达；大字截图是已滚动到附件/限制位置的截面，不代表完整表单只有该段。选择普通附件后用文件名呈现，不把附件JSON当正文。制作指引可选取内容，展示目录快照版本与重读提醒、实际校验入口和合法虚构样例。没有新增风格系统；共享120/150/180ms反馈沿用，未新增正常速度视频或实际系统输入证明。

10项新增来源/控制器检查覆盖定义与实例身份、不可变旧快照、文件必选/失败原子性、异步校验中的版本变化/重置与同次操作重复送达、真实声明解码/来源映射、旧200字段与转换40字段/附件边界、未知转换回执和晚到/销毁读取。新增5项Widget检查从真实共享控件录入、转换、冲突重选、未知核对、制作指引以及等待/错误/空结果。原Mac隔离守卫扩展实际旧版录入/转换/指引/重置，断言零生产通道/网络和零个人路径。
