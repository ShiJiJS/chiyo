`metrics/`包含16次代表标题基线及六种设置上下文。HTML在同Mac字体下用零尺寸行内基线探针读取，Flutter用RenderParagraph的公开dry-baseline API；代表标题最大差约0.575px，设置约0.29px。这里不把栅格抗锯齿和实际OS输入当作已测量内容。原型15个冻结文件和三份本机字体hash重新核验，布局/颜色CSS未修改。

## 可复现入口

在`apps/desktop`通过项目固定SDK执行相关`flutter test --no-pub`，传`--dart-define=UI_EVIDENCE_DIR=<项目内新目录>`以加载实际Mac字体和保存图。代表基线位于`zhiyu_settings_handoff_test.dart`；不传证据目录时这四个依赖Mac字体的用例会跳过。原生连续入口为`integration_test/zhiyu_candidate_native_test.dart`，必须使用Preview.xcconfig和ARM64环境，结束后恢复`lib/preview_main.dart`。

共享Profile复现：仓库根执行`./scripts/dev-macos.sh preview-profile-check <build/zhiyu-ui内新目录> --runs 1`。固定App身份、沙盒、arm64、普通入口和唯一App数量见`app.json`。不能用当前目录覆盖证据，也不能把Profile产物另存为第二个App。

准确剩余只有有限清单的D01、D02、M01-S1和H01–H03；保留原票勾选、依赖和OPEN状态。D01/D02并未获准作为视觉例外，未伪造HTML更新可用状态或把合成结果接入生产。
