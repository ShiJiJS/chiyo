# #102：联网运行页面与当前 App 文件维护

2026-11-09。原运行页面已接入联网正式数据源；本阶段不表示统一候选、完整试用或 #102 已完成。

## 实现和范围

- `RemoteWorkspaceSource` 改为直接实现 `WorkspaceSource`，正式接口均显式实现，不能再静默继承 unavailable 端口。正常启动器提供实际 `OnlineDesktopRuntime`；无桌面宿主的测试源才明确没有原生运行能力。
- 继续使用原 `WorkspaceRuntimeController/Page`。服务器状态与此 App 的窗口、退出、临时文件分别展示；退出只退出 App，不声称停止服务器或结束 CLI 聊天。
- 用户认证的 `GET /v1/owner/runtime` 复用 `OwnerRuntimeMaterials` 和 `OwnerAgentSessions`，仅返回设备上报的执行、文件交付和会话统计。Agent 接入凭证不能读取该用户接口。恢复备份不使历史材料或旧许可重新活跃。
- 凭据区是使用凭据文件的任务报告，不声称 App 检查了执行电脑的 PID、路径或材料。刷新报告不执行命令、不清理 CLI 文件，也不停止其他设备的任务。
- 此 App 的临时打开副本及另存操作待清理的 staging 来自原文件协调器；维护只操作这些已登记对象，保留使用中的副本，不回收用户另存的输出文件。恢复与定期检查沿用原清理流程，编辑或模态操作期间不自动维护。
- 本机运行操作先保存准确意图，再调用原生窗口或文件协调器。记录位于服务器身份隔离的私有目录，使用进程队列、文件锁和原子写入；原结果不确定时不能重复执行。结果发布失败后可核对原回执；重开时保留旧原生操作的未知结果，不把新窗口当作旧退出成功的证明，也不阻止用户对新窗口明确发起新操作。
- 退出前排空观察，关闭后只提供明确标注的退出前快照；原生退出失败可重新显示重试页面，不重新关闭已经关闭的资源。
