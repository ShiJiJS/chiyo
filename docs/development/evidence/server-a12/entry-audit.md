## 当前必须补齐的入口

`RemoteWorkspaceSource` 仍继承 `UnavailableWorkspaceSource`。对照原 `WorkspaceSource` 和正常页面，发现以下是初查发现的缺项及后续处理状态，不能将它们临时移到后三张票。

| 原有功能 | 当前证据 | 需要完成的结果 |
|---|---|---|
| 设置 | 未覆盖 `settings`，原设置页及主题读取调用 unavailable | 沿用原设置控件。本机保存外观、通知和后台选择；服务器统一保存请求期限、历史保留策略及清理回执。清理保留准确范围复核，失去回复先查原操作；不得把本机偏好写成所有设备的偏好。 |
| 应用运行、窗口和退出 | 未覆盖 `runtime`；`OnlineDesktopLauncher` 未向 `WorkspaceApp.desktop` 接原生运行适配 | 当前设备的窗口、导航、通知与退出可用；退出 App 不停止独立服务、不结束仍在 CLI 工作的聊天。不把服务端或别台设备的 PID、材料路径当成本机可检查的对象。保留真实未知状态及原操作核对。 |
| Agent 接入状态 | 未覆盖 `agents`；现有设备登记对话框已连接服务，但状态页面不可用 | 查询原服务器的会话及申请统计，并核对当前设备配套文件；不因包内 Skill 模板存在就假称用户宿主已安装或信任 hooks。不搜索私有聊天记录，不给 CLI 用户管理 Token。 |
| 已有资料切换模板 | 初查未覆盖；现已接通原共享转换规则、Owner HTTPS、远程方法及正常 UI，见 [阶段证据](adoption.md)。 | 使用原模板转换计划、字段/附件保留和确认规则；在联网资料与实际插件上预览、一次保存并核对准确原操作。不能藏掉按钮或随意丢字段来结束首轮。旧自定义模板转插件的 `legacyTemplates` 是另一入口，已经接通，不能将二者混同。 |

实现时继续使用已存在的控制器、展示和领域规则，不创建新的演示入口。全部连接之后，应让正式远程实现无法静默从 unavailable 基类继承遗漏功能；保留明确失败的旧测试基类不作为正式数据源。
