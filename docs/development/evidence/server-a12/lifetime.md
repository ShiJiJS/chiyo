# #102：联网 App 窗口、通知与退出

2026-11-09。当前完成正常启动器的设备生命周期接入；设置里的运行统计/维护页面仍未完成，#102 保持打开。本轮仍是隔离合成验收，没有正式安装或真实迁移。

## 当前实现

`OnlineDesktopLauncher` 为整个 App 创建一个 `OnlineDesktopRuntime`，连接变化只切换其远程数据源，继续使用已有 `DesktopPlatform` / `NativeDesktopPlatform` 和 `WorkspaceDesktop` 导航契约。没有创建本机资料服务、数据库或执行程序来冒充服务器。正式主入口使用这个启动器。

- 关闭窗口按本机已保存的后台选项处理；有菜单入口才收起窗口，菜单不可达时保留可见窗口。后台关闭时完全退出。窗口、菜单及通知打开使用原页面导航，通知只传不带资料内容的申请编号；打开不会批准申请。
- 编辑器/对话框或未完成写入锁定导航期间，系统导航不会穿过锁定。窗口激活还没完成就发生锁定、换连接或新的导航，旧动作不能稍后突然切页。原通知编号只用于选择申请，不是授权证明。
- 从正常远程待办查询发现新申请，只发送原来的通用系统通知。连接时已有待办不重复提醒；恢复、重连和重复查询也不重发同一轮已观察通知。通知关闭、不可用或发送失败不丢申请，失败与系统可用性分开记录。
- 启动、轮询、重连、睡眠恢复及回执核对不请求通知权限。沿用原设置行为：用户把通知从关闭改成开启并保存后，系统权限尚未决定时才调用原权限入口；系统决定不回滚已保存偏好，也不把回执重查变成第二次提示。
- 退出先等待当前 App 观察结束，卸载依赖数据源的页面，再关闭本机协调器与 HTTP 连接，最后调用系统退出。不会停止独立服务器、结束 Agent 聊天、撤销其许可、停止 CLI 执行程序或处理别台设备的 PID/文件。
- 资源关闭或系统退出失败时保留本次阶段事实及重试入口。系统退出重试不再次关闭已经成功关闭的资源。远程数据源的关闭失败可明确重试，各协调器独立收尾，不能因一个失败而跳过关闭其余句柄/客户端；未完成清理登记仍由原协调器恢复。
- 数据源关闭前取消并排空本 App 的观察，不在连接关闭后继续启动下一页查询。系统通知发送与健康探测分开，通知慢不能阻塞断线界面。没有把超时当成成功、原请求不存在或启动另一个执行程序的理由。

## 已验证的范围

实际使用 TLS、SQLCipher、正常远程用户/Agent 接口及原 Flutter 页面；系统窗口/通知/退出边界使用自动测试平台夹具，**不是实际 Cocoa 点击、真实系统通知或密码授权验收**。

- 相关 App 组 **23 项通过**：当时的生命周期7、联网设置10、接入3、备份界面1、文件界面1、原连接/编辑界面1；日志 `local/server-first-stage/a12-online-lifetime-regression-final.log`。
- 随后解耦慢通知与健康探测，增加真实 TLS 代理故障场景，最新生命周期8与原连接/编辑界面1共 **9 项通过**，`a12-online-lifetime-health-final.log`。这些与上述23项重叠，不累加为32个独立场景。
- 最新相关静态分析无问题，`a12-online-lifetime-analyze-health.log`；diff检查通过。

正常 `OnlineDesktopLauncher` 场景实际完成：连接已有配置、收起窗口、新申请经原轮询提醒、打开通知到原审批页面、确认请求仍待审批、系统退出、原 Agent 继续用原许可读取实际合成字段、重开同一配置并拉回两条资料及待办。不是只检查某个“服务器未关闭”布尔值。

其他场景包括：没有系统权限提示的启动/恢复、提醒去重、关闭通知、不相关设置及回执不重弹权限、菜单不可达时不能隐藏、延迟导航越过模态锁被拒、原资源关闭失败后的明确重试、系统退出失败时只重试退出。

慢通知场景让测试平台的通知回调保持未完成，同时 TLS 代理使 `/v1/server` 失败；正常启动器仍显示断线界面，证明健康探测没有等待通知完成。没有关闭 TLS 校验或把服务失败替换为内存数据。

早期静态检查发现覆盖接口的推断类型不够具体；测试中误用了旧方法名、漏了辅助参数声明，均已修正。初次界面回归还发现关闭期间观察未排空，导致遗留请求计时器；修复真实释放次序后回归通过，没有通过跳过计时器检查、固定睡眠或禁用轮询来通过。失败日志保留，未算通过。原备份界面测试的双独立数据库调试提示仍保留，未屏蔽。
