## 已实现的服务器部分

`OwnerPolicyRoutes` 通过受认证的用户入口读取和保存请求期限、历史保留天数；本机外观、通知和后台选项不在此传输中。保存仍用原 `OwnerAccess.saveDesktopPreferences`，保留服务器里原有的设备字段，不拿某台设备的外观覆盖它们。正常 `bin/server.dart` 已注入原 SQLCipher 私有状态仓库，服务观察标记包含设置版本，以便客户端重读。

| 用户接口 | 行为 |
|---|---|
| GET `/v1/owner/settings` | 只返回资料库设置标记、版本、请求期限和保留天数。标记由私有代次派生，不返回私有状态或私有代次本身。 |
| POST `.../changes` | 携带稳定操作编号/摘要、预期版本与资料库标记，保存共享策略。缩短保留时间须提交原清理预览。 |
| GET `.../operations/<marker>/<operationId>` | 返回原持久回执；确实不存在时先持久记录未提交，再回复不存在，阻止迟到的旧命令。连接或查询失败不能当作未提交。 |
| POST `.../retention-preview` | 沿用原历史清理计划及准确范围核对；最多 16 份预览，固定 30 分钟清理。重开、换库后不能继续使用旧预览。 |
| GET `.../notification-preview` | 只读正常待办元数据，不产生申请、不发 OS 通知，也不授予 AI 访问。 |

受限 Agent 设备凭证不能访问这些用户管理接口。传输拒绝额外本机设置、Token、密钥、错误摘要、错误版本或负数统计。资料库恢复后标记改变，即使数字版本恰好相同，旧命令也不能写入新库。

确认未提交的记录存于原加密服务器私有状态 `ownerPolicyAbsences`，不进入便携备份，也不改变资料表或申请/授权规则。仍使用原版本和存储事务保存策略、清理范围及回执；不是在 HTTP 层重写清理。

补齐一处旧库兼容：过去通过有效旧接口保存的期限可能不在当前预设中，例如 47 分钟。修改其他设置时可原样保留它，已保存的准确旧回执也可核对；不能将另一个非预设数值当作新的选择。原来的有效范围和新选择的预设限制均保留，不自动改成最近预设。

## 尚未实现的 App 适配

`RemoteWorkspaceSource.settings` 仍继承 unavailable。下一步需要本机偏好及原操作记录、正常设置控制器/页面的远程适配，以及重开后继续核对原操作。不能仅返回固定默认值，也不能用另一个本机资料库替代设备设置。
