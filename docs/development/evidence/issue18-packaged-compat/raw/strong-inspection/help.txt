usage: test-windows-packaged-compat.py [-h] --delivery DELIVERY --dart DART
                                       --evidence EVIDENCE
                                       [--formats FORMATS [FORMATS ...]]

Operator-assisted native restore of explicit format fixtures into empty
profiles. Formats1-4 are compatibility fixtures derived from the current
authenticated snapshot using the same projections as the repository tests.
They are NOT backups produced by genuine old releases. Format8 contains two
ordinary file versions and an empty file template, with no file delivery
facts. All data is synthetic. Requires port47125 free. In each printed phase,
select the indicated backup and recovery file in the actual app's native Open
dialogs, verify its format/counts, confirm restore into the empty test
library, and only then write the observation receipt with {"observed": true}.
Never read/print/attach recovery keys. The receipt records a real operator
observation, not automatic image recognition. This exits only its own child
through the packaged CLI and explicit PID. A failed run preserves its private
synthetic root for diagnosis; there is no force-kill.

options:
  -h, --help            show this help message and exit
  --delivery DELIVERY
  --dart DART
  --evidence EVIDENCE
  --formats FORMATS [FORMATS ...]
