## 原生输入诊断

正常 Release 主入口（隔离现有 Windows APPDATA）连接现有 NAS，实际显示 62 项；没有修改或保存原资料，按原控制协议正常退出。点击可聚焦搜索，普通 a 键可写入并触发筛选，Backspace 可清除；IME 拼音候选出现，但 Sky 文字/组合键不能确认。

为定位加入 tool/windows_text_input_probe.dart：仅合成 TextField、Ctrl K 回调计数和 HardwareKeyboard 事件，不加载配置、不连接 NAS。实际 Debug 原生窗口构建通过，Sky 在聚焦后发送 Control_L+k：事件观察到 Control Left ctrl=true，随后 Alt Left/修正使状态释放，Key K 到达时 ctrl=false，回调 0 次。type_text('中文 Windows') 同样观察到 Key V 到达时 ctrl=false，正文未写入。这直接解释自动组合键/粘贴未成立；尚不能据此认定真实物理键盘也失败。

最小诊断窗口按正常 WM_CLOSE 退出，没有强杀。不能把此定位结果、widget 快捷键通过或输入法候选出现，冒认为实际 Ctrl K、中文保存/取消已通过；本项仍待可靠原生输入或用户物理键盘核对。诊断重建命令：在 apps/desktop 下运行 flutter build windows --debug --no-pub --target tool/windows_text_input_probe.dart；不要将该目标的 Debug EXE作为正式 App。
