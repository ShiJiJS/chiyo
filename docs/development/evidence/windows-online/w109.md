## 实现及真实 NAS 验证

沿用正常 `OnlineDesktopLauncher → WorkspaceApp → RemoteWorkspaceSource → OwnerClient` 和现有 NAS。Widget 检查只替换原生窗口/托盘边界，不替换资料服务器、TLS、远程适配器、表单或 SQLCipher 设备存储。默认测试不自动连接私人 NAS；必须显式提供本机私有配置目录。

- 现有普通资料、凭据、目录、标签和模板可读；使用新 Windows 配置，不导入旧 Windows 库。
- 仅创建并编辑《Windows 知予接入说明》，保留原来的 57 项；之后共 58 项（43 条普通资料、15 项凭据）。可搜索、读取中文正文、选择维护说明目录、NAS 标签以及现有飞牛 NAS 关联。重开同一加密配置后版本、正文和分类关联保持。
- 在真实服务器已确认保存后，测试截断该回复；表单冻结，点击核对结果只查原操作编号，保存 POST 总数仍为一次。原回执路径补上只读缓存同步，之后正常关闭表单并读取新版本。
- 连接页分别拒绝错误 Token、其他 CA、错误服务器身份及不可达端点。错误输入不保存配置，改回原地址后正常加载。
- 在已连接的同一 App 中注入本机网络故障，正常健康检查显示断线屏障；恢复网络后屏障解除，资料版本和原配置保持。扩充后的连接检查单独 33 秒通过，退出 0；没有真实关闭 NAS 或改动网络设置。
- 不将资料响应、Token 或聊天证明写入测试日志。新增文档仅含使用说明，不含秘密。

原快捷键在 Windows 仍使用 Cmd K；现按平台使用 Ctrl K/Cmd K，阅读模式切换后恢复工作区焦点。相关 Windows/macOS widget 变体与表单保存/取消均通过。Windows 主机上的 macOS 变体不代表 Mac 原生实测。

## 原生与交付边界

根目录 `scripts/dev-windows.ps1 build` 退出 0，产物为本机 Release App 及 runtime-worker。修复版主入口以隔离 APPDATA 启动（PID 17736），真实窗口显示 58 项及《Windows 知予接入说明》的正文、NAS 标签和飞牛 NAS 关联。`info.exe app status --pid 17736` 返回 running，`app quit --pid 17736` 返回 exited，均退出 0；没有强杀。

原生自动化限制：界面正确显示 Ctrl K，点击并显式激活窗口后可观察到搜索框焦点，Tab 也能改变焦点；Sky 的文字注入没有形成可确认的搜索文字，Ctrl K 两种写法均未观察到焦点切换。尚不能区分原生按键注入与实际桌面快捷键的问题。Windows/macOS widget 快捷键回归通过，但不把它算成真实键盘通过；#116 同版本桌面验收必须继续定位并解决实际产品问题（如存在），不能静默勾选此项。原生中文录入也仍未实测，已验证的中文表单保存来自生产装配 widget 流程。
