| 私密材料保存范围 | 连接和控制事实不写普通偏好；本机状态用 DPAPI，操作库用 SQLCipher。原子发布只使用私有同目录文件，替换失败不先删除目标。仓库增加 `/local/private/` 排除。NAS 检查仅经 stdin 领取初始配置，输出只含通过状态与计数。 |

## 现有 NAS 核对

使用现有 NAS 的私人 CA、管理接入和服务器身份；未修改 NAS 资料正文。通过正常主人接口登记一个独立 Windows Agent 设备，未复制 Mac 设备或聊天身份。

```powershell
.\scripts\dev-windows.ps1 dart compile exe scripts/qa/windows-online-storage-probe.dart --packages=apps/desktop/.dart_tool/package_config.json -o build/development/windows-online-storage-probe.exe
```

初始化入口 `--initialize <独立配置目录>` 从独立 stdin 接收四字段配置，保存后重新读取。后续独立进程 `--reopen <同目录>` 不再输入 Token。实际结果：管理及 Agent 配置重开、身份分离、设置重开、NAS 认证和 Agent capabilities 均为 true，普通资料计数 42。

`--verify-failures <同目录>` 对该开发配置的本机设置执行损坏、缺失和错误服务器绑定检查，全部拒绝；finally 恢复原加密字节。结果 `settingsFailureChecksPassed=true`。没有修改 NAS 设置。

私有配置保留在被忽略的工作目录下，实际输出见本机 `local/development/w108-nas-initialize.json`、`w108-nas-reopen.json`、`w108-nas-settings-failures.json`；不将连接配置、Token、证书私钥或聊天证明写入本记录。
