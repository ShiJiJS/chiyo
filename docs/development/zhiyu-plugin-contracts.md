# U04：插件、旧模板与采用流程的前端合同

本清单对应[#65](https://github.com/ShiJiJS/agent-info-manage/issues/65)及[实施记录](zhiyu-macos-plugins.md)，仅描述当前正式Flutter组件与独立合成来源。全部七项UI完成后，F01再把同一合同接到Owner服务；当前没有真实包目录、数据库迁移、主机确认、凭据使用或系统文件操作。S1/S2及ADR0016仍保持原提议状态。

## 页面、数据与操作

| 页面/动作 | 来源、返回与版本范围 | 确认与结果 |
| --- | --- | --- |
| 设置中的插件目录 | `plugins.load`返回目录版本、包身份/来源自述/原始摘要、定义、启用状态、宿主登记面板及使用数 | `PluginsController`持有选择/过滤/页签/滚动；事件使元数据失效，不预读其他资料正文 |
| 宿主选择插件包 | 注入的`WorkspacePluginPicker`仅返回selectionId、文件名、字节数 | 取消不安装；未选或关闭后释放候选租约，页面不读取文件路径/原始字节 |
| 安装/更新预览 | `previewInstall(selectionId)`返回原始摘要、解码定义、当前目录版本、原包和差异 | 同一解码器检查字节/深度/重复键/命名空间/版本/白名单/引用；预览不写入，不信任作者自述 |
| 安装/更新 | `change`携带随机operationId、install、packageId、所见目录版本、selectionId及expectedDigest | 明确确认；同版不同摘要拒绝，字段形态变化需新定义身份；更新/降级只改变后续新建，不迁移实例 |
| 启用/停用/移除 | 先读取同一包及影响数，再提交原动作、目录版本/摘要 | 内置包可停用不能移除；已有内容/附件/凭据关系/历史/身份维护保持，停用限制新建，不阻止通用阅读/编辑 |
| 包模板预览、结构和说明 | `WorkspacePluginTemplate`包含作用域类型及不可变定义；外部包和内置类型复用表单/阅读器 | instructions和样例是来源文本，不执行命令/HTML/远端加载，不签发访问能力；无宿主设置能力不显示空页签 |
| 新建/编辑普通资料 | `loadTemplate`或`readDetail`，共用`WorkspaceCreate`/`WorkspaceEdit`，后者核对expectedVersion；新建锁定模板版本和摘要 | 草稿与正文不放入元数据目录；成功按同一类型化记录读回；字段实例身份不使用定义key代替 |
| 资料采用新模板 | `previewAdoption`携带记录、已启用目标、来源/同义/新值，返回原资料/目录版本、准确目标快照、不透明计划、映射/保留内容/错误 | 明确`applyAdoption(operationId,planId)`后同一资料生成新修订；冲突重新预览，取消/晚到释放计划；凭据不能采用成普通信息 |
| 采用后阅读/关系/编辑 | 目标definition与实例自己的retainedFields/retainedRelations分开，普通标量fieldIds及经历叶身份保留 | 同名关系沿用实例保留的原含义；概览补出目标布局未列出的原关联，关系页/候选/编辑规则一致，不改目标包定义 |
| 旧版模板目录 | `legacyTemplates.load/read`返回原模板/字段定义身份、版本、名称/说明、种类和转换限制 | 保持InformationTemplate的录入辅助含义；不读取历史资料，不给旧模板自动套新类型 |
| 用旧模板录入 | `createRecord`增加legacyTemplateId、expectedLegacyVersion和独立fileSelections，文本对应必须完整 | 新建generic资料，每份字段实例独立；附件逐项宿主选择，异步验证后再核对版本、资料集和同次操作，失败无部分写入 |
| 显式local转换 | `prepareConversion(id,expectedVersion)`生成候选，仍经过同一解码/安装预览及明确确认 | 宿主保存来源模板版本/定义映射，外部JSON不能伪造；转换不改旧模板或历史实例，旧200字段与新40字段/无附件种类分别处理，不能截断/伪装转换 |
| 制作指引及只读校验 | 指引显示上次读取目录版本/身份；开发命令使用同一TemplatePackageDecoder，只读一个指定文件 | known-template参数仅是引用上下文；合法exit0且installed=false，非法/读取失败exit2，用法错误exit64；不安装个人Skill/hooks或批准访问 |

## 单台主机身份

`hosts.load/read`是Owner专属投影，包含准确的记录或保留identityId、规范化端点、观察/已确认指纹、状态及资料/插件/身份版本。详情对象入口、插件设置和失去原资料关联后的维护读取同一事实。DNS大小写/末尾点、IP和端口按现有纯Dart规则处理；当前不接受IDNA或IPv6 zone，不把该UI解析当真实SSH安全边界。

`hosts.change(confirm/revoke)`核对原对象和全部版本；缺指纹不能确认，变化先核对新旧指纹，停用仍可查看/撤销，启用不恢复旧确认。只由宿主登记内置服务器的面板，外部JSON不能挂接设置代码；没有真实导入成功提示。确认主机与批准凭据使用独立。

## 普通编辑的版本冲突

冲突后原草稿、控制器和输入继续保留，保存禁用。“读取当前版本并核对”按Owner接口重新读取同一记录/定义、目录和关联摘要，显示当前值与将保存的草稿差异，不写入。读取失败保留草稿，可再次读取；返回比较前的表单不会解除冲突。

结构/实例身份一致时，可明确选择“保留草稿，按当前版本继续”，只推进表单的核对基线，仍须再次保存。比较包含将覆盖的名称/用途、可编辑正文、分类和改过的关系；没有改过的关系、附件和只读旧内容沿用当前版本。未改过的关系选择器同时更新到已核对事实，不显示另一份旧选择。此处不自动合并正文；全部被草稿覆盖的当前可编辑内容都先显示供核对。比较期间又发生修改，后续保存仍会冲突，不能把一次比较当永久覆盖许可。

字段/经历实例身份、定义结构或草稿分类变化时，不把旧值塞进新含义；先查看/保留需要的草稿，再明确“清空草稿并载入当前表单”。该动作只替换表单，不创建/保存资料。新包更新、新版旧模板与已有资料采用新结构都用相同入口。经历比较显示名称/时间/说明，不向用户铺内部fieldId；移除或更换过的叶身份不能靠旧草稿复活。超长比较明确只预览前2000字，来源和草稿保留全文。

## 失败、等待与生命周期

| 状态/失败 | 当前界面与来源保证 | 检查依据 |
| --- | --- | --- |
| 首读等待、错误、真空结果 | 目录未读取不显示0个包/模板；刷新失败保留旧投影及重读，真实空结果独立 | `zhiyu_plugins_test`、`zhiyu_legacy_templates_test`的确定等待/错误/空结果，控制器代际检查 |
| validation/invalid_package | 字段或JSON路径错误显示原因，候选/映射/草稿保持；不提交非法包 | `workspace_plugins_test`真实字节/深度/重复键/引用预算及Widget无效包入口 |
| unavailable/selection_unavailable/selection_busy | 保留元数据，提供重新选择/读取；候选和采用计划各有100份上限 | 来源预算/释放检查、Widget选择取消/失败，不以随机延时冒充状态 |
| conflict | 安装/维护重读目录/摘要，采用重预览，主机重核对，表单按上述比较决定 | 各共享mutation禁止直接再写；`zhiyu_plugin_contracts_test`包含核对期间再次修改 |
| unknown_outcome | 固定原operationId及意图，冻结修改/关闭/返回与重发；先查原回执，查询失败仍冻结 | PluginMutation、HostMutation和RecordMutation逐项检查原动作/目标/版本/摘要或计划；正负/错误回执均有来源/Widget检查 |
| 确认未提交 | 回执null只表示未提交，保留内容，重新核对并等待明确重试 | 不把查询失败转换成null；查询不写入，不从未知状态自动重新安装/采用/保存 |
| not_found/unsupported | 明确包/资料/模板/指纹或材料已不可用，保留身份与原内容；不按名称补建目标 | 缺包通用阅读/编辑，200字段和附件旧模板不做有损转换，凭据保持专用入口 |
| 晚到/关闭/重置 | 代际或mounted检查丢弃旧投影；晚到候选/计划释放；未知操作回执不随表单租约释放 | 现有插件/主机/采用/旧模板控制器与取消检查；重置清除集中合成变更，恢复虚构基线 |

无正文回执分别包含插件动作/目录版本/摘要、主机动作/身份及所见版本、普通记录动作/计划或旧模板范围和新引用/版本。回执不能携带资料正文、地址/指纹或文件原文；旧对象永久清理后只保留提交事实，不通过缓存复活内容。当前是内存去重和表单租约，不能称为生产持久事务或重启找回。

## 隔离、替换与真实接入

- 页面依赖WorkspaceSource及plugins/hosts/legacyTemplates等端口；共享Widget不导入SampleWorkspaceSource。只有PreviewWorkspace组合入口选择集中合成来源、包/主机/资料fixture及虚构附件选择，来源可整体重置。正式main不加载预览，不为服务失败回退假成功。
- 原生预览仍在构造生产服务前选择隔离路径。核对MainFlutterWindow、preview_main和MacPreviewDesktop与既有已验源码的摘要一致；更新后的Mac隔离守卫走包安装/新建、主机撤销、采用、普通冲突比较、旧版录入/转换、指引和重置，拦截File/Directory、网络和六个生产通道。桥接桩及未变化原生源码不是新的Cocoa运行证据。
- F01接真实Owner事务时保存目录/定义、宿主来源映射、实例快照/保留描述、真实fieldId/经历叶/附件版本、修订和回执；同时完成迁移、完整备份恢复及重启后待核对操作找回。来源摘要不是作者签名或安装信任，模板说明/关系/布局不扩大批准范围。
- 普通附件复用OwnerInformationEditorSession及既有文件存储事务。标量createInformationFromTemplate拒绝file字段，不能直接当附件表单适配；真实候选TTL/取消/故障回收与已提交/未知引用分开。单份导出/备份仍需核对Owner现有能力，当前UI未宣称已写出普通资料或安装真实包。
- 现有SshHostTrustSnapshot是全局known_hosts快照，按端点的Owner决定须与整体ID/hash及旧执行计划失效一致；不把Demo指纹或前端确认布尔值交给实际SSH。材料授权、通知、hooks、系统选择器及Mac焦点填充继续按既有模块/默认关闭边界处理。
