# #7 主子 agent 与聊天结束

实现采用 ADR 0002、0005 的应用层凭据边界。代码完成不等于真实 Codex 验收完成。
先验证 Windows；用户自有 Mac 的验证后续安排，不运行托管 macOS 验证。

## 已实现

- 已有父私密证明委托同根子引用；随机引用绑定实际子聊天 ID，复用同一授权会话、
  固定字段集合与到期时间。父/子公开 ID 无法查询或恢复读取能力。
- SubagentStart 仅提示父证明委托，不按父 ID 查找文件。主进程可在实际子 ID 已知
  后通过私密任务上下文交付专用引用；此交付不能进入用户报告或普通日志。
- 根会话结束先不可逆锁定状态：待审批取消，仍获批的授权撤销并记录 ended；
  已拒绝、已过期等终态保持不变。标签与历史保留；重复结束无副作用。
- 读取等待访问记录落盘后再次核查授权/会话/字段。结束、撤销、过期、删除或替换
  先发生时，阻止交付并将该访问记为未授权；不会返回等待前缓存的旧值。
- 独立仅撤销凭据只在新建未授权会话时签发。服务 `/session/end` 验证此凭据；
  它不能申请、领取、读取、审批、导入确认或导出。通用 CLI 不输出任何凭据。
- 私有结束索引仅含仅撤销凭据、本机端口、公开关联和随机代际，无关联路径、
  读取会话秘密、token、资料或数据库密钥。哈希文件名、长度/类型/数量限制、
  文件锁和原子替换保护更新；每根聊天上限 64 个未确认代际。
- SessionEnd 对快照内所有代际请求结束，2 秒操作预算、hook timeout 3 秒。
  结束路径不创建目录或重设 ACL，不访问读取关联文件，不等待审计存储或 UI。
  失败保留索引，确认成功只删除对应代际，空索引删除但无秘密锁文件保留。
- Stop/Interrupt/SubagentStop、普通 CLI 退出和切换聊天不会结束根会话。
  startup/clear/fork 新建未授权会话；resume/compact 仅保留上下文已有引用。
  恢复已结束、已过期、撤销或旧应用实例的授权失败，需明确重新连接再申请。

公开 ID 结束适配器可能被同用户调用者仿造或被延迟事件提前触发，这是用户已接受
的可用性代价；不会因此取得读取能力。文件中的读取关联在确认结束后仍可留在私有
目录，但不能复活内存会话，结束回调也不会为了清理而搜索这些凭据。未送达/失败
的结束事件由固定到期兜底。索引满额/损坏时停止创建关联，不静默丢失旧代际；应在
所有相关信息服务已退出后修复私有集成状态，而不是通过公开 ID 恢复旧授权。

## 自动验证

采用已同意的核心服务公开 API、真实独立 CLI/hook 子进程和 Flutter widget 边界。
新增 TDD 切片先分别观察到核心缺少 end 接口、结束期间访问记录错误标为 allowed、
delegate 返回 invalid_request、SubagentStart 没有指引、桌面缺少结束说明，以及
等待落盘期间撤销仍交付内容，再逐个实现修复。

核心覆盖不可逆/重复结束、批准与结束两种顺序、既有终态、时间回拨、旧服务证明
失效、结束期间等待落盘和仅撤销 HTTP 鉴权隔离。真实 CLI 覆盖同一范围/到期共享、
错误子关联、ID-only 拒绝、多启动代际及子会话清理、非根事件不触发结束、无响应
预算和保留失败索引后重试。Windows AOT bundle 还执行生成的完整 PowerShell hook
命令，检查 stdin 传递和 3 秒内确认结束。测试只使用虚构信息及临时状态目录。

这些测试没有安装或信任用户 hooks、修改用户配置、读取私人 Codex 历史/认证、
创建真实 Codex 聊天或操作桌面。它们不能证明 Codex 桌面实际事件送达。

## 待用户配合的 Windows Codex 验收

先按 [接入说明](../../integrations/codex/README.md) 审查并授权安装生成材料，仅用
虚构资料，报告不包含私密引用或凭据。记录 Windows/Codex 版本和实际事件来源。

1. 两个独立聊天分别启动，A 获批一个字段；B 仅有 A 的公开 ID 不能领取授权。
2. A 创建实际子 agent，取得实际子 ID 后用父证明委托，并将子引用直接交给该子。
   子读取相同字段成功，额外字段仍须申请；到期时间不变。
3. 子完成、CLI 退出、切换聊天均不撤销 A；普通工具调用结束也不影响授权。
4. A 正常关闭/归档或触发平台实际支持的根结束事件后，既有子引用与缓存 token
   都无法再读取，待审批取消，拥有者显示结束原因。不能触发的事件保留未验收。
5. 重复结束不产生新授权；resume/compact 不复活 ended/expired/revoked 状态。
   fork 使用新的未授权引用，检查继承上下文是否确实被最新 hook 引用取代。
6. 完全退出/重启信息应用后旧引用失效。遗漏结束事件或崩溃只依靠固定到期；
   不能因缺少已验证回调而声称即时自动清理成功。

实际 Codex 子 ID、上下文交付时机、fork 行为、根结束事件顺序/送达尚未实测。
因此 #7 继续保留真实接入验收缺口。
