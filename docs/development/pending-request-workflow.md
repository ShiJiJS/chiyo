# 待审批请求生命周期（Issue #4）

默认待审批 30 分钟，截止时间在提交时固定。OwnerAccess 可保存新的有效期；设置通过信息库的加密 settings 表持久化，重新打开后保留。桌面提供 5、15、30、60、120 分钟选项；核心允许 1 分钟至 7 天的时长。修改设置不会延长已有请求。

核心公开接口支持待处理、批准、拒绝、过期、取消。过期在公开查询/处理时计算并固定；时间回拨不能复活已判定过期的请求。判断与处理在核心所属 isolate 中同步完成，没有中途 await；并发调用先处理者得到终态，后到的批准、拒绝或取消失败。已有授权仍使用原来的撤销和授权到期规则。

`OwnerAccess.requestSubmitted` 仅在创建请求时发布一个请求标识事件；查询、桌面刷新与 CLI 等待不会再次发布。系统通知由后续后台任务接入此流。本票没有实现系统通知。

CLI `wait` 和 `cancel` 语义见 [通用 CLI 说明](../cli.md)。CLI 有界等待不取消请求，不自动重提，也不在等待返回时自动领取凭据。
