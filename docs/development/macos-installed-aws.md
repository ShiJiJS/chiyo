## 实测发现并修正的产品问题

历史已经保存上述五次操作，但凭据详情仍显示“最近使用 / 尚未使用”。
实际 AX、画面和旧源码证实 `credentials.dart` 写死了该占位，不能把它归因于
Keychain、历史丢失或刷新时机。

修正 `4d45dfe` 在详情中显示该凭据所有版本保留记录内最近一次操作的时间与结果，
共用历史已有的命令/焦点填充状态文案；只有批准、没有操作时显示“暂无保留的使用操作”。
记录时间不足时明确说明，不把失败、准备中或焦点填充写成命令成功；其他凭据的操作
不会串入。没有改动核心授权、存储、原生平台代码或公开协议。

27 项相关 widget 回归与严格分析通过，新增覆盖批准但未操作、两次操作的时间顺序、
准备→启动失败状态、轮换后仍显示旧版本事实、凭据之间隔离、焦点填充结果及秘密不显示。
焦点填充使用已有模拟 driver，是共享 UI 回归，不代表新增 Mac 焦点填充支持。
