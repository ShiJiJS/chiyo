## 当前代码支持的边界

- 信息字段内容区分 InformationText 与 InformationFile。文件只保存类型化的附件 ID/正版本引用，不接受路径、Base64 或空文本充当文件正文；旧文本构造方式保持兼容。
- 信息项、提案快照、回收和修订的字段序列化保留类型；文件引用不能被普通 value getter 读为字符串。修改名称、描述、分类和标签时保留已有引用，修订比较及恢复按内容类型处理，回收恢复产生新的字段身份。
- 旧 Agent 文本提案/创建和旧模板入口明确拒绝文件写入；普通 read 对已授权文件返回 file_delivery_required，未获授权时不泄露私有引用。公开目录不带附件引用或原字节。
- 在新迁移和交付实现之前，旧 HTTP 请求/目录、schema18 写入及格式1–7备份验证明确拒绝不支持的文件内容。它们是本次中间态的封闭边界，不是最终文件接口，也不把文件字段静默漏掉或当空文本保存。
