## r1：从请求到可读回的决定

审批入口提供关键词、待处理/全部/已处理和分页，保留所选请求、各请求勾选、文件版本、分路期限和滚动。普通字段按实例fieldId选择，经历展开后逐叶选择；文件显示版本、名称、类型和大小，只读元数据。普通申请可补选同一资料中的字段，混合凭据申请限制在原普通字段集合；凭据本身可减选，不会因批准普通字段而一起获批。字段和凭据期限独立，整理最多30分钟。

凭据区呈现材料版本、注入位置、首个程序/参数、接收方和工作位置，说明CLI注入及授权期复用、不续期、操作独立和未知不重放。字段/附件、凭据和整理各有使用说明。Mac焦点填充显示关闭原因，批准禁用、拒绝可操作。名称、用途和会话说明明确为Agent自述。

批准、拒绝和撤销记录在同一来源，可查询处理后结果和固定期限；实际凭据详情的初始请求、新申请和审批收件箱共享稳定请求引用，处理后详情读回同一状态。顶栏待处理数由同一来源计算，材料更新、停用和回收可以让对应请求失效，不维护另一个计数。新增字段不进入已批集合；同义模板采用保留实例身份，已删除身份不能靠同名复活。

读取晚到不能覆盖新选择；后台更新保留默认和已编辑选择，只标记核对版本变化，不静默按新范围批准。明确重读保留选择，Owner仍需处理不可用项。提交或结果未知时锁住请求切换和顶栏导航。回执逐项核对操作、请求、动作、所见版本、完整命令摘要与结果版本；不符或查不到结果时继续冻结。只有明确的空回执表示未提交，保留文件版本及独立期限，等待再次明确决定；不会自动重放。

预览说明提供合成到期、会话结束和丢失回复入口，不模拟真实聊天hook或系统执行。到期或会话结束时保留当前请求并展示其结束状态，重置恢复同一初始数据。尚未实现单次凭据执行结果面板，审批结果未知不等于执行结果未知。

## 数据、操作与失败接缝

| 接口 | 页面需要的事实 | 失败与一致性 |
| --- | --- | --- |
| query | 状态、元数据关键词、全局选择位置、当前页、总数及待处理数 | 校验查询预算；完整筛选/排序后分页；空与读取失败不同 |
| read | 请求身份、自述、会话、所见核对版本；固定/可选字段身份；附件版本元数据；凭据使用计划；已批范围/期限 | 不含字段值、附件原文、凭据材料或临时授权凭证；异步读取后再核对版本 |
| change | 随机操作身份、原核对版本、动作、准确成员及附件版本、两类期限 | 冲突、失效、预算/版本校验、确定失败或结果未知；决定与回执同一提交事实 |
| receipt | 原操作无正文提交事实和完整命令摘要 | null只表示确认未提交；失败/不符继续未知，不执行重放 |
| credentials.requests/history | 相同请求身份/批准状态及无操作的授权元数据投影 | 详情与收件箱共享事实；批准不制造“已执行”访问记录 |

真实服务接入不能把合成ID、内存状态或Widget勾选当权限。OwnerAccess.approve需准确reviewedVersions和实例成员；decideCredentialUse需固定版本、使用代次、接收配置和分路期限，凭据申请的普通字段不得扩大。经历需映射核心逐叶身份；普通附件固定版本与交付分开。整理固定资料版本、最多30分钟，自动应用元数据而不新增第二次批准。持久事务、会话结束、重启失效、操作日志/租约清理、导航与进程重启找回及完整备份另行验收。Mac填充继续由#51后置。

## r2：单次使用结果与整票交接

源码`13066ad8fef8cee380a1d9cb3ddfd5f412f1b6eb`，#66推进到7/8且OPEN，唯一未勾选为完整S5/实际Mac系统输入与录屏。使用共享正式Widget，不新增第二套界面；没有真实授权或执行。

批准凭据后先显示“尚无使用记录”，不会制造使用成功。预览说明可为当前仍有效、确实包含凭据的决定显示三条独立合成操作：退出码0、启动失败和结果未知。操作各有固定身份、授权、材料版本、会话、结构化本次计划和时间，同一grant的期限不变。凭据详情使用记录投影相同事实，不复制可各自修改的状态；普通字段单独获批、撤销、到期、会话结束、材料更换或回收均不能新增这些操作。

执行状态、是否启动/结束、退出码和材料清理分别表达。“查询原操作”只读取原身份，不启动、不填充、不清理、不延长期限；错误、记录缺失、错误对象、版本倒退及同版本矛盾均保留原观察并允许继续查询。进程结束和清理完成不能推断成功：合成未知记录即使后来确认结束并清理，仍是未知、无退出码。正式核心的audit_unavailable也会暂时遮蔽终态；若后来存在可信、已持久化的原操作终态回执，可以显示真实终态，不能一概把所有未知永久锁死或由UI自行推断。

操作查询与审批提交分开。审批已明确提交、某条使用未知时仍能浏览或撤销授权；审批本身未知时仍冻结提交意图和导航。异步操作查询按请求、页面读取代次和查询身份隔离；切走再回来可重新查询，旧失败/旧finally不会覆盖新结果或解锁新查询。后台读取/加载期间不发起对旧投影的查询。

整票审计修复三处状态问题：会话结束和撤销后的已批范围不再标记有效；请求冲突不会残留到搜索/跳转找到的另一请求；重新选择已处理请求按实际获批成员显示，而不是旧待批勾选。重置清除旧提示及查询状态。通过实际预览说明控制等待、空数据、失败及恢复，不把失败伪装为空；提交确定失败保留选择。整理请求可减选资料、选择15/30分钟，批准并不伪装成已应用整理结果。

### 新增只读使用合同

| 数据/接口 | 语义 | 失败/生命周期 |
