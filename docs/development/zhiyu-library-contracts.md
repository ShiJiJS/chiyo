# U02 信息库前端接口与接入清单

当前是隔离内存来源，组件和控制器依赖`WorkspaceSource`，只有预览组合入口认识合成fixture。接口实现及版本依据见[信息库实施记录](zhiyu-macos-library.md)。本清单记录现有页面读写需要和失败语义，不授权接入真实库、秘密或系统执行；F01在全部七张UI就绪后再核对核心服务。

## 数据与读取

| 入口 | 页面需要的事实 | 边界与结果 |
| --- | --- | --- |
| `changes` | 类型化对象引用；null表示目录/重置等全局变化 | 各控制器重新投影；代际检查禁止旧查询覆盖新结果，不抢已有输入焦点 |
| `loadSummary` | 当前资料、待审批和提案数量 | 数量来自同一来源，非页面硬编码；读取错误不显示成功 |
| `loadCatalog` | 目录ID/名称/父ID、独立标签注册表、类型、后代/标签数量、回收数量、目录版本 | 信息/凭据统一元数据投影；空目录及未使用标签仍可选；所有ID不依显示名 |
| `queryRecords` | 目录/关键词/一个类型/一个标签、分组/排序、offset/limit | 元数据交集；关键词不读字段正文/附件/秘密。完整结果排序分组后分页，返回全局组数、总数及选择位置；末页收缩纠偏 |
| `readDetail` | 主人明确打开的记录、版本、模板定义快照、值和关系 | 信息与凭据kind不可丢；普通详情对凭据只给元数据，values为空。不可变值/定义支持旧复合内容，不能字符串化覆盖 |
| `loadTemplate` | 新建普通资料所需空白定义 | 不借用其他对象正文；通用模板不带旧实例的额外字段；凭据不走普通创建 |
| `queryRelationCandidates` / `readSummaries` | 来源快照的关系规则、候选及已选身份的名称/类型/用途 | 候选搜索/分页只返回摘要，targetTemplates为空代表不限；不从标题猜限制，不提前读取目标正文；不可用引用保留身份提示 |
| `loadRevisions` / `previewRevision` | 版本摘要；按需完整原快照、当前/拟恢复内容、分类及目标名称快照、目录版本和提示 | 历史不可变；比较覆盖所有值、关系和定义；缺失字段要求先显式回收恢复，不能借旧版复活 |
| `queryRecycled` / `readRecycled` | 回收摘要、唯一entryId、删除版本、删除/到期时间；明确查看时的原快照 | 回收对象离开当前搜索/关联候选；不把回收内容塞入公开列表。当前30天字样是冻结预览配置，正式期限须由设置/服务核对 |

列表引用始终为`kind + id`；两个种类可具有相同字符串ID。真实适配不能复用一个仅按裸ID索引的表。目录/标签计数包括凭据；标签注册表独立于当前结果和当前一页。

## 写入与失败

| 命令 | 写入核对 | 成功后与失败后 |
| --- | --- | --- |
| `changeDirectory` | 操作身份、目录版本，完整目标名称/父级；同父级忽略大小写重名、防环、空删除（含凭据/子目录） | 返回新/改目录或删除null；错误保稿，冲突重新读取；目录消失只清对应筛选 |
| `createRecord` | 操作身份、普通类型、名称/用途、分类、值及关系 | 新对象v1及类型化引用；成功后读回定位，不将失败当创建 |
| `saveRecord` | 操作身份、expectedVersion；摘要/值与改变的关系key同一原子命令 | 返回`WorkspaceSaved(detail)`或`WorkspaceRejected(failure)`。未改关系/未知复合值保留；成功生成历史，失败不产生版本 |
| `changeRecord` | recycle/restoreRevision/restoreRecycled/purge、操作身份、类型化引用、记录或entry版本；恢复另核对目录版本 | 返回无正文回执。恢复超过删除版本、永久清理另确认对象；回收及恢复不复活旧授权 |

- 常见失败：`validation`及fieldErrors、`not_found`、`unsupported`、`conflict`、`operation_conflict`、`directory_not_empty`、`recycle_restore_required`、`cancelled`与读取不可用。保存和生命周期命令的失败均不应提前toast成功。
- 确定失败保留草稿或当前回收对象，允许明确重试。冲突必须重新读取/比较；`unknown_outcome`先核对来源，不允许直接重复提交。提交中防重复，未保存表单有关闭保护。
- 同一操作身份不能改负载；重试不能重复产生对象、版本或回收条目。当前合成实现指纹使用SHA-256，清理时移除旧成功缓存正文。显式fixture重置保留合成初始事实，不等同真实擦盘。
- 分类恢复遵循ADR0014：历史保留原事实，当前恢复只用现存目录/标签；缺目录归未分类、缺标签跳过。失效关联不恢复成可用链接。

## 跨页接缝与后续归属

- 关联跳转只移除阻挡目标的查询条件，定位目标所在页，返回恢复原查询、选择与列表位置。后台刷新同对象不重播详情进入动画。
- 主机身份入口导航到设置`plugin:builtin.server/host:<record-id>`，插件专属设置及信任摘要由U04补齐；标签管理到设置`labels`，全局管理由U07补齐。入口路由不是对应业务已完成。
- 档案经历、文档/文件/凭据专用生命周期和使用入口归U03；审批、提案、授权历史归U05/U06。普通正文/关系接口不能扩展为读取秘密或执行程序。
- F01必须复用真实字段实例ID、恢复映射、部分字段回收、授权失效事务、普通附件版本/受管副本及审计事实。前端template key、示例版本水位和内存操作缓存不能代替它们。
- 真实查询需保留全局分页/计数语义；200信息+8凭据/50目录/100标签只是UI容量检查，不是正式后端性能承诺。真实接入补齐持久化、重启、权限、备份和恢复后才可宣称功能完成。

## r11：Mac名称排序与分组投影

Mac名称排序使用系统CoreFoundation的显式`zh_CN`比较，不随本机显示语言改变，不维护演示名字的拼音对照表；名称相等（含规范等价Unicode）时按完整`kind:id`稳定排序。最近更新时间的平局规则不变。关联候选使用同一名称排序。CF locale、字符串和UTF-16缓冲只在当前排序期间持有，结束或失败都释放；读取范围仍限元数据，不读取字段、附件或秘密。Windows名称比较留原有实现，专项适配后置。

先按所选排序排列完整结果，再按类型/目录首现位置分组并保持组内顺序，最后分页；组数和选中索引仍属于完整投影。真实来源接入时须复用此查询语义，不能只给当前页重排。当前宿主文件模型将简历和其他文件合为`file`六项，冻结原型为简历文件两项/文件四项；通用资料分组名称也有差异。它们仍是后续S5待修项，不用中文排序通过来豁免。

## r12：文件模板与筛选族

已有简历使用独立resume显示模板，仍为information引用和普通file字段，不增加文件所有权体系。按类型分组区分resume/file；文件筛选和目标模板file的关联查询包含两者。目录、标签、选择与全局分页规则不变。筛选菜单和新建资料选择器不另加resume入口，普通导入仍生成file；文件名不决定模板，已有定义快照不因名称变化被转换。

loadCatalog提供冻结的紧凑类型菜单顺序，动态插件类型追加；完整结果自己的type仍包含resume用于分组。通用宿主采用“通用信息”，用户/插件声明的名称仍来自其定义。真实适配须按已知模板身份映射，不能从含“简历”的文件名或内容猜类型。本轮未改WorkspaceFileImport或任何生产协议、数据库/Keychain/权限边界；[r12证据](evidence/zhiyu-round09/u02/macos/r12/checkpoint.json)覆盖源/Widget与构建，完整S5仍开放。


## r13：内容形式选择与插件导航

创建选择器以catalog.creatableTypes决定可选类型，插件load只补充启用包的模板说明，不读取资料详情。说明等待/失败不隐藏可选类型；未知类型保留，失败可重试。选择返回明确的模板或插件设置意图，不把导航误当创建结果。插件入口关闭弹窗后通过既有模态导航队列进入settings/plugins；没有新增持久化操作或真实插件执行能力。

普通文件、凭据及通用/模板编辑仍走原接口和版本/幂等合同。选择器取消和插件导航不写记录；目录未选时显示未分类。四组几何及八组Widget入口不替代完整S5/OS输入，见[r13证据](evidence/zhiyu-round09/u02/macos/r13/checkpoint.json)。
