## 1000 条资料、32 个目录和 128 个标签

实际 Mac 签名 Debug Flutter、SQLCipher 和独立 ARM64 AOT CLI 的六阶段流程通过：

- 完整遍历 20 页，逐页核对首条身份，并选择末页第 1000 条资料；通过字段公开说明搜索唯一末项，私密字段值和主人私人标签/目录名称不能用于公开目录搜索。
- 原生测试驱动完成目录创建、循环拒绝、移动和标签改名；组合过滤及完整库关闭重开保持字段身份、版本、原值和分类关联。重开后原 CLI 授权失效。
- 四主题 × 100%/200% 字号，在 1280×800 完整应用中选中最后标签和第 32 个目录，清除过滤并翻页。目录列表使用受控 ScrollController，随后检查目标按钮实际可见、可点击；这不证明物理触控板或滚轮输入。
- 独立 CLI 通过 70 次协议断言，包括每阶段全量 1000 条公开目录的十页返回去重、搜索、目录/标签筛选及内容授权边界。
- 最终 native run-6：41 张 Flutter 渲染 PNG，Flutter 与两个 CLI 均退出 0，没有剩余测试进程组。资料准备计时 950 ms 只描述该夹具的写入耗时，不是响应时间或帧率保证。

较早失败轮次保留：run-1 未滚动即定位未加载的末目录；run-2 等待超时，退出测试启动器后发现子进程残留并明确回收；run-3/4 的嵌套滚动驱动未正确到达末目录；run-5 首次跳到估算滚动尾部后，变高行尚未全部加载。最终驱动等待列表完成尾部布局，另外为原生进程建立独立组并在失败时回收。以上失败均不算通过，不据此声称产品缺陷或修复。
