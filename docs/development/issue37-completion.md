## 冻结的保护值

| 对象 | 当前界限 |
| --- | --- |
| 单个原文件版本 | 10 MiB，允许零字节；不截断 |
| 原文件总量 | 100 MiB，正式可用版本、历史/回收保留正文与加密暂存共同计入 |
| 版本元数据/交付历史 | 各10000条，按保留及活动幂等规则管理 |
| 同时受管副本 | 32份、100 MiB；准备中及待清理也占位，与原文件预算分别计算 |
| 便携元数据/加密容器 | 64 MiB UTF-8 JSON / 256 MiB；正文按最多1 MiB分块，不做Base64快照 |
| 备份行数 | 总计500000；字段/标签关系/文件关系及访问/清理事实各200000；模板/设置各1000；其他表各10000 |
| 嵌套历史事实 | 总计500000，计数与完整备份验证器相同；为回收/修订后续清理预留行名额 |

上述事务准入用于含附件/文件模板的库。纯文本旧库保留原有格式7行为；没有把本票扩大成所有旧文本库的全新容量保证。预算按真实便携投影计算，并为已登记文件交付、活动凭据命令/填充、普通授权结束和附件保留时间预留剩余JSON贡献，包括外层转义。计数投影不是可保存的领域对象；正式导出/恢复仍做完整关系验证。初次副本登记因容量拒绝时不占操作、不写文件、不塞入不可能完成的审计修复队列。
