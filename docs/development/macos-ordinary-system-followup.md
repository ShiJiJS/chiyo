## 固定普通应用的通知允许

应用设置最初显示“尚未开启系统提醒”。实际点击一次“开启或检查提醒”，系统提示
位于`com.apple.notificationcenterui`；CUA只对info_desktop提示执行其已暴露的
“允许”动作，提示消失，应用显示“系统接受通知”。没有要求主人配合或输入密码。

系统设置中本应用允许on，桌面/通知中心/锁屏均选中，临时提醒、声音on、预览默认、
分组自动。保留已允许状态。全局“当镜像或共享屏幕时”为“关闭通知”，没有改动
该偏好、专注模式或其他应用设置；观察到这项设置不等于已经证明本条被它抑制。

从正式设置入口只发送一次测试通知，应用显示“测试通知已提交给系统；是否显示仍受
系统通知设置影响”。NotificationCenter没有出现这条测试通知的可点击项，Raise后
仍未观察到该条。ControlCenter观察返回timeoutReached，没有重启服务、重复发送、
注入回调或将API接受计为实际显示/点击。本次测试通知没有请求身份，不算申请定位。
系统设置返回原通知列表，普通应用返回原信息库。

通知权限和提交通路在普通安装中已有直接证据，真实前台/后台显示、点击、类型与
