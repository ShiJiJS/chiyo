## 修改内容

- 录入前查已有资料、凭据和完整目录，再查当前 App 的动态模板、格式及例子。
  优先复用已有位置，目录类型不按模板名称机械生成。
- 先提取长期有用的事实；没有独立用途的来源不重复附带保存。
  必须保管的原件建独立文件资料并关联，修订保留为版本。
- 应用用软件名和部署位置命名，设备配置单独保存并关联。已由业务 Skill
  维护的流程不在资料库再存一份。纠错直接修改最终内容，无变化不提申请。
- SSH 可由用户选本聊天内不限时；核对明确的期限类型和可用状态，不把空到期
  时间当作许可。撤销阻止后续使用，不终止已运行命令，也不撤回远端结果。
- 新手册仍将实际模板、字段和提交格式交给 App／CLI，不维护另一份固定清单。

上下文的子 Agent。提示只含普通整理任务、合成来源路径和隔离接入环境；没有
给条目数量、目标目录、模板、关联或版本划分答案。测试服务使用生产核心与
当前 App 实际导出的模板定义；客户端是已安装 0.4.3 的同字节 CLI／hook／worker。
采用独立端口、私密关联和内存库，不连接生产服务，不安装 hooks 或改变信任。
