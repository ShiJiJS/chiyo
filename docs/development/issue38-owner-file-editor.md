## 已连接的真实行为

所有者新建/编辑与模板套用现在走`beginInformationFileDraft`、`stageInformationFile`和`commitInformationDraft`。UI草稿明确分开文本、加密暂存摘要与未变附件引用，不读文件的旧value接口，不携带源路径/正文。模板只定义空文件字段；信息库继续保留目录树、中间列表和右详情，含文件标识、私有名称/大小/MIME/版本、更换、另存和公开预览均分支处理。

`OwnerInformationEditorSession`拥有整个表单生命周期：取消系统选择保留当前选择；摄入或更换失败保留原文件和其他输入；移除/改类型释放相应暂存，换模板成功清理原表单后才替换字段。关闭会等待已经开始的选择/摄入再回收。清理失败不伪装已完成，仍可重试；应用退出另有Owner统一回收。

相同保存输入复用同一操作ID，修改输入后才换ID。保存失败保留暂存供明确重试；同用途更换保留字段身份并产生新附件版本，类型/名称含义变化仍走新身份和确认。已知保存成功而最后清理失败时，界面明确“已保存”，锁定表单，只允许重试清理关闭，不重新提交或生成第二版本。

系统文件选择/另存复用现有Windows MethodChannel，返回路径只跨本机picker→Owner调用，不进入表单、错误文案或数据库。导入有界读取且不改源文件；另存不覆盖现有目标。跨设备导入的文件显示名称若含Windows不可用字符，只净化另存对话框的建议名称，不改原元数据。Release编译通过不等于真实系统对话框操作已验收。
