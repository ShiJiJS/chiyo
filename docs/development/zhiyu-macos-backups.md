## 用户路径与状态

设置→备份与恢复显示恢复密钥是否创建/另存、最近生成的归档、目标库是否实际为空及待清理资源。冷加载和读取失败不假设空库，不允许基于未确认状态写入；读取失败可重试。

导出先创建独立恢复密钥，显式显示/隐藏，再选择另存位置并保存密钥文件，最后选择归档位置并导出完整备份。保存密钥成功前不能导出；同名已有输出明确拒绝，不能覆盖。文件选择取消保留原选择、不提交；选择错误和确定保存失败保留可重试状态。选择器等待Owner选择时保留操作门禁，但不显示无限提交进度。恢复密钥在来源变化、写入、关闭和销毁后隐藏。

恢复先核对目标库严格为空，选择归档与恢复密钥，再只读检查格式、密钥匹配和完整范围，最后点击固定底部动作“确认恢复到空库”。没有覆盖或合并恢复选项。仅有标签、模板、历史、文件或凭据事实也不是空库；“空数据视图”不等于真的空库。归档损坏、密钥错误、较新格式、目标变化、文件选择版本变化或检查失效均拒绝恢复。成功结果显示同源回执及数量，可前往同一信息库读回；不再显示恢复前的空库警告。

正文单独滚动、弹窗标题/底部动作固定，200%文字将文件位置和操作纵向排布，不缩小字体。使用现有DesktopButton、DesktopDialog、DesktopEntrance、SettingsPreferenceRow和180ms弹窗/页面语法；没有增加另一套控件或动效体系。设计说明提供明确的“完整合成资料”和“独立空库恢复场景”，仅组合入口知道样本来源。

## 可替换数据与操作合同

| 接口/对象 | 内容与边界 |
| --- | --- |
| `status()` | 版本、独立密钥创建/另存状态、实际空库及阻挡原因、最近归档身份、待清理数量；不是正文或密钥 |
| `WorkspaceBackupResource` / 注入的picker | 不透明身份、文件名、输入/输出种类及版本；不向页面暴露原始路径、文件句柄或秘密。正式组合入口以后替换原生Owner面板 |
| `revealRecoveryKey()` | Owner明确显示动作使用的短期正文；普通状态、回执和资源对象不包含它 |
| `inspect(archive,key)` | 只读检查，返回绑定准确文件/密钥版本、目标来源及观察修订的token、格式/时间和完整分类计数；不会恢复 |
| `change(command)` | 创建密钥、保存密钥、导出、确认恢复、重试清理；operationId和摘要绑定完整动作、配置版本、选择和预览token |
| `receipt(operationId)` | 只读原操作事实，包含版本、准确输出/归档和范围；null明确表示未提交，查询失败必须抛错 |
| `releasePreview(token)` | 取消检查租约。清理失败单列待清理状态，不能误报已清理或已恢复 |

导出/恢复计数区分普通信息、凭据、凭据材料版本、普通附件版本/原文字节、目录/标签、类型定义、插件/旧模板、资料修订、回收对象、授权历史、操作事实和主机信任。控制器核对完整意图摘要、版本和返回资源；恢复回执还必须与原检查数量一致，不能因“有一条成功结果”就解锁。

确定写入失败不改变资料或发布归档。结果未知则保留原命令并锁定写入、关闭、设置换页和根级/原生导航，只查询原operationId，不重放导出/恢复。错回执、错范围或查询失败保持未知；确认未提交后要Owner再次明确操作，使用新身份。已提交回执独立于文件和检查租约保留，重复同一命令只返回原回执，不在重置后的资料上重写。

取消检查不恢复资料。临时资源清理失败保留数量及重试入口；清理本身可失败，仍能重试。资料写入已确认成功但清理待办时同时保留成功和清理状态，不把清理失败变成“资料没恢复”，也不拿清理完成推断外部进程结束。

## 同源合成往返与历史边界

`SampleWorkspaceBackups`只持有会话内逻辑资源、分离的资料快照、已批准样本原字节和回执，不做加密、文件系统发布、数据库访问或Keychain调用。显示的密钥以`preview-recovery:`开头，不能当真实恢复密钥使用。没有伪造实际加密成功或新备份格式版本。

完整导出覆盖同源当前资料/稳定字段与关系身份、保留修订/回收快照、普通附件各版本及字节、凭据材料元数据和历史、分类、偏好、类型/插件/旧模板及保存的主机事实。样本原文从现有受限资源清单按大小和SHA256验证；任何原文缺失或校验失败使整次导出失败，不跳过。原样本`unknown`有`unsupported.bin`原文，只是不支持预览，仍完整保留；不能将它误认为缺失，不能用简历字节替代。另有故障测试明确从资源清单移除它，证明缺失路径拒绝生成部分归档。

快照脱离活动来源。导出后修改原资料、切换为空库，并禁止再次读取原资源，恢复仍能读回原字段/关系/修订和附件页面。准备附件期间资料重置或变化取消发布；同数量的目标变化也不能复用旧检查。

不备份待审批、未确认提案、整理任务/结果、活跃访问能力、运行材料或输出。决定过的申请及操作作为旧设备历史事实保留，原会话全部结束；运行/准备中的旧执行显示未知，标记来自备份且没有本机可接管的进程或临时材料。读取历史及预览观察入口不能把原设备进程“核对为结束”，历史不重新成为有效授权。新申请使用新的合成会话身份，明确批准后才生效。本机数据库密钥和本机备份配置不从归档复制；界面没有触碰实际密钥。
