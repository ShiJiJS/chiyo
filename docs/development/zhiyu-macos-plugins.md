## 当前界面与结果

“设置 → 插件”使用正式Flutter页面和共享控件，列出已安装包并按启用状态筛选。包详情提供模板预览、字段/关联结构、原文录入说明、来源/摘要及使用数量。没有实际设置能力时不显示空设置页签；服务器专属主机设置仍归本票下一步，不以隐藏页签算完成。

选择包后先解码并预览，明确确认才提交。安装差异可以核对旧定义和新结构；同ID同版本不同原始摘要拒绝覆盖。更高或明确选择的较早版本只改变后续新建，旧实例快照不变；同字段key直接更换内容形态会拒绝，必须改定义身份。停用、移除先读回影响数量和后果；失败保留预览，冲突重读，未知结果冻结同一操作并先查回执。正回执退出后重新读取目录，负回执只表示确认未提交，等待明确重试。

内置服务器与外部域名都走同一个模板表单、字段校验、关系选择和资料阅读器，按插件ID写页面的分支没有增加。域名可以从插件或信息库新建入口创建，并关联同一信息库中的服务器。编辑器携带所见模板版本/摘要，提交前更新会形成冲突，不悄悄换定义。类型筛选目录与可新建模板目录分开，停用/移除不让已有类型筛选消失。

新建实例保留不可变definition、packageId、templateVersion及原始packageDigest；旧快照缺失的摘要不追补。可用性是当前目录投影，不回写旧快照。停用、缺包或新版不再提供某模板时，原资料继续按保留字段、经历、附件及关系查看和编辑，未定义的旧复合值保持完整JSON形状；重装只恢复可用展示，不迁移旧值、版本或定义。空日期的中文“未填写”采用现有桌面字体回退，避免等宽字体缺字。包被移除导致选择变化时，详情返回新选中对象顶部；跨工作台导航保留插件选择、筛选、页签与阅读位置。

## 输入与操作合同

| 接口 | 所有者界面获得什么 | 失败与生命周期 |
| --- | --- | --- |
| WorkspacePluginSource.load | 带目录版本的包/模板元数据、启用状态及使用数量 | 晚到读取丢弃；刷新失败保留旧投影，首读等待/失败不冒充0个包 |
| WorkspacePluginPicker | selectionId、文件名、字节数 | 宿主组合入口提供选择；页面不读路径、字节或本机目录 |
| previewInstall | 原始摘要、解码定义、所见目录版本、旧包及差异 | 校验/同版本摘要冲突/字段身份冲突保留明确原因；没有写入 |
| change | 原operationId、动作、包身份、expectedVersion及摘要/选择身份 | 先核对目录/内容；内存状态与无正文回执同次提交，无部分安装；内置包可停用不能移除 |
| receipt | 原动作、包身份、原目录版本、提交后的版本及摘要 | null只表示确认未提交；查询失败继续未知，不能自动重发 |
| releaseCandidate | 释放未选择或已关闭表单的选择租约 | 合成来源只清内存字节副本，不删除已提交回执；未知时保留原选择，F01须区分真实表单租约与提交引用 |

普通记录仍用WorkspaceSource及U03的回执/历史/回收入口。现有server/service/profile的工作台typeId保持兼容，外部类型使用packageId/templateId，不按同名覆盖内置身份；关联引用在宿主适配到现有带种类的资料引用。新建和编辑共用既有200叶字段预算与经历身份规则。

## 声明包校验

[结构合同](../design/zhiyu-template-package.schema.json)与TemplatePackageDecoder配合：UTF-8原始字节先检查1 MiB上限，递归最多16层；扫描重复键（包含转义后的同名键）后才解码，避免JSON静默覆盖。hostApi=1，三段非负版本，外部命名空间不得占用builtin；模板/字段/章节/关联/说明分别受S2预算约束。未知属性、脚本/设置挂接/远端图像属性、不支持类型/图标/布局、重复身份、悬空字段或模板引用均返回路径与原因。说明、样例及作者都是来源文本，不执行、不自动联网或获得可信标记。

JSON Schema记录结构与允许属性；原始字节/深度/重复键、UTF-8说明字节预算、引用及跨版本身份由Dart校验器执行，schema的x-注解明确这些补充规则。没有宣称只凭JSON Schema就能检查原始输入或安装安全。域名合成包来自冻结样例，外部服务器引用单独转换为S2要求的builtin.server/server；冻结原型原文件没有修改。
