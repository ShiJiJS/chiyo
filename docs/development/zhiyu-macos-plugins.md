## 当前界面与结果

“设置 → 插件”使用正式Flutter页面和共享控件，列出已安装包并按启用状态筛选。包详情提供模板预览、字段/关联结构、原文录入说明、来源/摘要及使用数量。只有宿主登记sshTrust面板的内置服务器显示“插件设置”，外部JSON不解码面板能力；无设置能力的包不显示空页签。

选择包后先解码并预览，明确确认才提交。安装差异可以核对旧定义和新结构；同ID同版本不同原始摘要拒绝覆盖。更高或明确选择的较早版本只改变后续新建，旧实例快照不变；同字段key直接更换内容形态会拒绝，必须改定义身份。停用、移除先读回影响数量和后果；失败保留预览，冲突重读，未知结果冻结同一操作并先查回执。正回执退出后重新读取目录，负回执只表示确认未提交，等待明确重试。

内置服务器与外部域名都走同一个模板表单、字段校验、关系选择和资料阅读器，按插件ID写页面的分支没有增加。域名可以从插件或信息库新建入口创建，并关联同一信息库中的服务器。编辑器携带所见模板版本/摘要，提交前更新会形成冲突，不悄悄换定义。类型筛选目录与可新建模板目录分开，停用/移除不让已有类型筛选消失。

新建实例保留不可变definition、packageId、templateVersion及原始packageDigest；旧快照缺失的摘要不追补。可用性是当前目录投影，不回写旧快照。停用、缺包或新版不再提供某模板时，原资料继续按保留字段、经历、附件及关系查看和编辑，未定义的旧复合值保持完整JSON形状；重装只恢复可用展示，不迁移旧值、版本或定义。空日期的中文“未填写”采用现有桌面字体回退，避免等宽字体缺字。包被移除导致选择变化时，详情返回新选中对象顶部；跨工作台导航保留插件选择、筛选、页签与阅读位置。

## 声明包校验

[结构合同](../design/zhiyu-template-package.schema.json)与TemplatePackageDecoder配合：UTF-8原始字节先检查1 MiB上限，递归最多16层；扫描重复键（包含转义后的同名键）后才解码，避免JSON静默覆盖。hostApi=1，三段非负版本，外部命名空间不得占用builtin；模板/字段/章节/关联/说明分别受S2预算约束。未知属性、脚本/设置挂接/远端图像属性、不支持类型/图标/布局、重复身份、悬空字段或模板引用均返回路径与原因。说明、样例及作者都是来源文本，不执行、不自动联网或获得可信标记。

JSON Schema记录结构与允许属性；原始字节/深度/重复键、UTF-8说明字节预算、引用及跨版本身份由Dart校验器执行，schema的x-注解明确这些补充规则。没有宣称只凭JSON Schema就能检查原始输入或安装安全。域名合成包来自冻结样例，外部服务器引用单独转换为S2要求的builtin.server/server；冻结原型原文件没有修改。

## r2：主机身份与宿主设置

源码`8e7b0b47dd3421b7bfcdc4daf75b3fce277835e8`将信息库“主机身份”入口接到内置服务器设置和准确的资料身份；先前选中其他包不会误入该包。跳转请求只消费一次，关闭后普通导航回来不重复弹窗，信息库查询和选中项保留；弹窗也可回到对应资料。旧`ssh-hosts`路由在组合入口转向服务器插件设置，不增加全局SSH入口。

沿用冻结R07/R08的设置工作区、对象入口、分隔线、字体/配色及共享120/150/180ms反馈。用户任务是核对当前要连接的主机并看清确认结果；“顺手”入口适合单台核对，“专用”插件设置适合集中维护，同一事实支撑二者。不采用自动确认，因为现有资料不能证明新指纹真实。原先详情点击只切设置而未选包/对象，路径中断；现在一次点击即看到指定主机，不需记住名称、重新找包和主机。明确撤销/重新确认后直接读回，失败留在原核对内容；没有新增风格或设计规范。

### 页面与操作合同

| 入口 | 返回/意图 | 失败和结果 |
| --- | --- | --- |
| WorkspaceHostSource.load | 当前服务器的Owner身份投影及失去资料关联的保留身份 | 明确等待/失败/重读/真空；不是公开目录预加载地址和指纹 |
| read(record或保留identityId) | 名称、规范化端点、当前/已确认指纹、身份状态、资料/插件/身份版本 | 缺资料/身份返回not_found；不存在的资料不会从历史回执重建 |
| change(confirm/revoke) | 随机operationId、原核对投影及变化指纹的明确核对决定 | 核对端点、资料、插件和身份版本；冲突重新读取；失败无部分状态 |
| receipt(operationId) | 原动作、opaque identityId、目标身份、原资料/插件/身份版本与新版本 | 无地址/指纹正文；逐项核对，错误回执不能解冻；null仅确认未提交 |

规范化是无IO的纯Dart检查：DNS大小写和末尾点、十进制IPv4及IPv6地址按同一身份投影，空端口默认22；保留端口区别，拒绝URI、用户/路径/选项文本及范围外端口。当前不接受IDNA或IPv6 zone，实际服务接入要明确与核心/SSH解析的一致性，不能仅依靠UI解析保护执行。身份事实按规范化host＋port保存观察到的指纹和已确认指纹；不同资料指向同一端点共享确认/撤销，名字不影响身份。修改地址/端口后新端点不继承旧确认，原端点仍保留维护入口，即使资料已改名/移走。

状态包含地址不完整、尚未取得指纹、待核对、已确认、指纹变化和已撤销。缺指纹不能确认；变化时展示新旧值、警告和明确核对选项。停用不能重新确认，但仍可查看和撤销；重新启用不自动恢复已撤销确认。未知结果冻结关闭、返回和重发，先核对原回执；正结果读回，确认未提交先重读再明确决定，查询失败仍冻结。晚到读取和已关闭控制器不回写页面。

只有SampleWorkspaceHosts保存可重置的合成事实，基线东京主机已确认只是冻结虚构资料。观察变化、缺指纹可从“设计说明 → 主机身份状态”重现；重置恢复同一基线。页面不存第二个布尔值，不读known_hosts、不发SSH/网络请求、不申请凭据使用。当前没有真实导入按钮或导入成功提示。

兼容与转换的容量分别处理：旧表单沿用现有1–200字段，可继续录入；hostApi=1每模板最多40顶层字段且不声明普通附件。遇到附件或超过40字段明确禁止转换，不能截断或把附件改成文本。其他旧字段名称/说明超过声明包预算时由同一校验器返回具体路径，保留旧录入能力，不提高合同预算。转换的说明由原字段说明组成，仍受16 KiB限制。

### 可实际运行的只读校验

在`apps/desktop`下执行`../../scripts/dev-macos.sh dart run tool/validate_template_package.dart 包.json`。跨包关联额外传`--known-template 包ID/模板ID`，身份须先从Owner元数据核对，参数本身不是已安装或可信证明。入口仅读取指定文件，以同一TemplatePackageDecoder检查原始字节预算、重复键、结构、引用等，不创建Owner、资料库、UI或安装器。标准输出单个JSON：合法exit0且installed=false；非法包或读取失败exit2，使用方式错误exit64。SDK自身的build hooks诊断在stderr，不混入JSON结果。

指引按S2-P05说明先复用→缺少时生成无秘密包与虚构样例→只读校验→交给主人预览安装→再提交具体录入提案；字段含义/格式/单位、普通文件用途、关联证据、去重和分类都有明确说明。这里只交付程序内可选取的指引与开发校验命令，没有安装或改写个人Skill、hooks、CLI身份。
