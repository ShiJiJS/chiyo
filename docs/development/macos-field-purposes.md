## 修正与回归

通用 DesktopTextField/TextFormField、凭据普通输入、模板、目录／标签以及审批、信息库、
凭据、提案、历史和选择器搜索接入同一用途／几何适配。原编辑行为、草稿和保存入口保持；
Mac 秘密仍走 MacSecretInput/NSSecureTextField，不登记普通文本框几何或发送秘密内容。
信息库用途固定为“搜索信息”，可见 hint 仍显示当前范围，不将用户目录名称作为通道用途。

给输入建立独立 Semantics container，避免空搜索框与整页标题合并。可见 hint 仍可以在
空字段时附于用途后；有值后用途保持，不能把整页文字包含关键词当作输入框通过。
目录／模板等外置装饰性标题排重；未改变版式、存储、授权或 Agent 协议。

真实原生中间轮发现隐藏 IndexedStack 页面仍保留布局和字段注册，近似／重复矩形导致
原生唯一匹配失败或整批被拒绝。保留此失败后，使用固定 SDK 的公开 Visibility.of，
订阅所有祖先可见性，隐藏页面不提交描述，切换时即使复用 const 字段也刷新。
没有通过放宽原生唯一匹配规则来掩盖问题。

最终同一公共控件／普通应用流程回归在独立 ec7f91f 产品源码上4项失败（Mac/Windows
widget 模式各2项），准确定位缺少 hint-only 用途与输入合并整页。新可见性回归在
4735a1d 上3通过/1失败，显示应只有请求、实际请求和历史都提交；修正后可切换、隐藏、
恢复和 index=null，字段 State 保持。最终相关18项通过、严格分析/格式通过。
Windows 模式未冒充 Windows 原生运行。初始编译缺 import、验证器文案错误以及中间失败
日志保留，与产品失败和最终通过分开。
