# Issue #5：审批时调整范围与有效期

关联 [Issue #5](https://github.com/ShiJiJS/agent-info-manage/issues/5)。本票在手动资料库上实现取消、补选和改选，不依赖目录或字段模板。原申请范围保留，最终批准保存明确的信息项和字段 ID 集合；授权不使用动态查询。文本说明作为普通受控字段选择。

桌面以信息项名称及字段名称同时显示“Agent 申请范围”和“最终选择”。用户可以从当前资料库的其他信息项选择字段，并在批准前输入本次授权的分钟数：默认 480 分钟（8 小时），接受 1–10080 分钟。到期时间从实际批准时刻计算；领取及读取均不延长。该输入只影响当前审批，不修改默认值或既有授权。

只有进程内的 `OwnerAccess.approve` 接受最终范围及有效期，普通 Agent HTTP/CLI 接口没有对应管理操作。批准同步地检查请求仍待处理、全部最终字段仍存在、范围非空且最多 200 字段、时长有效，再一次完成授权和状态转换。无效范围返回 `invalid_scope`、无效时长返回 `invalid_duration`，请求保持待审批；已处理、过期或取消返回 `invalid_request`。重复处理不能替换 token、范围或到期时间。

CLI `claim` 返回实际批准 `fields`、固定 `expiresAt` 和新增内容需另行申请的 `scopeNotice`，不输出 token。最初申请的字段若被取消或替换，读取会被拒绝；后来新增的信息项或字段也不会自动加入。修正同一字段的值后，已授权读取仍得到当前值。
