## 实际中断和回滚

虚构附件，共83,886,080字节。源库等待设置23分钟，独立目标空库17分钟；
均为专属临时目录内的SQLCipher及当前用户DPAPI，关闭通知，不使用真实资料。

实际Release通过两个系统Open对话框选择备份和恢复密钥文件，核对预览并点击
确认。监测只针对本脚本Popen子进程：原目标数据库270,336字节，观察到增长至
4,734,976字节，同时新回滚日志42,496字节、结构头非零，才故意中断该子进程。
进程退出1、日志仍在；这是明确故障注入，不是普通退出的强杀兜底。

在SDK仓储打开前，以SQLCipher原始连接读取目标，触发热日志恢复：integrity_check
为ok、journal_mode为delete，信息/附件版本/附件字节/文件字段/暂存/活动授权/交付
均为0，原17分钟设置保持。源备份、恢复密钥文件和目标DPAPI文件哈希保持。
原程序重启后独立CLI的旧会话返回unauthorized，没有恢复有效权限。
