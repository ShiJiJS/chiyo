## 路径与状态

设置→应用运行显示本机服务、临时凭据材料、普通附件维护、关闭窗口继续运行、关闭窗口和完全退出。冷读取/失败不显示为服务可用；保留旧观察但禁用写入，提供状态及关闭方式的各自重读入口。服务不可用时可以查看已登记观察，核查按钮禁用并说明原因；不能借“重试”启动另一个服务。

关闭方式通过同一WorkspaceSettingsSource保存，会话内重读一致，失败保留选择、未知只核对原设置操作。其他设置还有未保存草稿时，不随后台开关静默一起保存。开启后台运行且菜单栏可用时，“关闭窗口”只改变合成窗口状态，授权期限保持；菜单栏不可用时保留可见窗口并说明。关闭后台选项后，“关闭窗口”先打开同一完全退出确认，取消不结束授权。菜单栏入口丢失时已收起状态回到可见，不制造找不到窗口的状态。当前真实预览窗口始终由原生预览边界管理，仍可正常关闭和⌘Q。

临时凭据材料窗口按每页5项显示原计划、时间、执行结果、进程组结束观察和清理状态，能够跳到准确原申请。执行未知不等于进程结束，清理完成也不把未知执行变成成功退出码。核查只处理本机已登记、身份确认结束且仍需清理的文件材料，活动/未确认项保留；身份失败保留状态和明确重试。核查不重跑命令、不给旧执行第二次启动机会、不终止外部进程、不延长或重建授权。来自备份的执行只有历史事实，不进入本机材料维护。

普通附件维护显示准确资料/文件版本、已登记副本期限、保留/待回收/登记释放及原因，并可到原申请。副本期限与授权期限分开；副本到期不冒充整个grant结束。许可仍有效的副本保留，撤销/到期/范围失效后的登记才可核查回收；身份失败保留登记，明确重试。当前原文、保留版本和资料不因副本核查被删除；登记路径移除不承诺收回已读取内容。尚有副本待回收的请求受审计保留保护，不能先删除其原申请关联。

## 完全退出与部分失败

退出前只读核对准确会话/有效授权/待处理申请数量、仍登记的材料/副本以及未确认结束的外部执行数量。外部执行计数包括环境变量和文件两种凭据使用，不仅统计文件材料。检查token绑定来源epoch、完整资料变化观察及运行版本；期间有新请求、观察、偏好或资料变化就撤去旧确认，重新核对后才能提交。准备等待可取消，取消后晚到结果释放，不能重新弹出或提交旧范围。

确认后分别保留以下结果：

- 提交前确定保存失败：数据和授权尚未变化，保留确认/选择，可以明确重试。
- 退出审计保存未完成：按既有生命周期顺序先拒绝新能力、结束授权；资料库保持打开，窗口保留，重新核对后重试保存。不能说授权仍有效，也不能通过“继续运行”复活它们。
- 事实已保存、服务已停止但应用进程退出失败：进入已停服务状态，下一次只重试应用退出，不重做保存、结束会话或核查。
- 完成：退出事实已保存、服务停止、会话结束；未确认进程与使用中的材料保持独立状态，不宣告它们已全部结束或回收。

结果未知时保留原操作，锁定提交、关闭、Escape、设置换页和根级/原生导航，只查询原operationId。错意图/错退出范围或查询失败保持未知；确认未提交后才允许Owner明确新操作。已知的保存/进程退出失败是原尝试的事实，不是“全部退出成功”；原回执独立于后续尝试保留。同一旧命令在恢复预览后重放只返回旧回执，不能结束新的会话。

退出后的特殊页面只属于预览组合入口：不调用实际terminate，保留当前渲染器，明确说明合成结果，并可“恢复预览运行”。期间禁止进入仍依赖资料库的普通页面；保存未完成时只留运行页重试。恢复预览创建新合成会话身份，旧授权仍结束，需要重新申请批准。它不是正式产品的后台重启接口，不改变真实⌘Q行为。

## 数据与操作合同

| 接口/对象 | 内容与边界 |
| --- | --- |
| `WorkspaceRuntimeStatus` / `status()` | 观察版本、运行/保存失败/退出失败/已停阶段、服务/菜单栏可用性、合成窗口状态、本机材料与副本登记元数据；无PID、路径、秘密、输出或句柄 |
| `WorkspaceCopyMaintenance` | 登记ID、原requestId、类型化资料身份、准确文件版本、独立副本期限和清理观察；不是领取凭据或可使用路径 |
| `previewQuit()` / `releaseQuit()` | 只读数量及准确确认token；取消只释放计数视图，不持有正文、文件或运行能力 |
| `WorkspaceRuntimeChange` / `change()` | 核查材料、核查附件、收起/重新打开、确认退出、仅重试应用退出；完整摘要绑定operationId、动作、观察版本、退出token |
| `WorkspaceRuntimeReceipt` / `receipt()` | 原尝试的版本/阶段、窗口状态、核查释放/保留计数或原退出范围；null仅确认未提交，查不到可信结果必须抛错 |

SampleWorkspaceRuntime集中维护合成运行登记，材料来自同一审批执行事实，普通副本在组合入口已批准的准确文件范围内准备。没有新实现Agent领取动作，也没有真实副本。这些临时运行登记和可用能力不进入便携备份，恢复清空本机归属；既有授权/执行历史仍按原备份规则保留。正式适配必须复用已有核心file delivery历史和备份，不得把这份内存登记当作其持久化替代。
