## GH成功场景的约束核对

现有Mac证据包括真实GH2.102.0的无效合成Token→GitHub HTTP401，以及AWS/SSH的受控
成功/错误秘密。不能把HTTP401称为成功登录。生产gh_token配置固定GH_HOST=github.com，
禁止自定hostname、绝对API endpoint和认证/Host头；见
`packages/info_core/lib/credential_runtime_access.dart`的_validateTokenReceiver。

本轮核对[官方2.102.0 HTTP客户端源码](https://github.com/cli/cli/blob/v2.102.0/api/http_client.go)：
认证按实际目标主机取token，跨主机重定向不再加初始认证头。不能用本机无认证200响应
冒充真实GitHub账号成功，也不为合成接收器测试放宽上述生产约束。真实GH账号正向验收
尚需明确的专用测试凭据和用户操作条件；本轮没有读取个人登录或创建新Token。
