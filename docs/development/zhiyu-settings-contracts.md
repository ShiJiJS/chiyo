## 入口、数据和操作

主导航“设置”进入 `WorkspaceSettingsPage`，共用侧栏依次为外观、通知、请求与记录、插件、目录与标签、备份与恢复、应用运行、Agent 接入；旧版模板仍由插件侧栏进入。设置页持有组合入口注入的控制器，页面不读个人配置、数据库、原始路径或 CLI。`preview_main.dart` / `PreviewWorkspace` 是集中合成来源的组装点；`ZhiyuApp` 和各功能页不判断逐页 `isMock`，正式适配以后在组装入口换实现。

偏好不是八页各自保存一份：主题、通知、等待、保留和后台方式共享一个版本化来源，保存其他项时不得覆盖未改字段。待保存或冲突草稿保留，后台开关不能顺手保存其他页未确认的选择。切页和重新创建设置页后读取同一已保存状态；完整资料样本/空库恢复是组成入口，不是生产清库命令。

目录、标签、申请、授权、历史、材料和普通副本使用同一来源的实际身份与状态。资料和凭据分类数分别投影后汇总，不为设置复制另一套记录；公开目录与信息目录仍是不同概念。主机/插件属于 U04 的界面和合同；本票只核对在共用设置中的入口、状态保持和准确对象导航，不把 U04 后台作为前置。

## 等待、空数据、失败和恢复

| 路径 | 等待 / 空数据 | 确定失败 / 冲突 | 结果未知与取消 |
| --- | --- | --- | --- |
| 偏好保存 | 冷读取不把未确认提醒显示成关闭；已读配置刷新保留旧观察并禁用旧决定 | 失败保留选择；外部版本变化不自动换基，明确采用已保存值后再操作 | 写未知冻结关闭/设置和根级导航，只查原 `receipt`；只读失败可重试，不套未知写入锁 |
| 通知 / 保留预览 | 空提醒无目的地；0 条清理也需明确确认；读取中不可确认 | 读失败重试；准确历史/版本变化要求重新预览 | 取消读取可释放模态；旧预览/错误不覆盖后来观察；未确认不清理 |
| 分类列表 / 编辑 | 元数据列表与空分类可重现；200% 标题和当页列表一起滚动 | 失败保稿；标签删除按完整成员版本重检，不能凭同数量或同名替代；缺失上级要求明确重新选 | 写未知锁住编辑/根级导航，仅原分类回执解锁；重置使未提交准备取消，不重写已提交回执 |
| 备份状态 / 导出 / 恢复 | 未读状态不称空库；空视图不等于严格空库；取消文件选择不提交 | 密钥错误、归档损坏/新版、原文缺失、输出冲突、目标或资源变化均保留选择并拒绝写；明确失败没有部分发布/恢复 | 原操作回执核对完整资源/数量；写未知不重放；取消检查释放租约，恢复已成功但清理失败分别显示，可重试清理 |
| 运行 / 维护 / 退出 | 无登记材料明确为空；服务/菜单栏未知不冒充就绪 | 活跃/未确认进程与活动副本保留；保存失败保留资料/窗口但不复活已结束能力，退出失败只重试退出 | 退出 token 绑定准确观察；取消不结束授权；写未知只查原操作，不以路径消失推断进程结束 |
| Agent 总览 / 详情 | 冷读取不显示已连接；无关联/绑定不符不猜申请；新聊天零申请/授权 | 工具缺失、hook 未信任/定义变化、绑定失配、已结束均明确；诊断错指纹/摘要错绑定或计数拒绝 | 只读等待始终可关闭/Escape；旧成功/错误不覆盖新一代视图；读取失败可重试，不冻结为未知写入 |

所有写回执必须核对原操作身份、完整意图摘要、观察/结果版本及动作特有的准确结果；空回执明确未提交，查询失败不能解释为未提交并自动重放。确定未提交后仍需用户明确再次保存。无正文原操作事实与资料/文件内容分开保存，清理历史不误删当前内容，恢复历史不恢复活跃授权、待审批、运行进程或私密聊天能力。

模态计数、设置/分类/备份/运行的未决写入统一进入根级导航门禁，排队原生事件被丢弃；准确 UI 目的地在弹窗完全退出后执行。只读等待可取消，取消与写未知分别处理。预览模拟停止仍保留渲染器和正常 Cocoa 关闭/退出，不用强杀掩盖生命周期问题。

## 平台、视觉与导航核对

Mac 文案采用菜单栏、系统通知、后台运行和正常关闭；焦点填充明确当前不可用。设置与退出保留AppKit原生菜单的⌘,和⌘Q键位（MainMenu.xib），本轮只验证同一退出处理器及窗口关闭，不声称实际按键链路通过。通知说明 macOS 权限与专注模式的作用，但本预览不请求授权；应用运行界面不使用 Windows Job/盘符/托盘成功状态。现有包身份、正式资料容器、Keychain service/account、CLI/Skill/hooks 技术名称不因展示名改变。

r7 修正共享顶栏计数：原 20 像素高度在 200% 文字下小于实际约 38 像素行框；改为最小高度与内容自然高度，Center 按内容收缩，避免在普通字号下扩满导航行。100% 徽标仍 20 像素、顶栏仍 66 像素；四位/两位计数在两个视口、明暗、100%/200% 均完整且各目的地可达。1440 明亮普通文字的 8 组顶栏几何与旧 Mac r2 测量逐项差为 0，仅证明该局部未变，不外推整套 S5。

两条新的整票 Widget 路径从信息库主导航进入设置，实际经过全部八个侧栏入口，保存关闭提醒后换页/重新进入仍一致，不创建申请/授权或备份密钥。200% 使用侧栏真实滚动抵达尚未布局的入口；内容与侧栏各自滚动，不能把测试查找不到懒加载条目误当入口消失。页面仍使用原 R13 token、DesktopButton/Dialog/Entrance、滚动和焦点体系，没有改冻结原型、字号或动效门槛。
