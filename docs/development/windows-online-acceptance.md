本文件是检查范围。实际已通过/未通过及候选 SHA 见本次交付记录，不能用旧版本的通过数代替当前包。

## 当前候选需要覆盖

- manifest、App/CLI/worker/helper、全部模板引用、GH/AWS 完整载荷和许可同一提交；中文/空格路径解包及 SDK-free 运行。
- 正常入口打开本地加密库或连接 NAS，资料/目录/标签/关联、提案整份保存、申请/限定批准/读取、附件版本/另存/打开/PDF、凭据逐次操作、备份与独立空目标恢复。
- Windows 本地库的 DPAPI 密钥及私有 ACL、重开和缺失密钥时保留原库；本地/服务器模式的申请、提案和历史路由、双向同步及冲突保留。正式本地 CLI 接入、批准和读取，以及退出重开后旧会话拒绝。
- 断线、响应丢失、文件占用和重开只核对原操作；授权不续期，结束/撤销/到期拒绝新访问，不重放未知执行或覆盖已保存文件。
- App 关窗、托盘、通知原申请路由、模态期间导航、完全退出及重试；本地模式退出关闭本机服务，NAS 独立运行。唤醒后恢复连接并检查固定服务器身份。
- 真实窗口中文输入、保存/取消和高 DPI；实际通过范围分别记录，自动控件/通道检查不能替代键鼠结果。Ctrl K 已按用户要求移至后续 #117，暂不作为本轮完成条件。

## 需要用户在场或明确授权

- 正式安装、更换现有 NAS 运行版本、全局 hooks/Skill 安装及准确 hook 信任定义，按当次授权执行。
- 真实 Codex 宿主的两个聊天、主子身份、压缩/恢复保留引用及结束事件；受控 hook 载荷不冒充真实宿主已经发事件。
