# 目录、标签与公开目录（Issue #9）

本任务在加密资料库上加入目录层级、标签、已审阅公开说明和公开元数据检索。业务通过核心服务公开接口测试；CLI 仍只连接 agent 接口，不获得资料库或所有者管理能力。

## 所有者操作

“我的信息 → 目录与标签”支持新建、重命名目录与标签，以及调整目录上级。目录不能移动到自身或其下级。信息展开后可以“整理位置和标签”；浏览筛选包含所选目录的全部下级，并可以同时筛选标签。

“编辑公开说明”允许修改信息公开名称、公开描述及各字段的公开说明。编辑中的草稿不会发布，取消后不变；只有保存成功才更新 agent 目录。此入口不修改字段名称或值，改变字段的业务含义应新建信息并重新申请授权，避免复用旧身份。字段值与受控文本说明始终不进入公开搜索材料。

目录名称和标签名称仅用于本人整理，不加入公开目录或其检索文本。agent 可以获得信息项所属目录及标签的必要不透明标识，并据此筛选。目录和标签不表示权限范围，任何移动或标记都不改变已有授权。所有者的 `fieldsInDirectory(id)` 仅返回当时目录及下级内的明确字段标识快照。

## CLI

标准输入逐行 JSON，支持以下可组合选项；无需内容授权即可查询：

```json
{"command":"catalog","query":"公开名称或说明","limit":20,"offset":0}
{"command":"catalog","directoryId":"目录标识","tagId":"标签标识","limit":10}
```

结果包含 `status`、`items`、匹配总数 `total`、当前 `offset` 和下一页 `nextOffset`。最后一页 `nextOffset` 为 `null`；用它继续相同筛选。默认每页 20，`limit` 为 1–100，`offset` 为 0–1000000，查询字符串至多 200 字符，目录与标签标识至多 200 字符。无效类型或越界输入返回 `invalid_request`。目录筛选包含下级目录，未知标识得到空结果。

搜索仅对已保存的公开名称、描述、字段名称和字段说明进行不区分大小写的文字包含匹配。结果不包含搜索片段、字段值、内部资料、历史值、录入提案或目录/标签名称。分页是当前资料的偏移分页；编辑资料后可重新从第一页开始，分页本身不代表固定快照。

发现字段后仍按通用 CLI 的 `session → request → claim → read` 流程申请和读取。搜索与组织不签发授权。

## 加密保存和兼容

目录及标签具有独立稳定标识和递增版本，信息移动/标签变化递增信息版本并保留信息和字段标识。字段公开说明变化递增该字段和信息版本；普通值修正继续保留目录与标签。目录、标签、归属、公开说明与字段值一起保存在 SQLCipher 数据库，不建立外部明文索引。

组织迁移位于 schema 3，合并字段模板任务后当前数据库为 schema 4；旧版本分别按 `from < 3` 和 `from < 4` 增量迁移。继续保留早期资料、稳定身份、版本和待审批时长设置；字段公开说明编辑保留结构化/文本说明类型。该版本是开发版本，ADR 0004 的跨平台、升级和独立恢复验收要求保持开放。
