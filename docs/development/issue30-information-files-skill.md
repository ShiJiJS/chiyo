## 本次交付

随包 Skill 根据目录字段的 `kind:file` 进入[普通文件流程](../../integrations/codex/skills/agent-info-access/references/information-files.md)：协商能力，提交包含文字/文件的普通申请，查看主人最终批准范围，再以独立 operationId 执行 `file-fetch`。领取结果包含实际受管路径；同机文档/浏览器工具使用完并关闭读取后，以 deliveryId 执行 `file-release`。`file-status` 只返回事实，不补发路径；响应丢失先查原操作，同 ID 重试保持原附件版本，新逻辑操作才领取当前版本。

普通文件原文允许 Agent 阅读；Token/私钥等凭据仍通过命令注入或本机焦点填充使用。说明明确原文件名与安全路径名可能不同、远端工具不一定能读取本机路径、选择文件不等于网站上传成功，以及 Agent 录入/更新提案不能提交文件原字节。已删除“普通附件尚未实现”的当前说明，并更新 ADR0011 的实施状态；历史记录保留其提交当时范围。

源码生成器、SDK-free 生成器和 Windows 打包脚本均携带新的文件说明，解包校验增加对应完整性要求。生成器仍输出到新稳定目录，保持实际可执行文件路径，拒绝覆盖已有目录。这里只验证生成材料，没有安装到用户 Codex，也没有生成或替换最终 Windows ZIP。
