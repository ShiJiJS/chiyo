# Mac Agent 接入设置：实现与合同

本轮在独立 `codex/zhiyu-macos` 分支完成 U07 r6。源码 `528524079d1ec0fc4c55678d702045cb31bebece`，属于正式 Flutter 组件和只读控制器接通的合成前端；没有安装 CLI/Skill/hooks、修改信任、创建真实聊天或访问个人配置。#68 保持 OPEN、0/8，待整票合同和 S5 核对；#69 仍等待全部七项 UI。

## 用户路径与状态

设置侧栏 → Agent 接入 → 重新检测 / 接入诊断 / 当前聊天 / 接入流程 / 录入约定。准确申请入口先关闭弹窗、释放根级模态锁，再进入同一审批来源的原 requestId；打开不批准、不创建申请或授权。当前聊天每页 5 条，分页保留准确身份，关联变化撤掉旧列表并返回第一页。

连接观察分四层：本机服务是否接收申请、CLI/Skill 是否就绪、三个事件的 hook 定义是否已核对并信任、当前聊天是否有可核对绑定。只有四层同时满足才显示已连接。授权数量来自同一审批事实，连接本身不等于许可；Mac 焦点填充始终显示当前不可用。冷加载和失败不显示未经确认的连接成功；已读但正在更新/失败时，旧徽标明确标为上次观察。

接入流程明确材料准备、安装/启用、准确命令审查与宿主正式信任是不同动作。只读诊断展示 SessionStart / SubagentStart / SessionEnd、命令、匹配范围、超时及定义核对状态；初始合成命令只是不存在的字符串，不执行、不探测该路径。缺工具/缺 hooks/待信任/命令变化/无关联/绑定不符/已结束/新聊天及三类读取失败都有组成入口，可重置；这些入口不进入正式服务 API。

接入约定复用已有资料和模板、按保留用途选目录与查找习惯选标签、依据来源关联、不猜身份。标签默认可见不授予内容访问或分类写入；模板安装与资料提案确认分别决定，普通附件和托管凭据分别处理。没有信任、执行、复制私密值或启用焦点填充按钮。

## 读取端口与不变量

| 数据 / 操作 | 页面使用 | 必须满足 |
| --- | --- | --- |
| `WorkspaceAgentsSource.read()` | 总览 | 正版本、稳定观察时间、服务原因、CLI/Skill、三类 hooks、公开聊天元数据与同源计数 |
| `diagnose(expectedVersion)` | 接入诊断 | 只读；返回同版本同指纹完整观察；陈旧/不一致返回 `observation_changed` |
| `currentSession(expectedVersion)` | 当前聊天 | 同版本、同指纹、同公开绑定、唯一准确 requestId；总数/待处理/有效授权计数与摘要一致 |
| `changes` | 当前观察刷新 | 立即撤销旧详情；获取新总览后刷新仍打开的动态弹窗；旧成功/错误不可覆盖新观察 |
| 接入步骤 / 录入约定 | 静态只读说明 | 总览读取失败仍可打开和关闭；不要求服务在线，也不调用安装器 |

指纹绑定版本、观察时间、服务可用性及原因、CLI/Skill 状态、每条 hook 完整观察和聊天公开计数。真实适配必须提供同一次一致快照，不能每次读取都换观察时间，也不能用前端合成 revision 冒充实际宿主协议。

一条 hook 要核对准确事件、完整命令、正超时和定义身份/对应信任。缺少任一必需事件不能就绪；重复或未知事件使观察无效。空命令/定义/非正超时、未信任或定义变化明确不可用/待审查/已变更；同文件名不是信任证明。真实定义身份必须绑定宿主实际信任的完整定义，不可根据 basename 或公开标签推断。

公开聊天 ID、名称、自述用途只用于观察/展示，不作为鉴权证明。读取端口不暴露私密关联、认证文件、仅撤销凭据、聊天原文或配置文件。关联缺失或绑定不符时不返回同名/父聊天/公开 ID 猜出的申请。已结束聊天可查看原申请的结束状态，但不能继续授权或恢复旧能力。新聊天仅由明确的合成组成入口建立，开始为零申请、零授权；新请求和批准仍走既有同源流程。

根结束来自同一审批会话状态；窗口收起、重新检测、重启预览、压缩/恢复聊天均不延长期限或复活旧授权。备份不导出关联或本机信任；恢复只清除聊天关联，保留本机 CLI/Skill/hook 观察，尤其不得把变化后未信任的命令重置为已信任。整套样本的显式 reset 才恢复初始合成环境。

## 等待、失败与取消

页面只读，不存在写操作回执或未知提交锁。读取的 `unknown_outcome` 归为可重试的不可用，不伪造成功，也不无限冻结导航。诊断和当前聊天有独立错误、重新检测及关闭；重新检测先获取已确认总览，再要求匹配详情。读取期间可关闭/按 Escape；晚到结果、错误和 busy 结束只能更新原一代视图，同模式关闭再打开也不能被旧读取覆盖。来源刷新撤掉旧详情，避免沿旧 requestId 跳转。静态说明不因服务失败消失。

模态期间复用根级导航门禁；弹窗退出后才执行准确申请导航。普通观察加载不额外阻止主导航。不是写操作，因此不套用不可取消的未知提交状态。

## 检查、视觉与边界

20 项新增检查：15 项来源/模型/控制器、5 条 Widget 入口路径。覆盖无写副作用、三事件/定义信任、公开 ID 不猜绑定、同源批准/根结束、服务恢复不重连、明确新聊天、恢复保留本机未信任状态、陈旧版本/摘要计数、错指纹/绑定、异步关闭重开及读取失败重试。组成隔离守卫增加诊断与绑定不符的当前聊天读取，生产通道、HTTP 和越界文件访问均必须为零。

最终命令、检查和图片见 [r6 检查点](evidence/zhiyu-round09/u07/macos/r6/checkpoint.json)。1440×900 明亮与 1280×800 黑暗 200% 的 11 张本机字体 Flutter Widget 图已直接查看，覆盖总览、准确申请、命令变化、失败、说明、工具缺失、绑定不符、结束，以及长诊断滚动到 SessionEnd。标题和底部动作固定、正文独立滚动，200% 行尾动作下移；复用 R13 设置行、语义色、DesktopButton/Dialog/Entrance 与原导航/浮层/按钮动效，不另建图标/控件系统。说明改用中文文件入口，保留必要 hook 事件和命令用于审查。

未作独立子 Agent 评审；用户排除子 Agent 和 computer use。没有新的 Cocoa 实机运行、真实输入法/触控板/系统菜单交互、正常速度录屏或完整 S5 结论；既有 200% 顶栏徽标裁切继续开放。构建和 Widget 图不能替代这些门槛。固定一个 App，不复制 bundle/dSYM，未知 `.local/` 不动。继续 U07 整票交接与所有 UI 的剩余界面问题，不以本检查点宣告产品完成。

## F01 真实接入

复用既有 `info_cli` 的 prepare_codex / codex_bundle / codex_hook、ADR0002 和 ADR0005；不新造自动信任能力。准备工具在新的稳定目录发布材料，本身不安装个人 Skill、合并宿主设置或信任命令。实际宿主信任必须走官方入口，绑定最后稳定路径与准确命令/范围/超时。需要确实运行后才报告真实工具和信任状态；当前合成观察不是宿主状态探测器。

SessionStart 的私密聊天绑定、SubagentStart 的主会话已持有证明委托、SessionEnd 的仅撤销索引分别鉴权。复用既有真实验证边界：压缩/恢复不自动重连、子任务结束不误结束根会话、公开聊天 ID 不是读取凭据。正式总览与申请计数取可信且最小的元数据，不把日志/配置/私密关联透传页面；未知宿主能力返回不可核对。恢复、版本变更和最终交付须在隔离资料库及固定候选集中验证；UI 阶段不触发个人 Keychain、真实 hooks 或聊天。
