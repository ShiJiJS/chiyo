# 分类名称仅在用户限定的整理任务中向指定聊天开放

用户不希望长期维护分类，也明确同意 Agent 在本次整理任务中查看标题、公开说明和现有目录/标签名称。采用由用户选择参与聊天及固定资料范围的短期整理任务，而不将所有分类名称加入全局公开目录；任务不提供字段值，也不提供批准或直接改写能力。Agent 提交分类方案后，用户整批确认并校验版本，才原子调整分类与标签；信息、字段身份和内容授权保持原样。

任务最长 30 分钟，取消、会话结束、重启及方案提交结束其元数据访问能力。任务和待确认方案排除在备份之外。录入时的分类建议随用户确认一起原子应用，以减少逐项手动分类；保留用户在确认前调整例外的入口。
