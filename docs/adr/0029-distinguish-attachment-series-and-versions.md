# 文件系列与不可变原文分别识别

#131 的离线冲突中，两端可能各自产生“第 2 版”。不能把文件系列及递增编号当成这两份原文相同的证明，也不能在用户选择后覆盖另一端原有字节。后续每批新增原文取得独立引用，另存稳定的附件系列归属；界面编号继续表达修订顺序，历史、保留和同步按系列组织原文，精确读取仍使用不可变引用。

保留原来按系列和编号保存的旧引用，不重命名已有原文。新元数据使用内容格式 23，让旧读取器明确拒绝；本机格式 60 同时记住之前的可选存储能力，避免仅替换文件就假定本机已经创建服务器或同步表。代价是版本清单需要按明确的系列归属查询，新增文件时多保存一个归属标识；它避免改写原引用及其授权历史。信息项和凭据自身的冲突版本也需要独立保护，本决定不表示那些处理已经完成。
