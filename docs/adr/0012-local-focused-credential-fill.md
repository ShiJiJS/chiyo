# 以本机焦点填充覆盖有真实输入焦点的凭据使用

2026-10-18 accepted（2026-10-19 Windows范围已实现并验证，#35）。用户希望正常使用时秘密不进入模型上下文，并优先减少对不同浏览器工具的适配，选择先支持本机交互桌面的焦点填充：先批准、Agent点击密码框、CLI提交凭据引用、本机宿主发送输入。暂不选择逐工具浏览器插件或远程浏览器接入作为首轮必需方案。

此决策扩展ADR0008对浏览器填充的排除项；不提供对恶意Agent或同用户进程的强隔离。假密码实测只证明当前可见内置浏览器接收输入、正常工具读取脱敏；显示明文后的截图仍泄漏。输入不经过普通剪贴板或命令明文，目标变化/不可核验时拒绝，未知不重填；不能承诺所有第三方采集或模型服务载荷不含秘密。详见[当前设计](../design/local-focused-fill-contract.md)。

2026-10-19细化见[填充合同](../design/local-focused-fill-contract.md)：以应用身份固定允许范围，每次捕获实际前台密码控件；网站自述不构成来源核验，SendInput不提供HWND原子定向保证。填充与命令共享授权概念但使用独立结果类型；只读识别检查点不代表正式能力已接通。

2026-10-19实施状态见[Windows完成记录](https://github.com/ShiJiJS/chiyo/issues/35)：真实加密宿主/界面、独立CLI和原生端已验证，支持记录限于一个Win32密码控件和当前可见内置浏览器合成页面。DOM聚焦不等于系统前台，工具不能激活应用时需所有者切回，重新发现ready再填充。当前工具正常遮挡与显示明文截图的泄漏反例均保留；没有扩大为通用浏览器来源证明或通用脱敏承诺。SDK辅助功能失败另以最小探针对照定位，未关闭生产辅助功能；最终分发和真实Codex联合验收分别归#18/#30，用户旧包未更新。原决策不变。
