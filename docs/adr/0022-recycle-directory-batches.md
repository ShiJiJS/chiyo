# 目录及内容一起回收、一起恢复

2026-11-07，按 #85 的用户确认，选中的目录连同子目录、资料和凭据作为一批回收，并保留原目录层级供整体恢复。确认范围与实际提交之间若出现新增、移动或修改，必须重新核对；一次操作的目录、内容、历史事实和回执一起保存，不能以逐条删除代替整批事务。这替代 ADR0014 中新目录操作“只允许删空目录”的限制，但不改变旧的空目录删除记录和单条回收记录的含义。

整批恢复只恢复该批实际回收的目录身份及内容，不跟随关联复活其他已删除资料；同级重名或原上级不存在时，需由用户明确更改恢复名称或位置，不合并进同名目录。恢复前展示完整路径和变化。普通资料使用新的字段身份，凭据保持停用并更换材料版本和使用代次，旧授权不恢复。原目录、字段和内容历史保持只读；普通附件沿用现有版本及保留规则，不额外复制原字节。

回收批次只存目录和资料说明、正常回收项及凭据修订的引用，不另存正文或密码。为了让旧程序拒绝而非忽略这批信息，只有实际保存目录回收批次时才提高资料库标记到50；含批次的完整备份使用格式20，旧库和不含批次的备份仍沿用原格式。新增格式支持加密保存、重开和完整备份恢复，不移植机器上的操作回执或可用授权。App 的整批确认、分组回收站和恢复位置调整已接入；仍需与 #87 核对手动顺序并统一整包验收，本记录不表示 #85 已完成。
