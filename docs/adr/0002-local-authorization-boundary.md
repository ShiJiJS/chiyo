# 第一版采用加密存储和应用层授权，不要求限制 agent 的运行环境

用户需要通用 CLI 接入，不希望为了使用信息管理软件而限制 agent 的运行环境。第一版以加密存储、保护密钥和用户审批入口、限定范围的临时访问凭据及逐请求鉴权作为访问控制边界；不承诺抵御已控制本机或窃取有效凭据的攻击者。

访问凭据代表用户批准的范围，不是全库解密密钥。Codex 会话 ID 只用于关联，不能单独作为鉴权凭据。正常收到会话结束事件时撤销授权，默认最长有效期为 8 小时，用户批准时可调整并可随时手动撤销。此选择保留普通 agent 的使用体验，但不提供同一操作系统用户下各进程之间的强隔离保证。

第一版不设置应用主密码或密码解锁流程，用户打开客户端即可使用；数据库加密密钥由应用自动管理。此选择减少日常操作负担，因此不能依赖一个用户另行输入的秘密来保护运行中的应用；具体系统密钥保管和备份恢复机制需要另行设计。主密码和应用锁留待后续考虑。
