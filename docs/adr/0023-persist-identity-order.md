# 排列顺序按身份保存，与移动一起提交

2026-11-07，按#87保存同级目录及资料／凭据的手动顺序；以前／后面的对象身份作为位置，核心读取完整同级内容处理，不能把搜索或分页结果当成完整目录重排。复用#86的移动事务和回执，仅排序不更换资料字段、凭据材料或可用授权。旧资料没有顺序时沿用稳定的持久行顺序；新增身份排在已保存身份之后，不为读取而写库。

采用仅含身份的独立排列快照，不把顺序塞入正文修订或凭据材料版本。已回收身份的位置暂时保留，当前目录和资料仍只来自实际资料库；这些编号不能复活内容。整批回收前把尚未记录的位置一并保存，恢复原位置时沿用编号顺序；明确改到其他上级的恢复内容追加到该位置的现有同级之后。旧回收记录没有保存过手动顺序时只使用已有事实，不猜历史排列。

排列、归属和操作回执一起保存或回滚；保存前检查实际数据库的排列状态。真正写入排列后资料库最低标记为51，含排列的完整备份为21，避免旧程序忽略顺序。旧的1—20备份继续可读；恢复旧备份会清除接收库仅剩的旧排列偏好，不混入本机旧编号。此决策为ADR0022增加顺序保存，不改变整批回收、恢复及授权失效的规则。
