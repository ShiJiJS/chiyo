# 本机副本看护只保留清理能力

联网文件的本机执行程序在CLI退出后仍需处理到期、撤销、聊天结束和崩溃恢复。实现采用每份交付独立、绑定原设备的副本清理凭证，后台看护用它核对保留状态和确认清理；领取和返回原文路径仍须原聊天的正常读取证明。代价是增加狭窄的状态/清理接口，而不是长期保存可读会话证明，或依赖用户下次打开App才清理。

本机私有登记可保存清理证明和实际生成副本的身份，不保存可读会话证明。清理证明不进入普通输出、目录、历史或便携备份；Codex结束索引继续只含结束能力，不能按公开聊天ID恢复关联或读取能力。服务端只有在本机确认物理清理后才结束待清理状态；执行程序崩溃时由下次本机维护核对并清理已登记副本，不把丢失状态当作已清理。
