# 逐次调用适配器共享应用内的CLI执行器

Codex适配器每次只处理一条输入后退出，直接把任务和输出交给该进程会过早关闭HTTP客户端，并使下一次调用无法读取上一进程的内存输出。因此由本机应用托管复用CLI实现的执行器，Codex通过同一私密会话提交/查询固定启动计划；执行器保持最多16项执行及各自有界内存输出，原始通用JSON-lines CLI继续支持自身持有执行，不引入按公开聊天ID找回能力的机制。

这扩展ADR0008的执行归属，不改变一次性消耗、凭据版本/固定计划或撤销不终止已运行进程的含义。应用只启动随包的CLI worker，worker在Windows进程组内启动获批程序；应用退出后程序可继续，重开按已登记身份核查。活动能力、受管路径和输出不进入历史或备份。没有持续宿主时明确失败，不在状态未知时回退到另一条启动路径。
