# 凭据授权在有效期内复用，单次操作独立防重放

2026-10-18 accepted（Windows实现于2026-10-19完成，#33）。用户需要同一个凭据连续完成多步任务，决定取消整个授权“一次启动即消耗”的限制；授权绑定会话、凭据版本、接收配置和固定期限，每次命令/填充各自冻结并记录操作。复用不续期、不返回秘密；同操作ID仍至多执行一次，结果未知先查不自动重放。

这替代ADR0008及ADR0009中的授权一次性部分；ADR0009的持续宿主、身份核查、进程组与文件清理仍有效。现有协议v1和已交付程序的单次行为保持历史事实，不能把旧证明自动升级；目标细节见[当前设计](../design/windows-credential-and-file-update.md)。

2026-10-19实施状态：[Windows功能验收](../development/issue33-completion.md)完成。此处决定本身未改变；焦点填充沿用同一授权模型，但具体操作及支持范围仍由#35实施，普通附件由#37/#38实施。


2026-11-07，#89增加SSH的会话内不限时选择：用户可批准v2 `ssh_identity` 在原聊天结束前复用，不设置固定截止；旧限时记录、其他接收方式和普通字段保留原规则。使用明确的 `credentialValidity: session` 及空截止表达，不使用极大的分钟数代替。固定凭据版本、接收方式、逐次操作检查与防重放不变；撤销、真实聊天结束、凭据变更／停用及主机信任变化阻止后续使用，服务重启不恢复许可。撤销不会终止已启动的程序或撤回远端结果，既有执行、连接和材料清理仍按各自生命周期处理。新持久事实以资料库52／备份22区分，避免旧程序把空截止误读成许可或丢弃其含义；该格式只在实际保存新事实时提高。Skill更新按本轮任务要求暂缓，不作为已完成内容。
