# 服务器重启后保留仍有效的聊天授权

2026-11-08，用户确认多设备服务普通重启或升级后，仍有效的授权继续使用，避免每次维护服务器都要求重新审批。这替代 [ADR0010](0010-reusable-credential-use-grants.md) 中“服务重启不恢复许可”对未来服务器模式的适用方式；现有单机版本行为不变，服务端功能尚未实现。

恢复使用仍须核对原聊天、设备身份、原批准范围、期限或聊天结束条件，以及撤销、凭据变更和停用等状态。重启不续期、不改变获批版本或使用方式，也不能恢复已结束的聊天或已撤销的授权；无法确认这些条件时不能直接放行。每次命令仍有独立操作身份，重连不能导致重复执行。

代价是服务器需要持久保管并核对有效授权及相关身份，不再只靠进程内状态。这不是允许把本机备份中的历史记录恢复成有效授权；迁移和备份恢复仍需分别处理。
