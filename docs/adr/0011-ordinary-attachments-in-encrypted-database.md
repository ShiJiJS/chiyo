# 普通附件原字节存入现有SQLCipher数据库

2026-10-18 accepted（待实现，#34）。用户预计文件较小，选择将简历等普通附件的元数据与原始二进制内容一起存入现有加密数据库，减少独立文件密钥、外部附件缺失及备份一致性的维护。正文以BLOB按需读取，附件是普通信息的可授权字段；凭据文件仍独立，不因附件授权暴露密钥。

初版不引入外部加密附件库或服务器同步。附件版本/回收、受管交付副本和包含原字节的完整加密备份须一起实现；导入不删除源文件，撤销不承诺收回已读取内容。扩展旧规格排除附件存储的范围，不自动承诺OCR或通用解析，详见[当前设计](../design/windows-credential-and-file-update.md)。
