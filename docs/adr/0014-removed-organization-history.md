# 分类删除保留历史引用，恢复时只使用现存分类

2026-10-21，#54/#55。目录只允许空删除，标签删除与当前信息关系清理原子提交；修订和回收原始快照保持只读，旧分类ID作为历史事实保留，恢复为当前信息时缺失目录归未分类、缺失标签跳过。这样保留历史原文与字段身份，也避免恢复操作意外复活已删除分类。

该状态不能由旧阅读器正确处理，因此资料库标记升为22（无新表），防止旧应用打开后按旧分类规则恢复。包含缺失分类历史引用的完整备份使用格式10、沿用格式9表结构和附件容器，只放宽历史快照的分类存在性校验；当前信息关系仍严格校验。无这类历史时继续按内容输出7/8/9，读取兼容1–10，旧阅读器拒绝10。恢复删除前的旧完整备份仍是明确的整库恢复，与回收或修订恢复不同。
