# 标签默认对Agent可见，不区分私人或公开

2026-11-07补充：目录默认可查，见 [ADR0021](0021-default-visible-directories.md)，替代下文不公开目录树的限制，不改变内容访问和写入审批。

2026-10-25用户明确要求标签默认都能看见。Round09的普通发现接口将提供全部当前标签的ID、名称及可发现资料上的标签归属，支持关键词/类型/标签查找，无逐标签可见性开关，也不要求先获整理权限；现有标签一并适用。这样用户无需额外维护分类的公开设置，Agent也能按与用户相同的标签查找资料。

本决定替代 ADR0006/0007 中的标签读取限制，不授予标签写入、正文读取、普通文件领取或凭据使用权限。目录另遵循 ADR0021，关系图不因本决定公开。授权后修改分类仍遵循现行提案/整理流程。

2026-11-11 文档核对：当前 Agent 目录查询已包含标签名称及归属，原分阶段计划不再作为实现状态来源。
