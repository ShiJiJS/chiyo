# 模板插件描述资料，安全能力继续由宿主负责

2026-10-25，知予Round09规划。拟采用声明式JSON模板包、宿主提供的有限布局与可选内置设置面板，不加载任意可执行第三方代码；这样Agent能为新资料类型生成模板，同时不把授权、凭据和文件执行边界移进插件。每项资料持有不可变模板快照，升级或移除插件不改写旧资料；重复条目按现有稳定叶字段身份授权，避免新增经历自动进入旧授权。

本决定作为当前前端预览的设计参考；真实插件能力及相关范围由F01在界面完成后核对并拆分，不能因前端票已批准就宣告插件后台已排期。它扩展旧表单模板语义，不替代ADR0001/0002/0003/0010/0011的稳定身份、本地授权、Flutter/Dart及加密存储边界。范围与权衡见[Round09规格](../specs/zhiyu-round09/README.md)。
