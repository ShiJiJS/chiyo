# 目录层级默认对接入的 Agent 可查

2026-11-07，按用户在 #83 中确认的要求，全部当前目录的名称、层级、完整路径、稳定身份及同级顺序默认可查，包括空目录；可发现资料和凭据的目录归属也随元数据提供。这样 Agent 能在录入前复用现有位置，不必让用户额外批准一次目录读取。

这替代 ADR0006、0007、0015 中目录树仅供已批准整理任务读取的限制，接受目录名称本身会向接入 Agent 披露的取舍。它不扩大正文、原文件和凭据内容访问，也不授予目录或分类写入；新目录随提案整体审批，整理写入继续遵循原有审批规则。

软件与 CLI 的查询入口由 #83 实现；Skill 修改和新会话自主使用验收按用户要求暂缓。此记录不表示整张 ticket 已完成。
