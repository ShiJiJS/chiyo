# 客户端采用 Flutter，本地核心服务与 CLI 采用 Dart

2026-10-16 确认：使用 Flutter 开发 Windows/macOS 客户端，以独立 Dart 业务模块实现本地核心服务，以 Dart 编写独立 CLI。用户熟悉 Vue、Spring Boot，但接受学习 Dart 与 Flutter，以便后续开发手机授权确认端和其他移动应用；相比 Electron + Vue，选择承担前期学习成本，换取桌面与手机使用同一客户端框架的可能性。相比 Tauri + Vue/Rust，本地业务优先统一为 Dart，避免同时学习两套新语言。

业务规则独立于 Flutter 页面，通过平台适配层接入存储、密钥保管、通知和本机通信。CLI 仅通过受控接口请求服务，不直接打开资料库、不持有全库解密密钥，也不因此取得审批能力；共享语言和协议模型不意味着共享权限。本地核心随桌面应用后台运行，具体 isolate 或进程划分、原生依赖和安装分发仍需验证。

未来云端优先考虑 Java + Spring Boot，利用已有服务端经验；这只是后续技术方向，不引入第一版服务器依赖。手机审批、同步及云端职责仍不在第一版范围内。数据库及加密库、通信协议、凭据保管、平台插件和两端打包尚未定稿或实测；本决策不改变 ADR 0001、0002 的授权及安全边界。

后续决策：数据库、数据访问层和加密方向已在 [ADR 0004](0004-encrypted-sqlite-storage.md) 确认；具体依赖和平台集成仍待验证。
