# 托管凭据经获批启动计划交付本机子进程

> 2026-10-18部分替代（目标待实现）：[ADR0010](0010-reusable-credential-use-grants.md)取消整个授权一次性消耗；[ADR0012](0012-local-focused-credential-fill.md)新增本机焦点填充范围。现有v1程序与旧验证事实不变；本文件的托管执行、身份/进程组和清理边界仍适用。

用户确认加入字符串/文件凭据与本机CLI运行时注入：凭据独立于普通信息字段，使用授权固定版本和启动计划，文件采用类型化引用而非任意shell字符串替换，普通字段授权不因此获得秘密读取能力。

CLI经私密会话校验后准备材料并启动获批进程，使用许可限一次启动尝试；代价是获批程序及同用户进程仍可能接触原文，本方案沿用ADR0002的无强进程隔离边界，不承诺秘密对任意程序不可见，也不包含远程代理或浏览器填充。

本决策扩展旧规格的凭据保管排除项，不改变普通字段固定成员/当前值或ADR0007的整理语义；细化规则与待实现范围见[实施契约](../design/runtime-implementation-contract.md)。
