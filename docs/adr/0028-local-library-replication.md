# 资料内容同步与本机授权分别保存

按 #130、#131 已确认的范围，本地库作为独立加密副本，用户可选择连接服务器同步。同步资料库身份与各端副本身份分开：资料、字段、版本、关联和目录等沿用原 ID，各端继续使用自己的数据库密钥、设备接入凭证和聊天授权。关闭同步只停止传输，不删除任何一端资料；恢复备份或选择另一资料库后先重新核对共同基准。

首次传输采用有版本的内容清单、完整性校验和分块文件传输。目标为空才可接收初次内容；已有同库身份按共同基准接续，不同库且双方非空则保留双方并提示使用备份或空目标。接收端先验证隔离暂存内容，完成后原子发布；不直接复制正在使用的数据库文件，也不以覆盖整库充当后续同步。

普通资料、文件所有保留版本、凭据材料、目录/标签/手动顺序、回收事实、插件模板及可保留的历史进入内容同步。界面偏好留在设备，活动聊天许可、待处理审批、进行中的凭据执行、临时明文文件和接入配置留在所属服务。历史记录在另一副本中只表示发生过的事实，不恢复可用许可。

后续变更使用持久同步进度和共同基准核对。每次已提交的关联变化在接收端保持整体可见，消息重试须返回原处理结果。双方分别修改或删改冲突时保留两份候选和原历史，其他不冲突内容继续；用户选择后形成新的同步版本。代价是需要额外保存同步进度和冲突候选，但避免按电脑时间静默覆盖、整库替换导致丢失及把历史授权误当作当前许可。实际协议、存储及界面完成情况以相应 tickets 的实现证据为准。
