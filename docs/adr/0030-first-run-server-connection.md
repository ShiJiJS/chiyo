# 首次使用与知予服务器连接

按 2026-11-12 用户确认的原型，首次打开提供本地使用和服务器同步；日常设置只管理连接，不重复显示首次引导。服务器连接由 IP/域名、端口及「知予连接密码」完成，替代 ADR0024 中让用户手动填写管理 Token 的方式。未初始化的服务设置一次密码，已有服务登录，已记住且有效的连接直接复用。

第一版仅面向用户信任的局域网。新部署自动生成持久 TLS 身份，客户端首次连接取得公开证书并记住，后续严格校验已有信任及服务器身份；不会自动接受换过的证书。首次信任依赖局域网和所填地址可靠，接受这一取舍以免用户复制证书。私钥和数据库密钥只留在服务器，不发送给客户端。

密码校验产生 App 管理连接所用的私有 Token，不向 AI 提供。原管理 Token 保留供已有部署和维护使用；修改连接密码使旧密码登录签发的连接失效，不改变数据库密钥、服务器身份或独立 Agent 接入。旧库第一次设置密码必须由原有管理连接证明身份，不能因更新版本而被未认证客户端认领。

密码仅保存带盐校验值；校验在独立计算任务执行，登录和状态查询不写库。服务器密码状态属于该服务器的私有运行配置，随停机副本备份，不进入资料同步或便携内容备份。丢失旧库密钥和证书时仍拒绝启动，不生成替代品打开原库。
