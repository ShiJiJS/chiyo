## Parent

[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

用户定义并应用字段模板来创建信息；扩展模板后新增字段仍需授权，原有资料及授权不会被静默改写。

关联规格用户故事：8、9、11、36、57。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 桌面可创建、修改并应用字段模板，支持结构化字段和文本说明；模板生成的资料经用户保存后进入信息库。
- [ ] 字段定义与信息字段身份保持清晰，新增模板字段不自动加入已有授权，也不复用旧字段身份表示不同含义。
- [ ] 明确模板变更对既有信息的影响，不静默覆盖现有内容；模板用于辅助录入而非权限等级。
- [ ] 模板及相关数据加密持久化，重启可用；CLI 仍按公开字段说明发现并申请读取。
- [ ] 核心接口验证模板录入、扩展及范围不扩大，并演示桌面创建模板到 CLI 获批读取；不依赖目录整理界面。
