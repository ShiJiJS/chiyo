## What to build

用虚构信息从真实 Dart CLI 发起申请，在 Flutter 桌面端批准一个字段，CLI 领取凭据后只能读取该字段；桌面撤销后再次读取失败。

关联规格用户故事：16、18、28、30、34、35、39、54、56。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 使用已确认的 Flutter 客户端与独立 Dart 核心、CLI，提供可复现的开发运行方式；本票可用内存中的虚构资料，不引入云端。
- [ ] 在本票确定并记录本机通信、请求标识及最小凭据交付方式；真实 CLI 与桌面后台互通，CLI 不直接访问存储，普通 agent 接口不能自行批准、撤销他人授权或调用管理功能。
- [ ] 未批准只返回公开描述；批准固定到明确信息项及字段，读取不得扩大到整条信息。请求 ID、聊天 ID 和用途文字不能替代私密凭据领取关联。
- [ ] 授权默认最长 8 小时，重复读取不续期；提供最小桌面撤销入口，撤销、过期、服务退出及重启后旧凭据不可读。完整历史入口由后续任务扩展。
- [ ] CLI 返回明确的成功、待处理、未授权及服务不可用状态，凭据不进入命令示例、通用日志或公开状态响应；后续状态可在同一契约中扩展。
- [ ] 通过核心服务公开接口验证批准、跨字段拒绝、伪造领取、撤销及可控时间到期，并完成一次真实桌面与 CLI 演示；不宣称已完成加密或 Codex 集成。
