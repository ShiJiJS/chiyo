## Parent

[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

用户安装 Windows 应用和 CLI、接入 Codex 后，能完成录入、审批、后台运行、变更、历史与恢复，并能升级继续使用资料。

关联规格用户故事：1、2、3、4、5、48、54、55。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 交付可复现的 Flutter Windows 发行包及 Dart CLI 安装方式，声明支持架构、系统条件和已知限制；Codex 能找到并调用 CLI。
- [ ] 干净用户环境验证免应用密码启动、录入、目录发现、部分批准、读取、不同聊天隔离及主子 agent 共享。
- [ ] 验证等待超时、拒绝、通知、托盘后台、完全退出、会话结束及重启后的权限失效。
- [ ] 验证模板、批量提案、修改冲突、删除恢复、历史撤销和备份恢复；发行包实际加载 SQLCipher，密钥与错误输出符合契约。
- [ ] 用旧版本测试库验证升级后系统密钥可访问、数据库迁移与恢复行为；不要求额外运行云端或数据库服务。
- [ ] 记录真实桌面、CLI、Codex 及安装升级证据；修复发现的问题或明确发布阻塞，不把未验收流程标为通过。
