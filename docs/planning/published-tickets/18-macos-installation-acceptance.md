## Parent

[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

用户安装 macOS 应用和 CLI、接入 Codex 后，获得一致的单机流程，菜单栏、钥匙串及升级在实际分发环境中可用。

关联规格用户故事：1、2、3、4、5、48、54、55。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 交付可复现的 Flutter macOS 发行包及 Dart CLI 安装方式，声明架构、系统条件、签名及分发状态；不把开发机能运行当作其他设备安装成功。
- [ ] 干净用户环境验证系统密钥获取、免应用密码启动、录入、目录发现、部分批准和获准读取，记录实际系统提示与配置。
- [ ] 真实 Codex 验证主子 agent 共享、跨聊天隔离、会话结束及恢复；验证菜单栏、通知、关窗、完全退出和重启。
- [ ] 验证模板、批量提案、修改冲突、删除恢复、历史撤销和跨设备备份恢复；发布包实际使用 SQLCipher。
- [ ] 验证升级后的应用身份及钥匙串访问、数据库迁移，密钥不可用时不覆盖原资料；不依赖 Windows 安装验收票才能开展。
- [ ] 提供真实桌面、CLI、Codex、安装及升级证据；未解决的分发或平台问题明确阻塞发布，不用文档核查代替实测。
