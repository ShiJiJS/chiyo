# 实现普通附件字段、加密存储、授权文件交付与完整备份

父任务#34。前置为#36“客户端原型与字段合同”子票；按已冻结合同实现核心/存储/CLI，不自行改变客户端字段语义。依据[当前设计](https://github.com/ShiJiJS/agent-info-manage/blob/codex/round05-windows-sync/docs/design/windows-credential-and-file-update.md)与[客户端规划](https://github.com/ShiJiJS/agent-info-manage/blob/codex/round05-windows-sync/docs/design/windows-attachment-client-plan.md)。

## 范围与验收

- [ ] 增加带类型的文件字段载荷和附件版本引用；旧两类文本与未知类型失败规则明确，模板仅存字段定义，普通提案/元数据编辑不会丢失已有附件或将其转为字符串。
- [ ] SQLCipher迁移支持元数据/BLOB/版本关系事务；正文按需读取、不进入启动/分页全量快照、公开目录、普通文本read或Base64 JSON。所有者导入/替换失败保留旧版本；类型/含义变化用新身份。
- [ ] 文件按普通字段授权，混合申请可部分批准；批准前/范围外拒绝、同会话期限内重复领取、交付固定版本；新增字段不借旧身份进入授权，撤销/到期/删除/重启规则及历史正确。
- [ ] 专用CLI交付受管同机副本路径/身份、释放及失败结果；原字节一致，路径防穿越；登记副本在释放/失效后回收，占用留待清理，不假称撤回已读/上传内容。
- [ ] 实现版本/回收、完整备份新格式及数据库恢复；兼容旧格式1–5，旧读取器拒绝新格式；附件分块处理、关系/原字节完整，恢复不复活授权或临时路径。
- [ ] 测量并冻结容量/峰值内存及备份余量（候选单文件10MiB、保留附件100MiB、备份256MiB/文本64MiB）；超限/错误密钥/损坏/中断不部分提交、不截断，不接受无法完整备份的正式资料。
- [ ] 面向公开核心接口、存储和实际独立CLI验证混合样本、只修改姓名不丢文件、版本替换、旧库升级及备份字节往返；给客户端真实异步接口和错误投影，不以内部单元测试替代客户端验收。

原#31 Windows凭据备份已交付，本票仅扩展普通附件；#30负责最终Agent接续。服务通过后，#34仍等待Windows客户端子票完成，不直接关闭父票。
