# 普通文件作为信息附件存入SQLCipher，并完成授权交付和完整备份

## 状态与依据

用户2026-10-18已选择数据库方案并确认进入Windows计划；生产实现未开始。父任务#21；[目标设计](https://github.com/ShiJiJS/agent-info-manage/blob/codex/round05-windows-sync/docs/design/windows-credential-and-file-update.md)、ADR0011。现有凭据文件不等于普通附件支持。

## 范围

附件是可单独授权的信息字段，既可挂在现有信息项，也可用仅含附件字段的信息项表达独立文件。用户桌面导入原文件，元数据及原字节以BLOB保存在现有SQLCipher；按需读取，同机Agent获准后领取受管文件副本。普通附件可以被Agent阅读，与不返回原文的凭据文件严格区分。

本轮不做外部附件库、服务器同步、通用OCR/解析、Agent附件录入提案或远程浏览器文件传输。工程容量候选为单文件10MiB、保留附件总量100MiB；须测量后冻结，用户仅确认预计小文件，未指定数字。

- [ ] 先补信息库三栏附件详情、编辑/替换、审批勾选及备份恢复预览原型，保持Round05风格和中间列表。

- [ ] 桌面导入、替换、另存、删除/回收及历史关系完整；写入失败保留原文件版本，超限明确拒绝；不自动删除导入源。
- [ ] 复用普通字段授权规则，批准前/范围外不可领取；同会话期限内重复交付；每次副本固定版本，替换读取当前版本，新增/无关字段不借旧授权进入。
- [ ] 专用CLI文件交付返回受管路径/身份而非原文或Base64；路径处理防穿越，释放/撤销/到期/结束/重启有登记清理，占用显示待清理；不宣称撤回已读/上传内容。
- [ ] 升级数据库和完整加密备份格式，按附件处理BLOB避免整库内存编码；预览计数/体积，旧格式1–5可恢复，旧读取器拒绝新格式；恢复后原字节、版本及关联一致，授权/临时路径不复活。
- [ ] 验证容量/峰值内存及备份大小预算（候选总文件256MiB、文本payload64MiB），含保留版本和回收对象；错误密钥、损坏、超限、中断不改原库或留下半恢复。
- [ ] 实际Windows系统文件对话框、CLI读取及文档/上传工具的同机文件可用性用虚构资料留证，不把文件路径返回当作远程浏览器可用。
