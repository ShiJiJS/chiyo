# 通过CLI触发本机焦点凭据填充，减少密码进入模型上下文

## 状态与依据

用户2026-10-18已确认按本机焦点方向进入Windows计划。生产实现未开始；临时假密码原理测试已完成，不能当正式CLI/授权验收。父任务#21；依赖#33；[目标设计](https://github.com/ShiJiJS/agent-info-manage/blob/codex/round05-windows-sync/docs/design/windows-credential-and-file-update.md)、ADR0012。

用户目标：正常使用时密码不直接进入模型上下文/工具输出，不要求抵御恶意回读。首轮针对本机交互桌面，不要求给所有浏览器工具写插件。

## 流程

先获得允许焦点填充的凭据授权 → Agent点击密码框 → 后台CLI提交引用和操作ID → 本机宿主核验并直接输入 → 只返回实际输入状态 → Agent继续操作网站。有效期内复用，不逐次弹审批；不把密码作为命令参数或工具文本返回。

## 验收

- [ ] 先补申请/审批中的输入目标、复用期限、tips及历史状态原型；命令执行和填充结果分别展示，不给填充虚构退出码或文件清理状态。
- [ ] 正式CLI/宿主经私密会话使用#33授权；同操作ID不重复输入，授权/版本/到期/撤销/重启检查及审计先于秘密交付。
- [ ] 捕获/复核真实前台窗口、进程创建身份及焦点；审批和调用入口不抢焦点；桌面串行填充，目标变化/不支持/修饰键/权限失败有可解释拒绝，不盲填其他窗口。
- [ ] 直接键盘输入或等价受控原生方式，不经普通剪贴板；秘密不进argv、stdout/stderr、日志、历史、截图记录或明文脚本；用虚构数据精确扫描。
- [ ] 独立CLI验证实际完整输入及特殊字符，无paste且剪贴板不变；部分发送/未知只查原操作，不自动重填或提交登录，不读回密码验证。
- [ ] 当前可见内置浏览器及选定Windows密码控件逐个形成支持记录；UIA无法可靠定位的情形明确不支持，不把原理测试坐标操作当作生产目标识别已完成。
- [ ] 检查正常工具快照、显式value读取和遮挡截图；保留显示明文导致截图进入上下文的对照，说明浏览器工具脱敏不是本软件能力，不承诺所有外部采集/模型服务载荷无秘密。
- [ ] 隔离窗口/临时服务用完即关闭，真实资料、用户Codex配置和系统安全设置不作为测试捷径；#30同步Skill的先授权后点击及保持遮挡说明。

## 已有原理证据与不覆盖项

[2026-10-18测试](https://github.com/ShiJiJS/agent-info-manage/issues/35#issuecomment-6249832356)：临时CLI使用SendInput，28字符匹配、无paste、剪贴板不变；普通快照及显式value读取返回`<redacted>`，正常截图圆点；显示明文后的截图泄漏。正式授权/IPC/CLI、焦点竞态与完整控件兼容未实现。

不覆盖后台/无头/远程浏览器、锁屏/安全桌面、任意高权限程序，不把Agent自述网址当已核验来源。插件及逐工具适配可后续另立范围，本票不承诺通用浏览器自动填充。
