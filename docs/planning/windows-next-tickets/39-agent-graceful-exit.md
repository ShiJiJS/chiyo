# Agent 可调用的 Windows 正常退出入口

用户在 2026-10-20 指出：切换测试版本不能长期依赖用户到托盘退出。需要提供能由 Agent 调用、结果可核对的正常退出入口，然后继续 Windows 验收。

## 范围

- 通用 CLI 增加 `info.exe app status` 和 `info.exe app quit`，默认只定位本交付目录中的桌面程序；显式 PID 可选择另一安装目录中的本软件实例。多实例不擅自全退出。
- 经 Windows 本机会话的窄控制入口请求退出，不把批准、读取秘密或任意执行能力加入公开 HTTP 接口，不需要内容授权。
- 复用正常退出流程：立即停用现有许可，排空记录，停止服务并关闭库，最后终止窗口/进程。审计保存失败保持库及窗口可重试，明确报告失败。
- CLI 必须核对目标进程确已退出后才报告 `exited`；有界超时报告未知，不强杀、不靠端口消失推断退出。绑定实际进程句柄，防止 PID 复用后误操作。
- 正常后台、重复调用、启动错误、保存失败重试、旧版不支持、目标不符、多实例和超时都有确定行为。旧版不能补装新入口或降级强杀。
- 更新使用说明及验收约定；外观保持 Round05，不开发同步或 Mac 控制。
