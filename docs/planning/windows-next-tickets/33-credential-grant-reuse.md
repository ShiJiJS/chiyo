# 凭据使用授权在有效期内复用，逐次操作独立记录

## 状态与依据

用户2026-10-18已确认进入Windows计划；设计已整理，生产实现未开始。替代本票原“仅记录、待设计”状态，不表示已支持。父任务#21；[目标设计](https://github.com/ShiJiJS/agent-info-manage/blob/codex/round05-windows-sync/docs/design/windows-credential-and-file-update.md)、ADR0010。

## 要完成的行为

同一私密会话内，一次批准指定版本凭据及接收配置后，可在固定有效期内运行不同合法命令，不逐条再审批，不增加单次/多次模式。每次操作冻结自己的计划并防重放；一条命令失败不消费整个授权。

默认仍为15分钟，可选30分钟；不因使用延长。轮换、停用、删除、到期、撤销、会话结束和重启拒绝新操作。现有程序仍是v1一次启动，迁移不能自动把旧证明升级为复用许可。
