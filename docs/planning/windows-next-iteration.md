## 仍需要真实环境的门槛

- 通知：此前Shell接受投递，但未取得可靠实际点击回调；保留失败，不反复投递或猜坐标。
- Codex：生成材料及模拟payload不等于用户实际安装、信任、主子共享、结束/恢复流程。安排实际环境前不改用户配置来绕过信任。
- 干净Windows：当前用户原生与SDK-free PATH不是新用户/新机器安装。需用户提供或安排环境；不擅自创建系统账号、调整安全设置。
- 交付继续沿用Windows x64未签名便携预览；安装器、签名、自动升级未纳入本轮必要范围。最后明确运行库条件，整包更新应用/CLI/worker，不能只替换EXE。

macOS执行适配、#17真实双向恢复、#19Mac分发延期；服务器同步、手机审批、远程/无头浏览器接入、通用OCR及浏览器插件不在本轮。暂停同步不是暂停上述Windows工作。
