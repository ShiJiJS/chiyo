## What to build

agent 从用户指定资料中整理多条信息，提交带分类和公开描述的录入提案；用户在桌面批量预览、调整和确认，随后这些信息可通过正常申请读取。

关联规格用户故事：12、13、15、39、58。

## Acceptance criteria

- [ ] CLI 可提交包含多条结构化字段和文本说明的新增提案，返回提案标识和状态；提交并不立即写入正式信息库。
- [ ] 桌面端批量预览并允许调整目录、标签、字段及公开描述；明确显示本次将入库的内容，拒绝不产生正式信息。
- [ ] 确认后信息稳定持久化并进入公开目录；agent 仍需正常申请内容读取，提交提案不赋予全库读取、覆盖或审批能力。
- [ ] 未确认提案不得被公开目录或其他会话读取；处理重试不重复录入同一批内容。
- [ ] 通过核心接口和真实 CLI/桌面流程验证批量确认、拒绝和未授权读取；Skill 明确导入会话本身已看到其处理的原始资料。
