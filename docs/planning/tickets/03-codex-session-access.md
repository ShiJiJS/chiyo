## What to build

Codex 桌面端的一次聊天可以通过 Skill 和通用 CLI 自动关联授权会话；同聊天的主子 agent 共享批准范围，其他聊天独立申请，正常结束后停止新的访问。可使用第一条任务的虚构资料演示。

关联规格用户故事：30、31、32、33、34、55、56。

## Acceptance criteria

- [ ] 基于实际可用的 Codex 接口验证聊天关联及生命周期，并记录适配所需的安装和信任步骤；不读取私人对话或现有认证资料来推断身份。
- [ ] 同一聊天的主子 agent 能复用已有范围，其他聊天仅伪造相同 ID 不能领取授权；会话 ID 只作关联，凭据的交付、查找和保管有独立私密关联。
- [ ] 正常结束会话时撤销该会话授权并取消待审批请求；异常结束仍受到期限制，恢复聊天不复活已失效权限。
- [ ] 提供配套 Skill，指导目录发现、一次申请、复用范围和状态处理；业务 CLI 保持通用，Codex 专用行为限制在适配层。
- [ ] 通过核心服务公开接口验证两会话隔离与共享规则，并在真实 Codex 桌面端验证主子 agent、正常结束及恢复；平台缺口不得用文档查阅代替实测。
