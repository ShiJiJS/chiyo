## Parent

[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

用户可以在客户端查看默认保留 30 天的修改历史，选择旧版本恢复为当前内容；agent 始终只能读取当前已授权字段，不能直接访问旧版本。

关联规格用户故事：44、45。

## Acceptance criteria

- [ ] 客户端按信息项展示加密保存的版本历史、时间和差异，默认保留 30 天；保留期内可将所选版本恢复为新的当前版本。
- [ ] agent 公共接口不提供历史值读取，当前字段授权不能通过参数、错误信息或公开检索扩大到旧版本。
- [ ] 回收站中的信息先按回收站规则恢复；版本恢复不能绕过删除导致的权限失效，重新引入的已删除字段不继承旧权限。
- [ ] 普通仍有效字段恢复旧值后，已有授权读取新的当前值；恢复不回退整个授权状态或运行状态。
- [ ] 通过核心接口以可控时间验证保留、恢复及拒绝历史读取，并在客户端和 CLI 演示完整恢复效果。

## Blocked by

- T11：确认删除、进入回收站并重新授权恢复的信息
