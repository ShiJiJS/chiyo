[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

用户可以在桌面端手动创建、查看和修正一条具有结构化字段及文本说明的信息；应用重启后仍能使用，CLI 只能在新授权后读取。应用无需输入主密码。

关联规格用户故事：1、2、10、11、48、57。

## Acceptance criteria

- [ ] 支持手动创建和编辑信息项、字段及文本说明；公开描述与受控内容分开，信息及字段拥有稳定身份和版本，不依赖本机绝对路径作身份。
- [ ] 选定并记录加密存储和系统密钥保管方案；用户直接打开应用即可使用，CLI、公开配置和日志不包含全库解密材料。
- [ ] 已保存内容及受控元数据加密持久化；检查测试敏感值不会出现在临时文件、存储辅助文件和错误输出中。密钥不可用时给出明确错误，不偷偷改用明文。
- [ ] 应用重启后可查看已有信息并重新批准读取，旧运行实例的访问凭据不能复活；恢复链路完成前继续使用虚构数据验证。
- [ ] 在 Windows/macOS 分别验证密钥自动获取与持久化重开；若缺少真实平台验证条件，应报告未验证范围而非声称全部通过。
- [ ] 通过核心服务公开接口验证保存、更新、重开、版本变化及越权读取，并补真实存储与系统密钥适配验证。
