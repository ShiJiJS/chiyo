## Parent

[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

在信息组织、提案和历史功能齐备后，用户可以把完整支持范围的资料库恢复到另一台设备，保留可解释的数据关系，同时从没有有效授权的状态开始。

关联规格用户故事：50、51、53、57。

## Acceptance criteria

- [ ] 明确并在备份界面说明正式信息、目录、标签、模板、版本、回收站及审计历史各自是否纳入；不将未确定的数据范围默默交给用户猜测。
- [ ] 扩展早期备份格式覆盖声明包含的非运行时数据，恢复后标识、版本和关系一致；不能用仅恢复一条字段的演示宣称完整换机恢复。
- [ ] 待审批请求、待确认变更和有效授权不会在恢复时继续执行或自动生效；历史如被包含，仅作为历史事实，不变成活动权限。
- [ ] 验证 Windows 导出的受支持备份可在 macOS 恢复，反向亦然；不依赖原设备密钥。
- [ ] 损坏、错误密钥、格式不兼容及恢复中断不破坏已有库；恢复结果明确，不出现半恢复却报告成功的状态。
- [ ] 通过核心接口验证完整数据集往返及权限清空，并记录真实跨设备结果；服务器或同步协议不属于此任务。
