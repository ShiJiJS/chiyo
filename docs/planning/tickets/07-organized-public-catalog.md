## What to build

用户可以组织信息、复用字段模板，并审阅哪些名称和说明对 agent 可见；agent 可检索和分页查看公开目录，找到需要申请的资料。

关联规格用户故事：6、7、8、15、16、57。

## Acceptance criteria

- [ ] 桌面端支持目录层级、标签及可扩展字段模板，用户可调整归类和公开名称、描述及字段说明。
- [ ] CLI 可按公开元数据检索和分页发现信息；内部字段值、私有文本、历史值及未确认提案不出现在响应或搜索片段中。
- [ ] 目录移动、标签变化和模板扩展不改变信息身份，也不自动授予新字段访问权；信息标识和版本为未来单用户多设备保留空间。
- [ ] 公开描述必须经过用户保存或确认才成为正式目录内容；模板仅帮助录入，不构成权限等级。
- [ ] 通过核心接口验证公开字段投影、分页筛选、身份稳定及无内容泄露，并演示桌面整理后在真实 CLI 中检索。
