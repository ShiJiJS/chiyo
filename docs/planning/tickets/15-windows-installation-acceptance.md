## What to build

用户在全新 Windows 环境安装应用和 CLI，接入 Codex 后能完整使用单机版，包括审批、后台通知、资料变更、授权历史和备份恢复。

关联规格用户故事：3、4、5、54、55。

## Acceptance criteria

- [ ] 提供可复现的 Windows 安装或发行包及必要安装说明；CLI 可被目标 Codex 环境调用，失败时提供可操作的错误，不要求重新提供已有账号秘密。
- [ ] 在干净用户环境验证安装、首次免应用密码启动、手动录入、公开检索、申请及部分批准、获准读取和跨聊天拒绝。
- [ ] 验证主子 agent 共享、待审批等待超时、系统通知、关窗后台运行、完全退出及重启后的旧凭据失效。
- [ ] 验证批量录入、修改冲突、删除恢复、历史查看与撤销以及加密备份恢复，确认实际打包不会改变已测业务规则。
- [ ] 提供真实 CLI、桌面和 Codex 验收证据与已知限制；问题在本票修复或明确成为发布阻塞，不把未通过的路径标成完成。
