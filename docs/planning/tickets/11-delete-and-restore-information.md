[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

用户可以确认 agent 的删除提案或在客户端删除资料，资料进入回收站并立即停止通过旧授权读取；误删恢复后需要重新授权。

关联规格用户故事：40、41、42、43。

## Acceptance criteria

- [ ] agent 的删除申请进入用户确认流程，提交本身不能删除；客户端也提供明确的删除入口。
- [ ] 条目或字段删除后，旧凭据对该目标的新读取立即失败，其他仍获准目标不受无关影响。
- [ ] 回收站默认保留 30 天，用户可在保留期内恢复；恢复相同标识不能复活原授权，重新批准后才可读取。
- [ ] 删除、恢复和批准并发时保持固定范围及唯一可解释状态；已经成功删除后发起的读取必须拒绝。
- [ ] 使用可控时间测试回收站保留与清理，并验证真实桌面删除、恢复和 CLI 拒绝/重新授权读取；不宣称删除已导出的离线备份。
