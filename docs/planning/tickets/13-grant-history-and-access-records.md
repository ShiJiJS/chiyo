## Parent

[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

用户以授权历史为入口查看曾批准的范围、时长和状态变化，关联真实成功及拒绝的访问记录，并撤销仍然有效的授权。

关联规格用户故事：35、46、47、48、49、58。

## Acceptance criteria

- [ ] 桌面授权历史显示批准当时的会话、范围、有效期和后续结束、到期、撤销事实；后续名称变化不篡改当时的授权事实。
- [ ] 关联的访问记录包含时间、会话、操作、信息及字段标识和结果，能区分批准范围与实际发生的读取。
- [ ] 成功、越权和其他失败访问可解释，记录、通知和诊断输出不复制字段值、token 或密钥；无凭据请求不会通过错误结果发现私有目标。
- [ ] 从历史入口撤销有效授权后，新读取立即拒绝；记录保留为历史事实，界面明确撤销不会收回已披露内容。
- [ ] 明确并记录授权历史及访问记录的保留和清理策略，不擅自套用内容版本的 30 天规则；如需用户决定新的体验取舍，列明后再改变产品承诺。
- [ ] 通过核心接口验证历史关联、记录内容边界和撤销竞争，并通过真实桌面撤销及 CLI 再次读取展示结果。
