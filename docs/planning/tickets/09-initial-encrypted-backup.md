## Parent

[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

用户可以对已经保存的信息手动生成加密备份，另存恢复密钥，并在没有原设备密钥的环境中恢复这些信息；日常打开应用仍不要求密码。

关联规格用户故事：50、51、52、53。

## Acceptance criteria

- [ ] 桌面端提供启用备份、保存恢复密钥、手动导出和导入恢复的完整流程，避免把恢复密钥与备份作为同一公开文件保存。
- [ ] 使用测试信息验证恢复只需要备份和正确恢复密钥，不依赖原设备在线或原密钥；目标环境建立自己的本机密钥保管。
- [ ] 定义可演进的备份格式与完整性校验；错误密钥、损坏或不支持版本不能覆盖或破坏已有资料。
- [ ] 备份中不包含可恢复生效的 token、待处理审批及运行实例凭据；恢复后的读取必须重新申请。
- [ ] 通过核心接口和独立密钥环境完成往返恢复测试，并验证真实桌面操作；这一步先覆盖当前已有资料模型，后续完整恢复任务补齐新引入的历史和组织数据。
- [ ] 加密存储与这条恢复路径验证前，所有演示继续使用虚构资料，不主动迁移用户真实信息。
