## Parent

[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

用户面对包含多条资料的申请，可以取消字段、补选或改选信息并调整有效期，一次操作形成明确授权；agent 得到实际批准范围，不需要重新提交。

关联规格用户故事：9、10、17、18、19、20、21、29、36、37。

## Acceptance criteria

- [ ] 审批界面同时展示申请范围和用户最终选择，支持字段级取消、补选及改选，文本说明也作为受控字段选择。
- [ ] 批准默认最长有效期 8 小时且可调整；部分批准是成功处理结果，CLI 得到准确范围、到期时间及新增内容需另行申请的说明。
- [ ] 授权固定为批准时选中的信息项及字段集合，不依赖会扩大的目录、模板或标签查询；后来新增的信息及字段不能读取。
- [ ] 批准前资料或字段状态发生变化时重新校验实际选择，不对已删除目标发放有效权限；重复处理申请不能产生冲突授权。
- [ ] 通过核心接口验证部分批准、用户增加候选之外的信息、伪造范围和到期；使用真实桌面与 CLI 演示一次调整后读取。
