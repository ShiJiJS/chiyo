- 新增 apps/server，复用 info_core、info_storage 和真实 SQLCipher；没有改动核心业务规则。
- MountedDatabaseKeyStore 只读取已独立提供的 32 字节密钥，不自动创建/替换密钥；拒绝符号链接、不合法长度及宽松权限。丢失或错误密钥时原库字节保持。
