# 服务端 A08：密码、Token 和密钥保存在服务器

已确认的方案编号。阶段：首轮自动开发与合成验收。

## 要实现什么

资料与凭据一起提交，App 直接补填缺少的密码，整份齐全后一起保存。

## 验收条件

- [ ] 现有字符串凭据、Token、凭据文件及关联通过正常受保护流程保存，预览清楚显示类型、账号和用途。
- [ ] 沿用填写规则：人设定且未进入 AI 上下文的密码由用户填；Token 等由 Agent 填；已经读到的密码可由 Agent 填并告知已进入上下文，不让用户重复输入。
- [ ] 提案内直接填密码并支持显示/隐藏，不另批自己填写的值；任意必填项缺少时整份不能入库。
- [ ] 凭据文件直接提交，不新增逐种配置文件提取字段的协议。
- [ ] 新增、编辑说明、更换材料、停用等既有操作接通正常凭据编辑入口；只改说明不改变材料版本和有效使用代际。
- [ ] 重新连接后关联保持，普通目录、提案回执、历史和日志不暴露密码或密钥原文。
- [ ] 验收用虚构材料和隔离密钥；真实钥匙串、用户密码输入集中留正式交付。


## 本票范围

保存不授予 AI 使用许可，实际使用由 [#99](https://github.com/ShiJiJS/chiyo/issues/99) 完成。

## 执行约定

本阶段为单用户、局域网、必须联网使用；不开发离线同步、手机或网页管理端。

复用现有 Dart 业务规则和加密存储，先验证当前电脑连接独立服务器；跨电脑审批后置。开发与自动验收使用隔离合成资料、正常产品入口及实际内置能力，不逐票替换日常 App 或访问个人钥匙串。相关检查随开发完成，正式安装和必要人工操作集中安排；实际未验证的平台与系统项目如实记录。
