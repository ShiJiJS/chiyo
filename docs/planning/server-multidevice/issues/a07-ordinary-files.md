# 服务端 A07：上传普通文件，获批后下载到本机

已确认的方案编号。阶段：首轮自动开发与合成验收。

## 要实现什么

App 或 AI 保存附件及版本到服务器，确认后 AI 获批把指定版本下载到自己的电脑。

## 验收条件

- [ ] App 和 CLI 均可正常上传合成文件，文件资料、关联及同一文件的多个版本按已有规则保存。
- [ ] App 预览、替换、选版本、另存及本机打开使用实际远程交付，不把服务器路径作为本机文件地址。
- [ ] 空白客户端配置取回指定版本原字节一致；上传中断、重试、提案失败不形成可见半条资料或重复版本。
- [ ] AI 未获批不能领取原文；范围、版本和交付结果准确，普通响应不夹带凭据材料。
- [ ] App 完全退出后 CLI 仍能下载；普通服务重启保留原聊天有效的文件许可，结束或撤销的不恢复。
- [ ] 受管副本回收与用户自行另存文件分别处理；验收使用真实文件驱动和生产模板目录。
- [ ] 原生文件面板等尚需系统界面验收的事项留 [#103](https://github.com/ShiJiJS/chiyo/issues/103) 集中处理，不把模拟面板说成原生通过。


## 本票范围

仅用合成普通文件，不打开个人原件或清理真实目录。

## 执行约定

本阶段为单用户、局域网、必须联网使用；不开发离线同步、手机或网页管理端。

复用现有 Dart 业务规则和加密存储，先验证当前电脑连接独立服务器；跨电脑审批后置。开发与自动验收使用隔离合成资料、正常产品入口及实际内置能力，不逐票替换日常 App 或访问个人钥匙串。相关检查随开发完成，正式安装和必要人工操作集中安排；实际未验证的平台与系统项目如实记录。
