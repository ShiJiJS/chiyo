# 服务端 L03：另一台电脑审批，并同步待办和处理结果

已确认的方案编号。阶段：后置交付或跨电脑验证。

本票为后置事项，不作为首轮完成前提，不随 [#91](https://github.com/ShiJiJS/chiyo/issues/91)–[#102](https://github.com/ShiJiJS/chiyo/issues/102) 自动开工；待安排正式交付或另一台电脑验证时再执行。

## 要实现什么

AI 在一台电脑申请，用户在另一台批准，原电脑继续使用，在线 App 更新待办状态。

## 验收条件

- [ ] 复用统一申请、用户审批及授权接口，不改变资料身份、整份提案保存或本机执行规则。
- [ ] 跨电脑验证文字读取、录入提案、文件及凭据使用，申请电脑收到准确结果，命令与文件仍在 AI 电脑使用。
- [ ] 在线客户端更新待办及处理结果，一台处理后其他客户端不能一直显示可重复处理的旧状态。
- [ ] App 全部关闭时服务保留有效申请，重开可查；断线和普通重启不丢结果、不重复入库或执行。
- [ ] 同时处理同一申请或重复审批返回一致结果，不新增复杂冲突合并界面。
- [ ] 需要系统通知的平台集中测试通知打开目标，保留实际双端证据，不以同机两进程冒充双端实测。


## 本票范围

后续需求，不列入首轮上线必要条件；不开发手机或网页管理端。

## 执行约定

本阶段为单用户、局域网、必须联网使用；不开发离线同步、手机或网页管理端。

复用现有 Dart 业务规则和加密存储，先验证当前电脑连接独立服务器；跨电脑审批后置。开发与自动验收使用隔离合成资料、正常产品入口及实际内置能力，不逐票替换日常 App 或访问个人钥匙串。相关检查随开发完成，正式安装和必要人工操作集中安排；实际未验证的平台与系统项目如实记录。
