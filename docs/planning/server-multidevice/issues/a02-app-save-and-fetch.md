# 服务端 A02：App 连接服务器，保存和重新拉取资料

已确认的方案编号。阶段：首轮自动开发与合成验收。

## 要实现什么

在当前电脑的 App 填地址和 Token，保存、查看和修改资料；换空白客户端配置后仍能取回。

## 验收条件

- [ ] 现有 App 信息库、搜索及编辑入口接通远程数据；连接配置与可读错误在正常界面可操作，不以测试页面代替。
- [ ] 新增、查看、修改纯文字资料；退出后使用隔离的空白客户端配置重新接入，服务器内容保持。
- [ ] 目录层级、归属及模板身份随资料读取返回，提供后续提案需要的基础目录查询；完整目录管理由 [#94](https://github.com/ShiJiJS/chiyo/issues/94) 接续。
- [ ] 断开服务器时明确显示无法使用，不回退本机库或误报保存成功；重连查询原操作结果，保留已有版本检查。
- [ ] App 退出不停止服务；独立客户端进程取回相同内容，不以共享数据库文件或本地缓存冒充同步。
- [ ] 配置保存、Token 更换、服务器切换和无效身份均验证；另一服务器不继承旧聊天授权。
- [ ] 建立现有入口对照表，分别列出已接通、待接通及明确后置的功能，后续每票更新，避免最后才发现正式入口遗漏。


## 本票范围

这一票先完成保存和取回，不要求第二台物理电脑。

## 执行约定

本阶段为单用户、局域网、必须联网使用；不开发离线同步、手机或网页管理端。

复用现有 Dart 业务规则和加密存储，先验证当前电脑连接独立服务器；跨电脑审批后置。开发与自动验收使用隔离合成资料、正常产品入口及实际内置能力，不逐票替换日常 App 或访问个人钥匙串。相关检查随开发完成，正式安装和必要人工操作集中安排；实际未验证的平台与系统项目如实记录。
