# 服务端 A05：App 和 CLI 使用服务器当前的模板与例子

已确认的方案编号。阶段：首轮自动开发与合成验收。

## 要实现什么

App 管理模板插件后，CLI 查询相同的模板、字段和例子，并能按返回格式准备资料。

## 验收条件

- [ ] 服务器返回内置及已启用插件的模板目录、字段格式、关联说明和例子；App、CLI 查询一致。
- [ ] 安装、启停、版本变化后查询当前可用格式；旧资料展示和模板身份保留，不静默降为通用资料。
- [ ] App 沿用插件展示和编辑逻辑，不另写一套简化预览，也不在 Skill 固定列模板。
- [ ] 验证真实内置文件模板及一个合成插件，不能在测试中额外注册插件掩盖正式缺项。
- [ ] 动态示例能通过正常校验，覆盖普通资料、应用部署、设备配置及凭据说明；完整保存由后续票接续。
- [ ] CLI 与说明同步更新；不兼容的展示或模板能力明确提示，不丢字段后仍报告成功。


## 本票范围

复用现有模板插件能力，不新增远程插件代码执行平台。

## 执行约定

本阶段为单用户、局域网、必须联网使用；不开发离线同步、手机或网页管理端。

复用现有 Dart 业务规则和加密存储，先验证当前电脑连接独立服务器；跨电脑审批后置。开发与自动验收使用隔离合成资料、正常产品入口及实际内置能力，不逐票替换日常 App 或访问个人钥匙串。相关检查随开发完成，正式安装和必要人工操作集中安排；实际未验证的平台与系统项目如实记录。
