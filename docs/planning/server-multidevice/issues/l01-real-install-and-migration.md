# 服务端 L01：集中安装新版、迁入真实资料并处理系统确认

已确认的方案编号。阶段：后置交付或跨电脑验证。

本票为后置事项，不作为首轮完成前提，不随 [#91](https://github.com/ShiJiJS/chiyo/issues/91)–[#102](https://github.com/ShiJiJS/chiyo/issues/102) 自动开工；待安排正式交付或另一台电脑验证时再执行。

## 要实现什么

最终候选集中完成必要原生检查，验证真实备份后迁入选定局域网服务器，再切换日常 App。

## 验收条件

- [ ] 确定实际服务器及最终候选，核查 Linux 架构、持久目录；需要用户补充部署位置时在本阶段集中确认。
- [ ] 完成必要原生文件面板、密钥保存/授权及影响日常使用的检查，不仅凭 [#102](https://github.com/ShiJiJS/chiyo/issues/102) 自动通过就接管真实资料。
- [ ] 正常导出当前 Mac 完整加密备份，在独立位置恢复核对；系统密码由用户输入，能自动完成的步骤不转交用户重做。
- [ ] 停止旧库写入后迁入空服务器，核对内容、文件版本、凭据、目录及关联，不混入 Windows 测试库，不输出凭据原文。
- [ ] 固定位置集中换一个最终版本；包名一致不保证新签名免提示，系统确认集中处理，不放宽保护来绕过。
- [ ] 失败可回旧版和原库，成功仅留最新交付及必要恢复材料；旧库停止写入，不形成两套持续变化的数据。
- [ ] 正式 App 可用迁入资料，CLI 按新说明接入，如实报告仍未测的原生能力。


## 本票范围

后置交付，不阻塞 [#91](https://github.com/ShiJiJS/chiyo/issues/91)–[#102](https://github.com/ShiJiJS/chiyo/issues/102)；当前规划不授权直接迁移真实库或安装正式版本。

## 执行约定

本阶段为单用户、局域网、必须联网使用；不开发离线同步、手机或网页管理端。

复用现有 Dart 业务规则和加密存储，先验证当前电脑连接独立服务器；跨电脑审批后置。开发与自动验收使用隔离合成资料、正常产品入口及实际内置能力，不逐票替换日常 App 或访问个人钥匙串。相关检查随开发完成，正式安装和必要人工操作集中安排；实际未验证的平台与系统项目如实记录。
