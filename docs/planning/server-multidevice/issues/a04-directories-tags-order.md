# 服务端 A04：目录、标签、移动和排序保存到服务器

已确认的方案编号。阶段：首轮自动开发与合成验收。

## 要实现什么

用户在 App 整理目录、标签及顺序，重新连接后仍保持整理结果。

## 验收条件

- [ ] 现有新建、重命名、移动目录、资料归类、标签和手动顺序通过服务器保存，沿用正常菜单、多选及拖动入口。
- [ ] 重新连接后目录树、资料归属、标签、排列与服务器一致，目录和模板类型不混淆。
- [ ] 移动目录和批量资料不会产生循环层级、重复资料或丢失关联；断线后可查询原操作结果。
- [ ] 已有整理申请、任务和结果接通；Agent 只能在获批范围调整分类及标签，查询目录不等于修改许可。
- [ ] 自动验收覆盖真实工作区控件调用和加密存储重开，不以直接写库或界面演示代替。
- [ ] 目录删除、整批恢复由 [#100](https://github.com/ShiJiJS/chiyo/issues/100) 接续并保持待接通标记；本票不等待另一电脑、系统通知或人工拖动验收。


## 本票范围

[#96](https://github.com/ShiJiJS/chiyo/issues/96) 仅依赖 [#92](https://github.com/ShiJiJS/chiyo/issues/92)、[#93](https://github.com/ShiJiJS/chiyo/issues/93) 已有的目录查询，不被本票完整管理操作阻塞。

## 执行约定

本阶段为单用户、局域网、必须联网使用；不开发离线同步、手机或网页管理端。

复用现有 Dart 业务规则和加密存储，先验证当前电脑连接独立服务器；跨电脑审批后置。开发与自动验收使用隔离合成资料、正常产品入口及实际内置能力，不逐票替换日常 App 或访问个人钥匙串。相关检查随开发完成，正式安装和必要人工操作集中安排；实际未验证的平台与系统项目如实记录。
