# 服务端 A10：回收、恢复和历史从服务器读取

已确认的方案编号。阶段：首轮自动开发与合成验收。

## 要实现什么

App 可回收整组目录及内容、恢复资料与版本，查看准确的审批和使用历史。

## 验收条件

- [ ] 普通资料、文件和凭据的回收恢复接通正常入口；目录删除包含内容，按现有批次整体恢复，重连后状态一致。
- [ ] 资料和文件版本比较、恢复保留原文、版本身份及关联；恢复生成正常记录，不回滚整个数据库。
- [ ] 审批、提案和凭据管理历史从服务器查询，展示名称、范围、状态及必要差异，不展示难懂内部编号或凭据原文。
- [ ] 回收和恢复不使失效许可自动复活，已删除内容不继续作为正常可领取资料。
- [ ] 批量操作断线可查结果，重试不重复回收，失败不遗留半个目录恢复。
- [ ] 验收从正常 App 控件到服务，再用新客户端核对目录、版本及历史；[#99](https://github.com/ShiJiJS/chiyo/issues/99) 的执行历史由 [#101](https://github.com/ShiJiJS/chiyo/issues/101)、[#102](https://github.com/ShiJiJS/chiyo/issues/102) 联合核对。


## 本票范围

本票完成当前客户端查询及刷新，不新增跨端广播或依赖系统通知中心。

## 执行约定

本阶段为单用户、局域网、必须联网使用；不开发离线同步、手机或网页管理端。

复用现有 Dart 业务规则和加密存储，先验证当前电脑连接独立服务器；跨电脑审批后置。开发与自动验收使用隔离合成资料、正常产品入口及实际内置能力，不逐票替换日常 App 或访问个人钥匙串。相关检查随开发完成，正式安装和必要人工操作集中安排；实际未验证的平台与系统项目如实记录。
