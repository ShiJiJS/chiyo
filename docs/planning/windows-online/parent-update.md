# 服务端 L02：第二台电脑接入并完成另一平台验证

已确认的方案编号。阶段：后置交付或跨电脑验证。

本票为后置事项，不作为首轮完成前提，不随 [#91](https://github.com/ShiJiJS/chiyo/issues/91)–[#102](https://github.com/ShiJiJS/chiyo/issues/102) 自动开工；待安排正式交付或另一台电脑验证时再执行。

## 要实现什么

另一台电脑填写地址和 Token 后取得同一套资料，验证该平台的 App、CLI 和本机执行。

## 验收条件

- [ ] 另一物理电脑从空白客户端配置接同一服务，取得合成资料、文件、目录及模板，不共享数据库文件。
- [ ] 两个客户端分别保存、重读并保留版本检查，结果一致，不导入 Windows 旧测试库。
- [ ] 另一平台的原生面板、CLI 生命周期、执行程序和已支持凭据方式实际运行；Windows 已有填充在此接通，Mac 原生密码填充继续按已有 #51 单独处理。
- [ ] 连接配置和本机身份保管可用，断线与错误 Token 提示准确，不以另一平台结果代替。
- [ ] 按平台交付规范出包和记录，集中系统授权；拿不到第二电脑时保持后置未完成，不暂停首轮开发。
- [ ] 先证明资料共用及平台能力，不把尚未验证的跨电脑审批和提醒算作通过。


## 本票范围

可用合成服务器，不依赖 [#103](https://github.com/ShiJiJS/chiyo/issues/103) 真实迁移，也不默认触发需要费用确认的 Windows CI。
