Agent 通过本机 CLI 发现公开目录并申请所需信息，Flutter 桌面端由用户批准固定字段范围，核心服务逐次鉴权后返回获准内容。本 PR 集成第一版单机实现及 Windows 开发预览交付；真实平台验收尚未完成，保持草稿。

已实现：

- Flutter 桌面、Dart 核心与 CLI；Drift + SQLCipher 加密资料库，Windows 当前用户 DPAPI 保管随机本机密钥，密钥或引擎错误时拒绝打开并保留原库。
- 待审批、部分批准、补选和改选、固定范围与期限、拒绝、取消、等待、撤销及到期。更新值不要求重复审批，新增或恢复字段不扩大、复活旧授权。
- 目录、标签、公开元数据检索与分页、录入模板、手动录入、批量录入提案及基于版本的修改/删除预览，用户确认才生效。录入默认只读卡片，单项另开编辑；列出自述 Agent/聊天、用途、数量及标题摘要，确认后可查看当前只读详情。分类建议随确认原子应用并复用同名标签。
- Agent 发起的分类整理：CLI 请求进入既有访问审批，用户选定范围并一次批准元数据访问及自动分类/标签写入，30 分钟内提交直接应用，不需应用创建任务或二次确认。没有字段值或内容编辑能力；全部批准身份/版本及提交前会话/期限复查，冲突整批不应用。空结果正常完成并可只读查看，旧任务不自动取得写入能力。
- 后台托盘/菜单栏、通用新请求通知及完全退出；30 天回收站和修改历史、差异及恢复。
- 加密且不含值或凭据的授权历史/访问记录，默认 90 天、可选 30/90/180/365 天。记录写入失败暂停内容交付并保留事实以供重试。
- 私密 Codex 聊天关联、父证明委托的主子 agent 共享和独立仅撤销 hook 凭据。公开聊天 ID 不提供读取能力；结束、撤销、过期或删除在读取等待期间生效时仍阻止交付。未安装或信任 hook，未修改用户 Codex 配置。
- 独立恢复密钥的完整加密备份，包含当前资料、组织、模板及保留期内版本、回收站和授权/访问历史；排除全部提案、待审批和活跃凭据。只向空库原子恢复，恢复历史只作过去事实，旧运行权限全部失效。
