## What to build

Codex 在同一聊天中多次调用 CLI 能复用已获准范围，其他聊天独立申请，用户不用手动维护聊天凭据。

关联规格用户故事：30、32、54、55、56。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 依据实际可用的 Codex 接口完成安装和聊天关联，记录所需配置；不通过读取私人聊天历史或已有认证秘密推断身份。
- [ ] 在本票确定并实现多次 CLI 启动之间的私密关联、凭据领取和保存；自报会话 ID、环境中的公开标识或可猜请求 ID 不足以领取另一聊天的凭据。
- [ ] 同一聊天重复读取不重新审批或延长授权；另一聊天走独立申请，原授权范围与到期规则不变。
- [ ] 提供配套 Skill，覆盖目录发现、一次申请、范围复用和已支持的状态处理；Codex 专用逻辑留在适配层，业务 CLI 保持通用。
- [ ] 通过核心接口及真实 Codex 的两个聊天、多次 CLI 调用验证关联与隔离，记录实测平台；子 agent 共享和结束事件由下一张接入票实现。
