## What to build

用户查看最近 30 天的修改版本，将旧版本恢复成新的当前内容；agent 仍只能读取当前获准字段。

关联规格用户故事：44、45。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 客户端展示加密保存的修改历史、时间和差异，默认保留 30 天；恢复产生新当前版本，不回退整个资料库运行状态。
- [ ] agent 的当前授权不能读取历史值，也不能通过搜索、参数或错误信息获取旧版本。
- [ ] 回收站内容遵循先恢复再授权的规则；恢复已删除字段不复活旧权限，仍有效字段恢复值后可由已有授权读取新的当前值。
- [ ] 恢复时检查并发版本变化，不静默覆盖；清理历史不影响当前有效内容。
- [ ] 核心接口以受控时间验证历史保留、清理和恢复，真实桌面与 CLI 演示恢复效果及拒绝历史读取；保持加密与已承诺备份契约。
