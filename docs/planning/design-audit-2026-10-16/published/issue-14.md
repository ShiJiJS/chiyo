## What to build

用户确认删除后，信息进入回收站且旧授权立即不能读取；恢复资料后需要重新批准访问。

关联规格用户故事：40、41、42、43。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] agent 删除提案需要桌面用户确认，提交不删除；用户也能在客户端直接执行明确的删除操作。
- [ ] 信息项或字段删除后旧 token 对其新读取失败，不影响同授权内其他有效目标。
- [ ] 回收站默认保留 30 天，可在期限内恢复；保存必要的删除与恢复事实，恢复同一标识不复活旧权限。
- [ ] 删除、恢复、批准与读取的并发结果可解释；成功删除后发起的读取必须拒绝，重新批准后恢复目标可读。
- [ ] 核心接口以可控时间验证保留和清理，真实桌面与 CLI 验证删除、恢复、拒绝及新授权；不声称删除已导出备份或已披露内容。
