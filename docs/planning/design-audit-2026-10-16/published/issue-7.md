## What to build

同聊天主 agent 与子 agent 复用授权，聊天正常结束后撤销授权并取消待审批；异常结束和恢复聊天也不会复活旧权限。

关联规格用户故事：31、33、34、55。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 真实 Codex 主子 agent 通过私密关联共享整次聊天的授权范围，子 agent 需要更多字段仍须申请；其他聊天不能以相同自报 ID 加入。
- [ ] 正常收到会话结束事件时撤销该聊天授权并取消待审批请求；不会把普通 CLI 结束、子 agent 结束或切换聊天误认为整次聊天结束。
- [ ] 结束、批准和读取之间有唯一可解释的状态；结束后新读取失败，结束事件缺失由有效期兜底。
- [ ] 恢复聊天不复活已结束、过期、撤销或旧应用实例的权限；Skill 与桌面状态能解释需要重新申请。
- [ ] 通过受控时间核心测试及真实 Codex 验证子 agent、结束和恢复流程；记录平台差异，无法触发的事件不能仅靠文档宣称实测通过。
