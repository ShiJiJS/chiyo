## What to build

用户按目录和标签整理资料、审阅公开说明，agent 搜索和分页发现可以申请的信息。

关联规格用户故事：6、7、15、16、36、57。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 桌面支持目录层级、标签和公开名称、描述及字段说明的编辑，用户保存后才更新对外目录。
- [ ] CLI 根据公开元数据检索和分页，不返回字段值、内部备注、历史值或未确认内容，搜索片段也不泄露。
- [ ] 目录移动和标签变化保持信息身份，不扩大已有授权；按目录批量选择时最终仍保存固定标识集合。
- [ ] 组织数据保持加密及稳定标识、版本，为后续同步预留而不实现同步服务。
- [ ] 通过核心接口验证检索、分页、移动和授权不扩张，真实演示桌面整理后 CLI 发现并申请读取。
