## What to build

agent 提交修改提案，用户查看差异并确认；原授权立即读到修正值，新字段仍需批准，过时提案不会覆盖新内容。

关联规格用户故事：14、36、38、39、44。当前为待确认的正文草案，尚未发布。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 修改提案携带目标及基础版本，桌面展示字段和公开描述差异；确认前正式内容不变，拒绝和重试结果明确。
- [ ] 读取旧内容必须有对应权限；提交响应、差异接口和错误结果不能向无读取权限的 agent 暴露旧值。
- [ ] 用户手动编辑或其他提案导致版本变化时显示冲突或要求重新预览；校验版本与正式写入保持一致。
- [ ] 普通值修正保留字段身份，新增或替换业务含义按新身份处理；定义明确操作，不依赖模型自动判定语义。字段移除遵循删除后旧授权失效规则。
- [ ] 已授权字段读取最新值，新字段不可读；变更前版本加密保存，为后续用户历史查看提供数据，但 agent 不能读取旧值。
- [ ] 核心接口验证确认、并发、字段身份及范围不扩大，真实 CLI/桌面演示修改后读取；备份覆盖已承诺的数据范围。
