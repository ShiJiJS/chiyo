## What to build

用户在一次审批中取消、补选或改选字段并调整有效期，CLI 获得实际批准范围；新增信息不会自动加入旧授权。

关联规格用户故事：9、10、17、18、19、20、21、29、36、37。当前为待确认的正文草案，尚未发布。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 桌面同时展示申请范围及最终选择，支持跨信息项补选、改选及部分批准，文本说明按字段选择。
- [ ] 授权默认最长 8 小时、批准时可调整；部分批准作为成功结果返回准确字段和到期时间，并明确新增内容需重新申请。
- [ ] 保存批准当时的信息项和字段集合；新增信息或字段不扩大授权，不用动态分类查询充当授权范围。
- [ ] 批准时重新检查目标状态，重复处理不产生冲突授权；目标无效时返回可解释结果。
- [ ] 核心接口验证部分批准、额外补选、越权和到期，真实桌面与 CLI 演示一次调整后读取；使用手动信息库，不要求先完成目录模板或 Codex。
