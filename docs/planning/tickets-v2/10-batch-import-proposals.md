## What to build

agent 将用户指定资料整理成录入提案，用户批量调整分类、字段和公开描述后确认，信息才正式入库。

关联规格用户故事：12、13、15、39、58。当前为待确认的正文草案，尚未发布。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] CLI 提交多条结构化字段及文本说明、建议分类或模板的录入提案，返回可查询状态；提交不直接形成正式信息。
- [ ] 桌面批量预览并允许调整字段、目录、标签和公开描述；确认后加密持久化并可被公开目录发现，拒绝不写入正式信息。
- [ ] 未确认提案受保护，不出现在公开目录或其他会话响应；重试确认不重复创建同一批资料。
- [ ] 提交能力不赋予读取、覆盖、审批或全库访问；导入后的正常读取仍需授权。
- [ ] 扩展 Skill 说明原始资料已被导入 agent 看到；核心接口及真实 CLI/桌面验证批量确认、拒绝和越权读取，支持的数据若已有备份能力须保持兼容。
