## Parent

[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

窗口关闭后 CLI 仍能访问有效授权；新申请通过系统通知提醒，用户从托盘或菜单栏打开待办，完全退出后停止访问。

关联规格用户故事：4、5、22、23。当前为待确认的正文草案，尚未发布。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 实现 Windows 托盘及 macOS 菜单栏入口，关窗不停止本地服务，也不结束聊天授权；可重新打开原待办。
- [ ] 每个新申请触发一次通知，状态查询、等待重试和重开窗口不重复提醒；通知不包含字段值、token 或密钥。
- [ ] 完全退出停止连接和读取，重启或崩溃恢复不复活旧 token；CLI 区分服务不可用与等待中的请求。
- [ ] 在本票确定后台生命周期及相关平台配置，保持 Flutter/Dart 技术基线，不要求独立安装系统服务。
- [ ] 核心服务测试覆盖生命周期，真实两平台演示关窗、通知、重开、退出及重启；后续加入持久化时保留相同失效契约。
