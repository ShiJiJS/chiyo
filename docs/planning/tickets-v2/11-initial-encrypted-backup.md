## Parent

[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

用户启用备份、另存恢复密钥并手动导出；没有原电脑密钥时仍能恢复当前信息，日常打开应用无需密码。

关联规格用户故事：50、51、52、53。当前为待确认的正文草案，尚未发布。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 桌面提供启用、保存独立恢复密钥、导出和导入流程；恢复密钥不与备份打包成同一个公开文件，也不进入日志。
- [ ] 在本票确定备份格式、版本及密钥封装，恢复密钥独立于本机数据库密钥；使用所选加密能力，不自行发明密码算法。
- [ ] 无原设备密钥的测试环境能恢复声明覆盖的当前信息，生成新的本机数据库密钥并建立系统保管。
- [ ] 排除活跃 token、运行实例凭据和待审批状态；恢复后的内容必须重新申请读取，不能将旧授权变回有效。
- [ ] 错误密钥、损坏、未知格式及恢复中断不会覆盖或破坏原资料；导出时保证资料一致，不依赖对正在写入的数据库简单文件复制。
- [ ] 核心接口和真实桌面完成往返恢复；本票先保证基础信息模型，完整跨平台和历史恢复由后续任务验收。加密、系统密钥和恢复链路通过前仅使用虚构资料。
