## What to build

申请进入桌面待办，agent 可等待或先做其他工作；超时后继续查询同一申请，用户可拒绝，过期申请不能批准。

关联规格用户故事：17、22、23、24、25、26、27、54。当前为待确认的正文草案，尚未发布。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 桌面待办显示聊天关联、自述用途、候选范围及剩余时长，提供批准和拒绝；用途仅供判断，不充当可信身份。
- [ ] 待审批默认有效期 30 分钟，可在设置调整；明确待处理、批准、拒绝、过期和取消，终态不能再次批准。
- [ ] CLI 支持提交、状态查询和有界等待；等待超时不取消请求，重复查询不新建申请或重复产生通知事件。
- [ ] 提供通用 CLI 使用说明，明确拒绝或过期后不自动重提，可继续独立工作；Codex Skill 后续复用这些规则。
- [ ] 可控时间下验证到期、并发处理、取消与批准竞争；真实桌面和 CLI 展示等待超时后查询原结果。系统通知由后台运行任务实现。
