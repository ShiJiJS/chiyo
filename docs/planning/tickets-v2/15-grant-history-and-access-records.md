[单机信息访问授权软件：第一版规格 · Issue #1](https://github.com/ShiJiJS/agent-info-manage/issues/1)

## What to build

用户查看曾批准的范围及实际成功、失败访问，从历史入口撤销有效授权后，CLI 的后续读取立即失败。

关联规格用户故事：35、46、47、48、49、58。当前为待确认的正文草案，尚未发布。

实施约束：Flutter 客户端、Dart 核心与 CLI；持久化使用 SQLite + Drift + SQLCipher，系统保管随机本机数据库密钥，备份采用独立恢复密钥。遵循已确认的固定字段授权、免应用密码及应用层安全边界；不引入云端、手机审批或 SSH 代理。具体通信、凭据和插件配置在相关任务内确定；共享语言不等于共享权限。主要测试边界为核心服务公开接口，并补本票相关的真实接入验证。

## Acceptance criteria

- [ ] 加密保存并展示批准时的会话、实际范围、时长及结束、过期、撤销事实；名称变化不改写原批准事实。
- [ ] 访问记录关联时间、会话、操作、信息及字段标识和结果，能区分批准范围与真正读取；无凭据失败不向请求者泄露私有目标存在性。
- [ ] 历史、诊断及通知不复制字段值、token 或密钥；公开接口不允许 agent 查看其他会话的私密记录。
- [ ] 从历史撤销后新读取失败，界面说明无法收回已披露内容；撤销与读取竞争仍符合核心契约。
- [ ] 在本票明确授权历史和访问记录的保留、清理策略，不擅自套用版本历史的 30 天；涉及未确认产品取舍时提出具体建议再对齐。
- [ ] 核心接口及通用 CLI/桌面展示完整记录与撤销，不依赖 Codex 专用适配；Codex 接入后沿用同一会话和生命周期记录契约。
