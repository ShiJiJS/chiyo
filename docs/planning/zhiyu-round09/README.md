## 如何开发

先在Mac完成正式Flutter客户端界面，以独立的、可重置的示例数据走通交互。HTML仅作外观参照；后续接真实服务时复用这些Widget、控制器和数据接口，不能再重新画一遍。

U01吸收原T01中当前需要的最小准备：确定查询/操作/错误结构、隔离预览入口、集中示例状态。旧T01中的真实服务适配和广泛代码整理留到后续按实际需要拆分，不另开第8张实现票，不要求先完成后台。

U01–U07在同一个预览程序中推进。跨页目标尚未完成时记录缺口；不能用永久空白页、无效跳转或成功提示替代完整流程。所有页面就绪后，在F01开始时检查整套预览，缺口返回相关U票修复，再规划真实功能。

界面完成只记“界面可预览”。后续模块分别记录“已接真实服务”“真实流程已验证”。无子Agent，无服务器同步；示例数据不得触碰真实资料或执行真实系统操作。
