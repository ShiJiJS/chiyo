# U02 压力资料与大字号

沿用冻结Round09；压力资料由独立Dart工厂生成，不改冻结HTML/JS。固定种子902026，200条普通信息及8条凭据（列表共208条）、50个真实目录（另有全部/未分类两个虚拟范围）、100个标签。保留原31项身份与正文，加入长中英文名称、重复名称、长标签、多层目录和时间平局；不增加真实文件或执行能力。

## 进入与重置

设计说明 → 资料规模 → 基准资料/压力资料。切换明确重置预览修改、查询和返回位置；先取消旧读取，再使用同一个来源刷新全部控制器。压力场景进入全部资料，基准回到自托管服务的Azure。重置保留当前规模；从回收站或展开阅读切换时返回三栏。普通页面不判断isMock，只有预览组合入口认识这个配置。

初始回收站采用冻结seed中的“旧部署笔记”，回收日期2026-10-20、原目录自托管服务及原正文。它不进入当前列表或关联候选，恢复产生更高版本，重置回到原回收事实。空场景开始写入时不能复活这条回收内容。

## 功能与显示边界

- 分组/排序作用于完整结果后再分页；全局组数和同名对象的类型化ID平局规则可重现。跨页关联打开要定位目标所在页，返回恢复原页、选择和滚动。
- 100标签仍使用一个标签小菜单及其共享选项搜索，不引入条件构造器。编辑表单的标签选择与跨页关联草稿在失败后保持，重试后从来源读回。
- 紧凑选择触发器有一行省略和完整名称提示；菜单保留全部名称。大字号目录将数量移到名称下、名称最多两行、缩进改为每级10（最多3级），正常字号继续原22缩进和右侧数量。字体和既有动效不缩小。
- 空/错误结果拥有独立滚动区，标题/筛选/底部操作不滚走；不复用另一栏的PrimaryScrollController。大字号下动作可经正文滚动到达，不与固定底栏重叠。
- 信息和凭据允许同字符串ID，但必须保留kind。合成关系可显式使用kind/id对象；有歧义的旧字符串引用拒绝加载，不能猜测成另一个种类或覆盖记录。正式适配继续使用现有类型化引用。

这是前端容量和可达性检查，不代表真实存储容量、实际OS输入或完整S5通过。最后的原生画面/录屏、两个尺寸和两主题的完整R01–R04对照、相关动效及实际输入仍按主票跟踪。证据记录工厂、输出hash和种子，避免提交442KB完整重复fixture或多份App。
