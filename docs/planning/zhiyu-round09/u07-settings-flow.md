# U07：设置实施流程

按冻结R13和S4设置合同继续，完整任务仍为#68。当前r5完成共用导航、外观、通知、请求等待/记录保留确认、目录标签管理、备份恢复、应用运行/维护/退出及原插件/旧模板整合，0/8且OPEN；Agent接入与整票交接仍需实现。

1. 共用设置侧栏与会话配置：已完成版本化来源、完整偏好命令、冲突/未知原操作查询及根级锁；原设计说明主题也走同源保存。通知概况预览可到准确待处理申请，打开不批准，不发真实系统通知。
2. 请求与记录已实现r2，目录与标签已实现r3。等待时间只影响新申请；缩短记录保留先读取准确清理范围并明确确认，授权状态/内容保留/回收与审计保留分别处理。目录复用既有空删除、层级和版本规则，标签已接通当前稳定ID管理和信息库同步；历史分类引用不复活已删除分类。
3. 备份与恢复已实现r4：独立密钥先另存、完整导出、归档/密钥检查后明确恢复到严格空库；无覆盖或合并策略。完整范围及恢复后的文件/分类/身份可读回，确定失败不改变数据、取消不提交、未知只查原回执，待清理可重试。全部为同源合成资源；真实存储/加密/Owner文件面板在F01复用既有实现。[合同及证据](../../development/zhiyu-macos-backups.md)。
4. 应用运行已实现r5：Mac菜单栏/后台偏好、材料与普通副本核查、准确退出确认、保存/进程退出失败及原操作未知核对。活跃或未确认材料保留，不重跑/终止程序；模拟退出后旧授权结束，预览进程仍可正常关闭与⌘Q。[合同与证据](../../development/zhiyu-macos-runtime-settings.md)。
5. Agent接入：连接/诊断、当前聊天关联、接入步骤/错误、Skill与hook信任边界；连接不授予资料权限，焦点填充默认不可用。此处仅说明/演示，不安装或注册真实hooks，不修改用户信任设置。
6. 整票正常/空/等待/失败、完整输入/操作/错误交接、隔离及S5核对；系统联合验收集中到固定候选。可以先继续能自动完成的UI，未验项保持开放。全部七项UI完成后交F01，不提前接正式库或Windows。

[实现与接口](../../development/zhiyu-macos-settings.md)记录准确源码、检查和后续接缝；沿用同一集中来源与正式组件，不另做HTML演示。
