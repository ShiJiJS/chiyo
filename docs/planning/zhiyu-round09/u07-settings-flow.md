# U07：设置实施流程

按冻结R13和S4设置合同继续，完整任务仍为#68。当前r3完成共用导航、外观、通知、请求等待/记录保留确认、目录标签管理及原插件/旧模板整合，0/8且OPEN；不能以主题保存代替备份、运行维护或Agent接入。

1. 共用设置侧栏与会话配置：已完成版本化来源、完整偏好命令、冲突/未知原操作查询及根级锁；原设计说明主题也走同源保存。通知概况预览可到准确待处理申请，打开不批准，不发真实系统通知。
2. 请求与记录已实现r2，目录与标签已实现r3。等待时间只影响新申请；缩短记录保留先读取准确清理范围并明确确认，授权状态/内容保留/回收与审计保留分别处理。目录复用既有空删除、层级和版本规则，标签已接通当前稳定ID管理和信息库同步；历史分类引用不复活已删除分类。
3. 备份与恢复：选择加密归档与恢复密钥、先校验再确认范围/冲突策略，失败保留可重试状态、取消不提交。仅合成资源，不能触碰真实密钥或系统文件选择；普通文件与凭据、模板定义等完整范围及恢复后的分类/身份要可读回。真实存储/加密/Owner文件面板在F01复用既有实现。
4. 应用运行：Mac菜单栏和关闭窗口继续运行、服务状态、活动材料及普通附件维护、完全退出前的会话/清理说明。状态来自可替换来源，不能以材料清理推断程序结束。仅演示系统效果；预览本身仍保留正常关闭与⌘Q。
5. Agent接入：连接/诊断、当前聊天关联、接入步骤/错误、Skill与hook信任边界；连接不授予资料权限，焦点填充默认不可用。此处仅说明/演示，不安装或注册真实hooks，不修改用户信任设置。
6. 整票正常/空/等待/失败、完整输入/操作/错误交接、隔离及S5核对；系统联合验收集中到固定候选。可以先继续能自动完成的UI，未验项保持开放。全部七项UI完成后交F01，不提前接正式库或Windows。
