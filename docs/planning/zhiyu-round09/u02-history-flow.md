# U02 内容版本与回收流程

沿用冻结Round09的信息库、版本弹窗与回收站方向，复用现有菜单、弹窗、颜色、120/150/180ms动效。主人需要先核对历史内容，再恢复；永久清理需要单独确认对象。主导航仍为五项，回收站是信息库内部目的地。

## 状态与动作

内容版本：详情菜单 → 读取版本摘要 → 无历史/失败重试/选择旧版本 → 读取完整对比 → 核对恢复 → 提交中 → 新版本读回。切换版本不写资料。比较覆盖名称、用途、目录、标签、定义、全部值和关联，不只列前四字段。冲突后必须重新读取并比较；未知结果先读回，不直接重交。退出保留信息库查询及列表位置。

回收：详情菜单 → 核对对象 → 回收提交 → 当前列表与计数更新。回收站：摘要列表 → 按需读原快照 → 恢复或永久清理确认 → 提交 → 重新读取列表。空、等待、读取失败、提交失败和对象被其他操作改变均可重现；失败保留当前对象，不自动关闭。恢复后可打开该资料；返回信息库保留原查询。

## 数据合同与安全语义

版本与回收列表只包含摘要，正文只在主人查看比较或回收快照时读取。普通信息与凭据身份分离；本轮普通版本/回收接口拒绝凭据，凭据生命周期归U03。保存旧内容形成不可变历史；恢复产生更高版本，操作身份重试不得重复产生版本或回收条目。

遵守ADR0014：历史保留原分类事实，恢复只用现存分类，缺失目录归未分类，缺失标签跳过。恢复前核对资料版本与目录版本；缺失字段要求先显式回收恢复，不能借旧版本复活。缺失关联目标显示历史身份但不恢复成可用链接。回收恢复不复活授权；预览不持有任何真实授权。

修订/回收保留30天，来源在读取及变更前清理到期内容；使用可注入时钟确定性验证。永久清理移除该资料的预览历史、回收正文和成功缓存。幂等指纹使用不可逆摘要，不留原字段JSON。预览固定合成fixture仍供“重置”恢复，不把内存清理宣称为磁盘安全擦除。

正式F01必须对接真实字段ID、恢复映射、回收事实和授权失效事务；本轮模板key只是展示合同，不能替代这些真实身份。没有真实库/钥匙串/系统权限操作。

## 验收重点

两尺寸、明暗主题与200%文字下检查长内容可滚动、固定操作栏、对比前后身份和风险提示。验证保存→读取旧版→恢复→读回、冲突重比、失败不变、回收隔离、分类删除后恢复、过期清理、永久清理后旧操作不可重建及末页收缩。实际OS输入与完整S5保留集中验收，本轮离屏/Widget结果不替代它们。
