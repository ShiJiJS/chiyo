# F01：后续阶段规划：界面完成后拆分真实功能、测试与Mac交付

GitHub：[#69](https://github.com/ShiJiJS/agent-info-manage/issues/69)。发布与依赖已回读核对，2026-10-25。

状态：published-deferred-until-ui-complete。本票是后续工作的继续入口，不是现在开发全部后台的任务；使用documentation标签，不加ready-for-agent。

当前平台：Mac ARM64；Windows适配后置。最新目标已恢复持续Mac开发；本票仍等待全部7项前端完成，再按实际能力规划真实接入。按[Mac接手计划](../macos-continuation.md)继续；本票在Mac界面完成后规划真实接入，不提前实现后台。

## 这张票为什么保留

本轮只安排7张前端任务，把整套知予界面用示例数据做出来。等这些界面完成后，由本票重新梳理后续开发，避免丢失本地服务、权限、旧资料兼容和打包等内容。

## 开始前检查什么

- U01–U07完成，实际Mac ARM64 Flutter程序可以运行；有明暗主题、两个桌面尺寸、主要交互录屏和与冻结原型的对照。
- 在同一程序复查服务器→应用/维护文档/凭据→使用申请→审批→历史；提案批准→信息库变化；插件安装预览→新建对应类型；档案→简历文件版本等完整路径。全用示例，不访问真实资料。
- 界面缺口记回相关U票修复，明显遮挡、布局或交互问题不能留到后台阶段掩盖。
- 读取本轮各票的已验/未验记录和最终数据接口；重新核对代码、PR和GitHub已有问题，不只读取这份旧计划。

## 之后打算分哪几阶段

1. **按模块接真实功能**：先复核前端状态，再复用/补齐本地接口，最后用隔离资料库完成真实业务测试及视觉回查。
2. **兼容与整体测试**：检查旧资料、插件缺失、迁移失败、备份恢复及跨页流程，明确仍由旧验收票承担的事项。
3. **Mac交付**：复用#50，安排本机ARM64整包、固定身份、安装升级与回退，清理重复App、dSYM及旧构建；系统联合验收集中到固定候选。Windows字体/窗口/CI和安装工作在Mac主线稳定后再排。

本票完成时产物是经过核对的下一批规格和实现票，不代表这些功能已经开发完成。

## 待拆分的内容

| 模块 | 后续具体做什么 | 先核对可复用什么 |
| --- | --- | --- |
| 外观与信息库 | 保存主题，接通目录/标签/关键词/类型查询、列表详情和编辑；切换资料不串内容 | 现有分类、标签、共享控件和读取接口 |
| 服务器、应用及关联 | 保存模板字段、模板快照和显式关联，支持从服务器找到应用并返回 | 现有字段身份、凭据关联与版本规则 |
| 个人档案 | 教育/工作经历逐条保存、排序；每个可授权字段保持独立身份 | 已有字段授权；新增经历不得扩大旧授权 |
| 文档与普通文件 | 文档阅读、支持的文件预览、版本替换/恢复、授权交付 | 已有文件加密入库、版本、回收和备份，避免重做 |
| 模板插件 | 声明式包校验、安装/更新/停用/移除，旧资料保留快照，套模板先预览再保存 | 旧手工模板与通用资料，缺插件时仍可读 |
| 插件专属设置 | 把SSH主机信任放进服务器插件设置，保留单台主机入口 | 宿主已有SSH信任能力；先不做任意插件执行代码 |
| Agent查找与录入 | 关键词/类型/标签查找，全部标签默认可见；按模板提交录入修改提案 | 现有公开目录、提案及Skill；正文/文件/密钥继续按权限 |
| Agent制作模板指引 | 说明怎么选现有模板、准备新JSON包、检查格式并交给主人安装 | 按skill-manager管理个人Skill；不让Agent绕过安装确认 |
| 审批与凭据使用 | 把真实申请、批准/拒绝/撤销/到期、运行时注入接进新界面；Mac焦点填充继续由#51独立评估，默认关闭 | 已有有效期内复用、每次操作独立记录；不改成每条命令重批 |
| 提案和历史 | 接通修改差异、批量确认、冲突、对象删除后的历史、单次授权多次使用 | 已有审阅/审计/删除身份保留，不重建一套历史真相 |
| 全局设置及平台能力 | 通知、期限、保留、运行维护、正常退出、Agent接入、备份恢复 | 既有实现和Mac平台适配 |
| 兼容与交付 | 新旧数据混合备份恢复、升级失败回退、名称改为知予而技术标识保持兼容 | 原数据/密钥位置、CLI、hooks、Skill身份及安装清理约定 |

上述是待核对的范围，不是12张预先确定的新票。根据界面最终结构和实际代码合并/细分；原T01–T20草稿也只作参考。原T01中只有最小前端准备并入U01，剩余重构确有必要才安排。若新增数据模型，相关任务当时就处理重启、备份和恢复，不拖到总验收补救。

## 后续必须继续遵守

- Mac优先，Windows适配后置；无服务器同步、无子Agent，不触碰真实私人资料来做演示。
- 界面不重画。实际数据实现替换示例来源，布局、交互和动画保持冻结原型约束；服务失败不回退假成功。
- 标签默认对接入Agent可见，不设计私人标签或公开开关；标签可见不等于获准读取正文或使用凭据。
- 领域与插件规格中尚未通过真实实现验证的容量、迁移和外部设置边界，在拆分时逐项核对；有新的范围取舍写清影响。
- 复用#44工具/文件、#46生命周期、#47通知、#48整套UI及#50 Mac交付；#42/#43/#49保留已关闭范围，新接缝定向回归。#41剩余Windows回归、#45双机迁移及#18/#23/#30等Windows遗留后置，状态与原标准不改；#51不作为当前UI门槛。详见[旧票归属](../macos-continuation.md)。
- 从整合已有Mac适配、PR #61修正和本轮前端成果的Mac分支继续；核对最新远端，不按旧hash覆盖当前修改。
- 分配数据版本前核对Mac库22/条件23、备份11及最新源码；品牌变化不改bundle ID、Keychain、资料容器、CLI/Skill/hooks身份。
- UI阶段不请求个人系统授权；Keychain、通知点击、睡眠和真实Agent联合检查在同一最终候选集中安排，不承诺不同新签名永久免提示。
