## What to build

左边选目录和标签，中间找资料，右边看详情，保留你要求的中间列表。查找只用关键词、类型和标签，分组与排序各用一个小按钮；普通信息、文件资料和凭据都能在同一列表找到。

## Acceptance criteria

- [ ] 实现目录＋关键词＋单类型＋单标签、分组及排序；旧无模板资料显示通用类型，后续模板类型自动进入类型菜单。
- [ ] 统一摘要但不合并信息/凭据权限模型；凭据分类加密保存，目录非空判断覆盖凭据；标签删改保持稳定对象身份。
- [ ] 完成清除、全部资料、换目录、后台刷新、分页、无结果和关联返回的显式状态规则；不做复杂筛选构造器。
- [ ] 200信息/50目录/100标签与长标题检查；R01–R03的滚动轨道、键盘和两尺寸合格，查询不读取正文。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。

## Demo

按目录→类型→标签→关键词找到资料，切换分组/排序后查看详情，清空结果再返回。
