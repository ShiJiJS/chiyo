# T12：Agent发现类型、验证插件包及制作指引

状态：draft-awaiting-approval。确认拆分后才发布并添加 ready-for-agent。

## What to build

Agent能发现已安装模板定义、生成一个缺少的声明包并只读验证，再交给用户安装。

## Specification

[S2](../../../specs/zhiyu-round09/02-plugin-contract.md)、[S4](../../../specs/zhiyu-round09/04-flows.md)；要求：S2-P05、S4-A02。所有票同时遵守 S5-V06、S6 的实现与证据约束。以冻结 Round09 为参照，原型演示数据/假成功不得进入正式代码。

## Acceptance criteria

- [ ] CLI/服务提供兼容版本的模板元数据/定义及包验证；不暴露记录值、私人标签目录或关系图。
- [ ] 保留旧catalog输出兼容；新增字段可按协议能力发现，未知hostApi明确报错，不添加任意复杂查询表达式。
- [ ] Agent无直接安装/启用审批能力；不可信instructions不能覆盖授权边界，恶意包验证无副作用。
- [ ] 更新仓库接入文档和受管理Skill制作指引；分发按skill-manager要求执行并记录来源，不直接改生成目标。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。

## Demo

独立CLI列模板→关键词/类型发现→生成虚构域名包→验证→用户安装后再发现，不读取任何字段值。
