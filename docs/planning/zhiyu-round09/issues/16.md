# T16：完整录入提案工作台与差异阅读

状态：draft-awaiting-approval。确认拆分后才发布并添加 ready-for-agent。

## What to build

用新样式审阅新增、修改、删除和批量提案，查看整理结果与冲突，保存后能找到对应资料。

## Specification

[S4](../../../specs/zhiyu-round09/04-flows.md)、[S3](../../../specs/zhiyu-round09/03-library.md)、[S5](../../../specs/zhiyu-round09/05-fidelity.md)；要求：S4-A04、S3-L04、S5-V05。所有票同时遵守 S5-V06、S6 的实现与证据约束。以冻结 Round09 为参照，原型演示数据/假成功不得进入正式代码。

## Acceptance criteria

- [ ] R11实现队列/详情/决定区和字段差异，不仅新增单条；混合批量保留原事务、冲突和选择语义。
- [ ] 新类型按章节/条目展示，但最终决定仍映射固定字段/对象；附件和凭据相关变更不隐藏关键风险。
- [ ] 补齐原型未画的批量/删除/冲突状态及布局，失败保留选择，处理后列表状态与信息库一致。
- [ ] 整理完成结果只读，修改前后与历史快照真实；回收、修订和提案跳转不可用目标有明确反馈。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。

## Demo

提交混合批量→审阅差异→遇版本冲突→重提保存→跳转资料→查看整理结果。
