# T10：服务器插件中的SSH主机信任设置

状态：draft-awaiting-approval。确认拆分后才发布并添加 ready-for-agent。

## What to build

全局设置里不再单独放SSH主机信任，而是在服务器插件自己的设置中管理。查看某台服务器时，也能直接核对它的身份；没有专属设置的插件就不显示这个入口。

## Specification

[S2](../../../specs/zhiyu-round09/02-plugin-contract.md)、[S4](../../../specs/zhiyu-round09/04-flows.md)；要求：S2-P04、S4-A01。所有票同时遵守 S5-V06、S6 的实现与证据约束。以冻结 Round09 为参照，原型演示数据/假成功不得进入正式代码。

## Acceptance criteria

- [ ] 全局侧栏不再单列SSH，旧入口重定向；没有设置能力的插件不显示空页签。
- [ ] 只内置服务器可挂接宿主注册面板；外部包不能伪造面板能力，UI和执行读取同一核心信任状态。
- [ ] 更改host/port、未取得指纹、指纹变更、导入失败、撤销和停用均有明确状态；停用保留查看/撤销维护入口。
- [ ] R04/R08通过，实际known_hosts及核心校验回归；信任主机不等于批准使用凭据，不用原型假指纹。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。

## Demo

服务器→主机身份→插件设置→导入/核对虚构主机→改端口→撤销；检查停用后的维护入口。
