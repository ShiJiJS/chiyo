## What to build

全部新资料和旧资料可一起备份恢复，旧手建模板从主流程退场而内容与兼容能力仍可用。

## Specification

[S1](../../../specs/zhiyu-round09/01-domain-and-data.md)、[S6](../../../specs/zhiyu-round09/06-architecture-and-delivery.md)；要求：S1-D05、S1-D06、S6-C03。所有票同时遵守 S5-V06、S6 的实现与证据约束。以冻结 Round09 为参照，原型演示数据/假成功不得进入正式代码。

## Acceptance criteria

- [ ] 在各增量已支持自身备份的基础上，完成混合旧资料/插件快照/条目/关联/附件/凭据的整库恢复矩阵，不补一个之前一直丢数据的备份实现。
- [ ] 正式主入口只保留模板选择/插件管理，旧手建模板仍可查看和转换；仅在所有调用迁移后删除旧编辑实现。
- [ ] 损坏包/缺插件/删除分类/关系目标回收和旧备份1–10走正确回退；失败不更改正式库，活跃授权和临时材料不复活。
- [ ] 更新迁移/恢复说明与实际版本兼容表，提供真实SQLCipher故障回滚及旧读取器拒绝新格式证据。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。
