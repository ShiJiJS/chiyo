## What to build

在设置里选择Agent制作的模板文件，先看到它会增加什么资料类型、包含哪些字段，再确认安装。安装后新建资料时就能选这个类型，例如增加“域名资料”；不需要你自己逐项搭建模板。

- [ ] 冻结hostApi1的生产schema与验证器、格式/容量边界和错误定位，附合法及非法包夹具；不是复用原型宽松验证。

- [ ] 域名与服务器实际共用渲染和保存接口；包/状态加密持久化，刷新重启、失败回滚和备份恢复完整。
