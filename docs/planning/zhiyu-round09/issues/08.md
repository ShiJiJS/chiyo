# T08：从JSON安装模板插件并创建第一项资料

状态：draft-awaiting-approval。确认拆分后才发布并添加 ready-for-agent。

## What to build

在设置里选择Agent制作的模板文件，先看到它会增加什么资料类型、包含哪些字段，再确认安装。安装后新建资料时就能选这个类型，例如增加“域名资料”；不需要你自己逐项搭建模板。

[S2](../../../specs/zhiyu-round09/02-plugin-contract.md)、[S1](../../../specs/zhiyu-round09/01-domain-and-data.md)；要求：S2-P01、S2-P02、S1-D06。所有票同时遵守 S5-V06、S6 的实现与证据约束。以冻结 Round09 为参照，原型演示数据/假成功不得进入正式代码。

## Acceptance criteria

- [ ] 冻结hostApi1的生产schema与验证器、格式/容量边界和错误定位，附合法及非法包夹具；不是复用原型宽松验证。
- [ ] 所有者预览确认安装；禁止覆盖builtin、重复身份、未知/可执行属性及远端资源，不声称作者已验证。
- [ ] 域名与服务器实际共用渲染和保存接口；包/状态加密持久化，刷新重启、失败回滚和备份恢复完整。
- [ ] 设置插件入口及多模板选择可用；R07走通，安装只增加定义，不保存虚构样例为真实资料。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。
