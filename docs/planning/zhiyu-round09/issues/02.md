## Acceptance criteria

- [ ] 采用冻结Round09的顶栏、字体、颜色、图标及圆角；先完成R01和R13的外观页，不用旧四主题框架换两种颜色交差。
- [ ] 旧主题偏好映射到明亮；保存/失败/重启读回走真实偏好存储，其他配置不丢失。
- [ ] 统一现有按钮、菜单、提示、弹窗、滚动与focus控件的明暗状态及动效，列出其他页面后续迁移范围。
- [ ] 只改展示品牌；数据路径、CLI、Skill、会话关联及hooks信任保持兼容，不能全局字符串替换技术标识。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。
