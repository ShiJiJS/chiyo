## 实施顺序与状态边界

1. 接通公开目录查询与类型/标签筛选，先用独立 CLI 核对公开范围和未授权拒读。
2. 接通真实请求提交和原请求查询。同一会话的同一操作标识重试返回原结果；相同标识携带不同意图应报冲突。不能仅按用途或字段内容去重，否则会吞掉合法的新申请。
3. 接通收件箱列表、计数、详情与请求定位；刷新必须覆盖批准、拒绝、撤销、到期和会话结束，不能只比较待批数量。
4. 补齐 Mac 接入说明、连接失败诊断及与 #72 的联调。安装文件、服务连接和宿主信任是三个不同状态，分别如实显示。

这里的“重开/查回”区分三种情况：页面重新打开或网络重连，在服务及会话仍有效时查回原请求；应用服务关闭后，沿用核心取消待批及结束授权的规则，主人查询无正文历史结果，旧 AI 会话不能凭公开请求 ID 找回能力；备份恢复仅恢复历史，不恢复待批或活跃授权。异常中止后无法确认的结果明确为未知，不编造处理记录或自动重放申请。不得为实现收件箱而持久化可复活的会话秘密。

## 联调收口清单

- 复用已接入的配套文件诊断、会话选择和接入说明，在 #72 联调时再次核对：接入诊断分别显示本机服务是否可用、交付工具是否完整、宿主是否完成安装与信任；无法观察到的状态明确为“无法核对”，不能把文件存在、准备成功或未发现配置当作已信任或未安装。
- 会话页面展示实际可观察的公开关联信息；存在多个会话时由主人明确选择，不按最近请求猜测“当前聊天”。查看会话或跳转申请不会创建申请、批准或恢复能力。
- 申请来源区分服务确认的会话关联与 Agent 自报名称/用途；没有提供的字段如实说明，不冒充已验证身份。诊断不读取私密关联文件来找回能力。
- 完成接入说明及 #72 联调：相同请求在 App 和 AI 端得到一致处理结果；断开、未知信任、多会话、过期观察结果都有明确反馈。

## 实现范围

- 复用 `packages/info_core/lib/agent_server.dart`、现有 CLI、DesktopRuntime、prepare_codex/codex_bundle/codex_hook 和既有会话接入，适配新界面 Agent 设置与审批来源，不另建协议、云服务或演示请求发生器。
- 实现 ADR0015 已确认的公开目录发现：支持关键词/类型/标签查询，标签名称与归属默认可见；未授权不返回字段正文、文件原文、密钥、目录树或关系图。现有接口未实现部分须补齐并验证，不能把 UI 文案当实现。
- 请求由 AI 提交，保存真实请求身份、会话、请求字段和提交时固定的等待截止时间；重试查回原申请，不能生成重复审批。变更等待设置不延长既有请求或授权。
- 收件箱数量、分页、过滤、详情、Agent 页跳转来自同一真实数据源；覆盖多申请、空态、断线重连、请求在其他入口被处理/到期。更新丢失后可重新查询，页面不能假定推送必达。
- 复用已有可信私密会话证明与仅撤销凭据；聊天公开 ID 不能鉴权、领取或找回能力。诊断仅显示必要公开元数据，不泄漏证明、配置、聊天正文。安装、命令准备与宿主正式信任分别显示事实，不根据文件存在猜就绪。
- 提供 Mac 的实际接入操作说明和失败诊断；不在本票自动安装个人 Skill/hooks 或更改全局信任。已有合成项目授权仅限该项目，不能泛化到其他项目。
- 系统通知不是接收申请的唯一通道：前台/页面重开可查询当前真实待批请求，应用服务重启则查询历史终态或明确未知结果。系统通知授权、投递、点击仍归 #47，首批允许通过 App 收件箱处理；通知点击绝不批准申请。

## 验收标准

- [ ] 用独立 CLI/服务客户端查询 M01（#70） 合成库，按关键词/类型/标签得到准确公开元数据，未获准读取正文被拒绝。

- [ ] 不同聊天不能按公开 ID 冒用能力；连接状态和信任未知有真实错误提示，日志不含私密证明。
- [ ] 与 M03（#72） 的请求状态合同明确且使用同一来源；批准/拒绝后的变化能返回 AI 查询端。
- [ ] 记录 Mac 实际 CLI 接入证据与安装说明；真正宿主聊天的联合验证由 M04（#73） 完成，不能以测试直接调用核心替代。
