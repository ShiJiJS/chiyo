## Acceptance criteria

- [ ] 多请求搜索/分页/状态切换、范围补选减选、条目展开、文件版本和期限选择使用实际前端交互。
- [ ] 凭据、注入位置、CLI启动说明/填充目标清楚呈现，相应tips和授权期复用说明符合原型。
- [ ] 批准/拒绝/撤销/到期/会话结束/冲突/未知执行结果由确定的示例状态触发；不执行真实命令或批准真实请求。
- [ ] 使用正式Flutter组件与控制器；从界面入口走到示例结果，正常、空数据、等待和失败状态可重现。不是另一套HTML或截图展示。
- [ ] 1440×900、1280×800、明暗主题、200%文字、键盘和本票相关动效完成S5对照；提交实际Flutter截图/录屏，注明示例数据。
- [ ] 预览不连接真实资料库、秘密、hooks或系统执行能力；数据集中维护并可重置，未来通过同一接口换真实服务，不靠逐页isMock分支。
- [ ] 记录页面需要的数据、操作和失败结果，并完成相关前端检查；未接后台内容汇总给F01，不以示例成功宣称真实功能完成。
