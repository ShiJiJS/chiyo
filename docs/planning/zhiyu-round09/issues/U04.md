## What to build

入口放在设置的插件管理中，不占左下角或日常导航。完成插件管理全过程和旧资料改用模板的预览，让用户先看清安装、更新、停用、移除与字段对应关系。

## Acceptance criteria

- [ ] 示例包的安装预览、格式错误、更新差异、停用/移除影响和缺插件通用展示都能操作；不依赖生产插件安装器。
- [ ] 服务器插件专属设置可进入，无设置能力的插件不出现空页签；单台主机身份、缺指纹、变化和停用状态可演示。
- [ ] 旧资料套模板先预览对应/未对应/冲突字段，再更新示例数据；缺失长流程先补有限状态图，不能用单个成功toast替代。
- [ ] 使用正式Flutter组件与控制器；从界面入口走到示例结果，正常、空数据、等待和失败状态可重现。不是另一套HTML或截图展示。
- [ ] 1440×900、1280×800、明暗主题、200%文字、键盘和本票相关动效完成S5对照；提交实际Mac Flutter截图/录屏，注明示例数据、Mac字体和输入检查范围。
- [ ] 预览不连接真实资料库、秘密、hooks或系统执行能力；数据集中维护并可重置，未来通过同一接口换真实服务，不靠逐页isMock分支。
- [ ] 记录页面需要的数据、操作和失败结果，并完成相关前端检查；未接后台内容汇总给F01，不以示例成功宣称真实功能完成。

## Demo

从设置进入插件→预览虚构域名模板→模拟安装→查看新增类型；演示更新/停用/移除影响，打开服务器插件设置，再给旧资料套模板，查看无法对应的字段如何保留。

在Mac原生预览的明暗主题和两个指定内容尺寸下对照S5平台参考，提交实际Flutter截图及正常速度交互录屏；Windows历史图不能代替本票Mac结果。
