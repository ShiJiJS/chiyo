# T05：应用服务模板与资料关联双向浏览

状态：draft-awaiting-approval。确认拆分后才发布并添加 ready-for-agent。

## What to build

录入一个应用并关联它运行的服务器、维护文档或凭据，从两端找到同一关联并返回原查询。

## Specification

[S1](../../../specs/zhiyu-round09/01-domain-and-data.md)、[S3](../../../specs/zhiyu-round09/03-library.md)；要求：S1-D04、S3-L02、S3-L03。所有票同时遵守 S5-V06、S6 的实现与证据约束。以冻结 Round09 为参照，原型演示数据/假成功不得进入正式代码。

## Acceptance criteria

- [ ] 应用模板与服务器共享定义/渲染接口，关系持久化为同一事实，反向展示无双份可冲突数据。
- [ ] 凭据关系复用既有关联事实；读源资料不能读取目标资料或密钥，Agent普通catalog不返回私人关系图。
- [ ] 支持选择/移除关系、并发冲突、目标回收/恢复和历史查看；禁止重复/自指，普通资料互链不误当目录防环。
- [ ] 关联参与修订/回收和备份；跨筛选跳转及返回可解释，R04长关联列表不压缩正文。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。

## Demo

应用关联服务器及密钥→两端查看→部分批准服务器字段→验证目标未获授权→回收目标并检查失效提示。

Windows优先，无子Agent、无服务器同步。仅按本票范围开发，不顺手重写全仓或关闭历史父票。实现文件位置由当前代码决定，先阅读规格的模块边界；不是机械照搬HTML结构。
