# T04：内置服务器模板完成录入、持久化与分组阅读

状态：draft-awaiting-approval。确认拆分后才发布并添加 ready-for-agent。

## What to build

软件预装服务器模板，填写主机地址、端口、登录用户、用途等信息后，按原型分区展示，不再把所有字段平铺成长表。保存并重新打开后内容完整；Agent申请其中某个字段时，仍只得到你批准的部分。

## Specification

[S1](../../../specs/zhiyu-round09/01-domain-and-data.md)、[S2](../../../specs/zhiyu-round09/02-plugin-contract.md)、[S3](../../../specs/zhiyu-round09/03-library.md)；要求：S1-D01、S1-D02、S1-D06、S2-P02、S3-L03。所有票同时遵守 S5-V06、S6 的实现与证据约束。以冻结 Round09 为参照，原型演示数据/假成功不得进入正式代码。

## 开发顺序

本票复用已完成的[U02](U02.md)界面，不再另外画一套。

- [ ] 先复核前端：正常和异常状态齐全，若有遗漏先在同一套界面补好。
- [ ] 再接真实本地服务：替换示例数据来源，优先复用现有接口，缺失能力才新增。
- [ ] 最后验证：真实隔离资料库/CLI走通本票流程，检查保存、重启、权限及失败恢复，再对比样式和动画。

下方原有界面要求作为复核标准，不重复实现。UI票完成不等于本票完成。

## Acceptance criteria

- [ ] 内置定义通过生产验证器与宿主通用表单/章节渲染器，不把server ID写死为独立数据模型。
- [ ] 保存稳定实例字段ID、定义映射及不可变模板快照；失败保留草稿，重启、修订和本票新增数据的备份恢复完整。
- [ ] 旧无模板信息继续通用阅读；服务端校验字段类型、必填和版本冲突，CLI旧扁平读取兼容。
- [ ] 用合成服务器完成部分字段批准读取，证明新布局未扩大grant；R01的字段层级、连接概览和反馈符合原型。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。

## Demo

从新建选服务器→保存→重启→展示→独立CLI申请一个字段→批准并读取，其他字段被拒绝。
