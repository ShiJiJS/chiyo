# 知予 Mac M01：新界面接入真实资料保存与重启恢复

## 用户结果与范围

主人在现有知予界面创建、查看、修改和管理普通资料，关闭重开仍能读到准确内容。首批支持普通文字字段、服务器/应用资料、文档正文、档案经历的独立叶字段，以及目录、标签和资料关联。普通附件原文、托管凭据和插件安装不在本票；其入口明确未接入，不显示示例成功。

属于 #69 的最小可用阶段；无其他新实现票前置。#62–#68 的非阻塞外观验收不阻挡本票；影响编辑、保存或错误提示的界面问题必须在本票交付前解决。当前为实施中、尚未完成：已提交共享界面组合入口、持久保存回执、字段布局与迁移/备份基础；正式资料来源、启动接入及完整验收仍待完成。进度见 [实施记录](../../../development/zhiyu-macos-real-m01.md)，不以基础测试通过代替本票验收。

## 复用与实现接缝

旧版 #24 已按 Windows 优先范围交付，本票复用其核心事务与身份规则，新增的是 Round09 界面到真实来源的适配；不重开 #24，也不把其旧界面/Windows 证据当作本票完成。

- 复用 `apps/desktop/lib/main.dart`、`desktop_bootstrap.dart`、`desktop_runtime.dart` 的正式启动和生命周期，以及 `packages/info_core` 的 InformationService/OwnerAccess、`packages/info_storage` 的 SQLCipher/密钥/迁移能力；不重建另一套资料库或授权服务。
- 为 `apps/desktop/lib/workspace/workspace_source.dart` 及相关资料合同实现正式适配，在组合入口接入现有页面。生产入口不能构造 SampleWorkspaceSource；预览入口不可静默转为个人库入口。维持正式 bundle ID、Keychain service/account、资料容器与 CLI 身份兼容，不把预览身份误用于正式资料。
- 审阅 `zhiyu-library-contracts.md`、`zhiyu-content-contracts.md`；将模板槽位、经历叶、关联引用映射到真实稳定信息项/字段身份。纠正内容保留身份；新增、替换、恢复按核心规则分配身份，不能扩大既有授权。已有不支持类型保留且如实只读，不能丢字段或强行降级。
- 保存采用版本检查与事务；资料、修订、关系、回收状态和无正文操作回执一致落盘。重复提交同一操作不重复创建；结果未知先查原操作，跨导航/重启找回，不能凭列表变化猜成功或自动重放。错误保留可安全恢复的输入，不能把敏感草稿写明文日志。
- 核对当前 schema/备份版本再分配新版本；任何新增持久字段同时处理旧库升级及现有备份导出/恢复兼容。完整备份 UI 后置，不等于允许本票新增数据不可恢复。主题等无关设置不顺便重置。
- 正常退出确认保存/关闭结果；密钥不可用、错误密钥或迁移失败时保留原库并停止服务，禁止新建空库覆盖或回退示例数据。原生退出、菜单、睡眠专项仍由 #46 收口。

## 验收标准

- [ ] 从无样例种子的隔离真实加密库创建上述资料；目录、标签、关联、文档正文及经历叶可正确读取与修改。
- [ ] 正常退出及独立进程重启后数据/身份/修订一致；真实启动不会自动注入阿里云服务器等样例。
- [ ] 删除、回收、恢复遵循已有身份及授权失效规则；不支持类型和未修改旧字段完整保留。
- [ ] 版本冲突、重复保存、确定失败、提交后响应丢失及重启核对覆盖真实持久事务；没有假成功或重复资料。
- [ ] 隔离旧库升级和新增字段备份往返通过；错误密钥/升级失败不覆盖原库，测试日志无正文或密钥。
- [ ] 新界面的实际业务接入、相关自动化回归和 Mac 构建通过，记录准确源码、已验/未验范围；不以构建代替实际输入验收。

## 边界

在 `codex/zhiyu-macos` 工作，Mac ARM64 优先；不改 Windows 分支、不触发 Windows CI。无云同步、无演示模式、无主人发起访问申请。验证使用隔离合成资料，尽量复用固定候选集中处理系统授权，不承诺换签名后永不弹窗。#42 的旧持久化结论保留，本票验证新界面接缝，不重开或冒用旧整包结果。
