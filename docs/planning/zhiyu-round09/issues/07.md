# T07：文档与普通文件的阅读、版本和交付界面

状态：draft-awaiting-approval。确认拆分后才发布并添加 ready-for-agent。

## What to build

文字说明按文档方式阅读，PDF等支持的文件可以预览，并显示文件格式、用途、大小和版本。还要能替换文件、看旧版本、恢复版本和另存；Agent领取文件继续沿用现有审批流程。

## Specification

[S3](../../../specs/zhiyu-round09/03-library.md)、[S4](../../../specs/zhiyu-round09/04-flows.md)；要求：S3-L03、S3-L04、S4-A01。所有票同时遵守 S5-V06、S6 的实现与证据约束。以冻结 Round09 为参照，原型演示数据/假成功不得进入正式代码。

## Acceptance criteria

- [ ] 文档支持纯文本/安全Markdown，PDF只读预览；不支持格式与解析失败明确回退到元数据及本机打开。
- [ ] 沿用SQLCipher附件、版本、交付和材料清理；预览不生成永久明文缓存，普通附件和凭据文件不可混用。
- [ ] 展示格式、用途、包含内容类别、版本与大小；真实文件预览替代原型演示纸面，混合信息不丢文字字段。
- [ ] 补充原型缺失的版本长流程状态；R06可执行替换→旧版→恢复，独立CLI领取获批版本并核对撤销/到期。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。

## Demo

导入虚构简历→预览→换版→恢复版本→申请附件→领取受管副本；检查错误格式的回退。
