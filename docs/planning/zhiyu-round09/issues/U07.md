## Acceptance criteria

- [ ] 通知、期限与保留、目录标签管理、备份/恢复密钥及错误、后台运行/维护/退出、Agent接入均有完整界面状态。
- [ ] 主题/设置在示例会话内读写；系统通知、退出、备份、hooks信任等效果仅演示，不修改真实系统配置。
- [ ] 设置使用Mac菜单栏、系统通知、后台运行和⌘快捷键文案；平台不支持的能力明确显示不可用，焦点填充默认关闭，不照搬Windows路径或成功状态。预览进程本身仍能正常退出。
- [ ] 设置各入口注册到U01的预览导航中；本票检查设置自身路径。其他UI页面全部完成后再做整套跨页对照，由F01承接检查和后续拆分，不把其他模块的后台列成本票前置。
- [ ] 使用正式Flutter组件与控制器；从界面入口走到示例结果，正常、空数据、等待和失败状态可重现。不是另一套HTML或截图展示。
- [ ] 1440×900、1280×800、明暗主题、200%文字、键盘和本票相关动效完成S5对照；提交实际Mac Flutter截图/录屏，注明示例数据、Mac字体和输入检查范围。
- [ ] 预览不连接真实资料库、秘密、hooks或系统执行能力；数据集中维护并可重置，未来通过同一接口换真实服务，不靠逐页isMock分支。
- [ ] 记录页面需要的数据、操作和失败结果，并完成相关前端检查；未接后台内容汇总给F01，不以示例成功宣称真实功能完成。
