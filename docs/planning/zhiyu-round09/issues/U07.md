# U07：全局设置与完整预览串联

状态：draft-awaiting-approval。界面阶段票；完成表示可预览，不表示真实功能已完成。

## What to build

完成其余设置页的界面，把全部主页面接进同一个可运行的预览程序。

## Specification

[S5 视觉与动画](../../../specs/zhiyu-round09/05-fidelity.md)、[S6-C06 示例与正式数据边界](../../../specs/zhiyu-round09/06-architecture-and-delivery.md)、[先界面再接功能](../frontend-first.md)。参照状态：R13及缺失设置流程补充状态。

## Acceptance criteria

- [ ] 通知、期限与保留、目录标签管理、备份/恢复密钥及错误、后台运行/维护/退出、Agent接入均有完整界面状态。
- [ ] 主题/设置在示例会话内读写；系统通知、退出、备份、hooks信任等效果仅演示，不修改真实系统配置。
- [ ] 设置各入口注册到U01的预览导航中；本票检查设置自身路径。其他UI页面全部完成后再做整套跨页对照，作为T02开始接真实功能前的共同条件，不把其他模块的后台列成本票前置。
- [ ] 使用正式Flutter组件与控制器；从界面入口走到示例结果，正常、空数据、等待和失败状态可重现。不是另一套HTML或截图展示。
- [ ] 1440×900、1280×800、明暗主题、200%文字、键盘和本票相关动效完成S5对照；提交实际Flutter截图/录屏，注明示例数据。
- [ ] 预览不连接真实资料库、秘密、hooks或系统执行能力；数据集中维护并可重置，未来通过同一接口换真实服务，不靠逐页isMock分支。
- [ ] 更新数据/操作/错误合同及前端定向检查；未接后台项目明确记录，不以示例成功关闭对应T功能票。

## Demo

启动独立“界面预览·示例数据”程序，从真实入口走完本票正常路径，再展示一种失败及恢复路径；切主题和调整窗口，核对菜单、滚动和动画。

## Blocked by

- U01：软件外壳、明暗外观与通用控件

## 执行边界

用户明确要求先整套前端，因此本票不被新后台接口、数据库或CLI实现阻塞。只先确定页面所需数据合同，现有技术栈和安全规则保留；无子Agent、无服务器同步。界面反馈仅属于独立预览，不进入正式发布的成功分支。
