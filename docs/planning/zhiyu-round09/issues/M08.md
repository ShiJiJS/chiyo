## 用户结果

新版信息库中已有托管凭据可打开，显示准确名称、公开用途、Owner私有备注、材料版本、启停/到期状态和关联资料；秘密始终掩码。随后接入安全录入/文件选择、新建与修改、更换材料、启停、保留版本恢复、回收与永久清理。复用原核心和SQLCipher，不另造凭据库。AI使用审批/执行的新版适配另作后续任务，不以普通字段授权代替凭据使用授权。

## 实施顺序

1. 先接Owner元数据和保留材料版本查询，真实凭据列表→详情→关联可达。通用资料值、搜索/公开目录、日志和UI回执不得包含材料原文。关联或申请记录查询失败不应使已读取的凭据元数据整体消失，但必须显式保留读取失败，不能伪造空记录。
2. Host持有安全字符串输入/原生文件选择及短期暂存身份；泛型表单只得到不透明候选与元数据。取消/迟到/换库清理准确对象，未知提交不丢失核对责任。
3. 真实写入、启停、更换和生命周期使用持久原操作回执与版本核对。结果未知先查原操作，不自动重放；同编号不同意图冲突。秘密/私有草稿不能进入明文回执。需要持久扩展时同时处理迁移与备份。
4. 材料恢复创建新版本/代次且停用，旧授权不复活；历史材料/回收按原30天规则处理。准确作用范围和两次明确确认后永久清理，Owner管理不创建AI请求。
5. 同源SQLCipher、实际控件、独立重开/完整加密备份往返及Mac打包；真实系统面板、Keychain、物理输入如实另记，不重复触发个人授权。
