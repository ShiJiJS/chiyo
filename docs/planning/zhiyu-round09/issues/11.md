## What to build

你现在已经存进去的资料不用重新录入。选择一个合适模板后，先预览旧字段分别放到哪里、哪些暂时无法对应，确认后再调整；无法对应的内容也保留，不直接丢掉。

## 开发顺序

本票复用已完成的[U04](U04.md)界面，不再另外画一套。

- [ ] 先复核前端：正常和异常状态齐全，若有遗漏先在同一套界面补好。
- [ ] 再接真实本地服务：替换示例数据来源，优先复用现有接口，缺失能力才新增。
- [ ] 最后验证：真实隔离资料库/CLI走通本票流程，检查保存、重启、权限及失败恢复，再对比样式和动画。

下方原有界面要求作为复核标准，不重复实现。UI票完成不等于本票完成。

## Acceptance criteria

- [ ] 采用前预览匹配、未映射、形态/含义冲突；不依据秘密或名字自动分类和建立关系。
- [ ] 同义映射保留字段身份，不同含义创建新身份；附件、目录/标签、凭据关联和修订完整，冲突不覆盖新编辑。
- [ ] 旧手建模板兼容保留，可显式转换为local包；不自动改历史资料，也不要求用户再手搭一次全部字段。
- [ ] 补充采用模板预览/失败/恢复画面，迁移合成schema22资料并备份往返；不在真实库试错。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。

## Demo

旧服务器资料→映射预览→保留未映射字段→采用→读取旧批准字段→修订恢复；转换一个旧模板。
