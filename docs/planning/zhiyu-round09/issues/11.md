# T11：为既有资料采用模板并兼容旧手建模板

状态：draft-awaiting-approval。确认拆分后才发布并添加 ready-for-agent。

## What to build

用户选中旧资料，预览字段映射和显示效果后应用合适模板，不丢失原字段和历史。

## Specification

[S1](../../../specs/zhiyu-round09/01-domain-and-data.md)；要求：S1-D05、S1-D06。所有票同时遵守 S5-V06、S6 的实现与证据约束。以冻结 Round09 为参照，原型演示数据/假成功不得进入正式代码。

## Acceptance criteria

- [ ] 采用前预览匹配、未映射、形态/含义冲突；不依据秘密或名字自动分类和建立关系。
- [ ] 同义映射保留字段身份，不同含义创建新身份；附件、目录/标签、凭据关联和修订完整，冲突不覆盖新编辑。
- [ ] 旧手建模板兼容保留，可显式转换为local包；不自动改历史资料，也不要求用户再手搭一次全部字段。
- [ ] 补充采用模板预览/失败/恢复画面，迁移合成schema22资料并备份往返；不在真实库试错。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。

## Demo

旧服务器资料→映射预览→保留未映射字段→采用→读取旧批准字段→修订恢复；转换一个旧模板。

## Blocked by

- T09：插件更新、停用和移除不损坏现有资料

## 执行边界

Windows优先，无子Agent、无服务器同步。仅按本票范围开发，不顺手重写全仓或关闭历史父票。实现文件位置由当前代码决定，先阅读规格的模块边界；不是机械照搬HTML结构。
