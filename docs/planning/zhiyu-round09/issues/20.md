## Acceptance criteria

- [ ] 制作固定源码的Windows候选包，标题/托盘/通知/快捷方式统一知予，旧CLI/Skill路径和数据库/DPAPI身份不改。
- [ ] 真实独立虚构库验证正常退出→替换→重启与失败回退，沿用单一最新分发目录和有界清理，不删除唯一可恢复来源。
- [ ] 汇总各票S5证据及当前包hash，完成所改范围最终检查；旧#18/#23/#30门槛继续在原票跟进，未过时标候选包而非全面验收发行版。
- [ ] 交付附升级说明、旧库迁移预览、已知限制和回退办法；不迁移真实库来凑测试，不新增Mac/服务器同步或子Agent工作。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。
