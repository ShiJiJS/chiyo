2. 持久结果：在真实SQLCipher事务中记录不含正文/密钥的操作意图与结果；同编号同意图不重复、不同意图冲突。文件发布与数据库提交跨边界失败时保留明确未知/清理待办，不能凭文件存在猜成功。结果核对只查原操作，重启后不自动重放导出或恢复。
3. 实际来源：实现WorkspaceBackupSource，组合到OwnerWorkspaceHost及picker。复用InformationBackups、Owner导出/恢复屏障和Mac同卷暂存，不另写加密或备份格式。状态只报告可证明的密钥另存、目标空库、归档和清理结果。页面不得直接访问数据库、原始路径或密钥文件。

5. 联合检查与交付：真实SQLCipher/文件的定向故障、旧格式和独立进程往返；新版控件与实际Owner来源联合检查；最终Mac包/原生文件面板证据另外记录。保留已有候选，集中构建和系统配合，完成后清理多余App/dSYM。

- 独立恢复密钥与本机数据库密钥分开；仅主人显式显示/另存，不写日志、回执或公开配置。密钥保存成功前不可导出；保存已有文件必须拒绝，不覆盖。

- 实际schema/备份版本在实现时核定，新增本机日志不能进入可移植备份；旧库迁移及旧备份恢复必须保留原数据，不借实现本票重置个人库。
