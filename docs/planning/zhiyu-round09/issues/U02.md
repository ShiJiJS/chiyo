# U02：三栏信息库与服务器、应用资料界面

状态：draft-awaiting-approval。界面阶段票；完成表示可预览，不表示真实功能已完成。

## What to build

用示例服务器和应用完成三栏浏览、简单查找、分组排序、详情编辑和资料关联，保留中间列表。

## Specification

[S5 视觉与动画](../../../specs/zhiyu-round09/05-fidelity.md)、[S6-C06 示例与正式数据边界](../../../specs/zhiyu-round09/06-architecture-and-delivery.md)、[先界面再接功能](../frontend-first.md)。参照状态：R01、R02、R03、R04。

## Acceptance criteria

- [ ] 普通信息、文件和凭据列表使用同一种摘要结构；目录、类型、标签、关键词组合与清除/返回规则完整。
- [ ] 服务器/应用详情、表单、关联选择和返回位置可操作；保存/失败由示例数据来源驱动，列表与详情同步。
- [ ] 补齐目录/标签管理、空结果、长名称、失效目标及旧资料通用视图；支持大数据量fixture，不引入复杂筛选。
- [ ] 使用正式Flutter组件与控制器；从界面入口走到示例结果，正常、空数据、等待和失败状态可重现。不是另一套HTML或截图展示。
- [ ] 1440×900、1280×800、明暗主题、200%文字、键盘和本票相关动效完成S5对照；提交实际Flutter截图/录屏，注明示例数据。
- [ ] 预览不连接真实资料库、秘密、hooks或系统执行能力；数据集中维护并可重置，未来通过同一接口换真实服务，不靠逐页isMock分支。
- [ ] 更新数据/操作/错误合同及前端定向检查；未接后台项目明确记录，不以示例成功关闭对应T功能票。

## 执行边界

用户明确要求先整套前端，因此本票不被新后台接口、数据库或CLI实现阻塞。只先确定页面所需数据合同，现有技术栈和安全规则保留；无子Agent、无服务器同步。界面反馈仅属于独立预览，不进入正式发布的成功分支。
