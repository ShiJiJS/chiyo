## Acceptance criteria

- [x] 普通信息、文件和凭据列表使用同一种摘要结构；目录、类型、标签、关键词组合与清除/返回规则完整。查找保持关键词+类型+标签；分组/排序为小按钮，不加多条件表单，不设私人标签。
- [x] 服务器/应用详情、表单、关联选择和返回位置可操作；保存/失败由示例数据来源驱动，列表与详情同步。
- [x] 补齐侧栏目录/标签导航与就地操作、空结果、长名称、失效目标及旧资料通用视图；支持大数据量fixture，不引入复杂筛选。独立目录/标签管理页由U07负责，复用同一示例状态与控件。
- [x] 使用正式Flutter组件与控制器；从界面入口走到示例结果，正常、空数据、等待和失败状态可重现。不是另一套HTML或截图展示。
- [ ] 1440×900、1280×800、明暗主题、200%文字、键盘和本票相关动效完成S5对照；提交实际Mac Flutter截图/录屏，注明示例数据、Mac字体和输入检查范围。
- [x] 预览不连接真实资料库、秘密、hooks或系统执行能力；数据集中维护并可重置，未来通过同一接口换真实服务，不靠逐页isMock分支。
- [ ] 记录页面需要的数据、操作和失败结果，并完成相关前端检查；未接后台内容汇总给F01，不以示例成功宣称真实功能完成。
