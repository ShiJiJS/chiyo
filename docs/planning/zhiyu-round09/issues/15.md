## What to build

页面明确显示：用哪个密钥、交给哪个程序、以什么方式使用。例如SSH使用临时密钥文件，或把token交给指定程序；浏览器填充则展示目标应用。还要说明有效期内可以重复使用，不会每条命令都重新审批。

## 开发顺序

本票复用已完成的[U03](U03.md)、[U05](U05.md)界面，不再另外画一套。

- [ ] 先复核前端：正常和异常状态齐全，若有遗漏先在同一套界面补好。
- [ ] 再接真实本地服务：替换示例数据来源，优先复用现有接口，缺失能力才新增。
- [ ] 最后验证：真实隔离资料库/CLI走通本票流程，检查保存、重启、权限及失败恢复，再对比样式和动画。

下方原有界面要求作为复核标准，不重复实现。UI票完成不等于本票完成。

## Acceptance criteria

- [ ] R10涵盖字符串env、文件argv、路径env和焦点填充；三个关键问题显式呈现，tips位置及焦点符合S5。
- [ ] 原始命令是首次用途说明，不误标成整段授权的命令白名单；同grant多次操作、不同operationId维持现有语义。
- [ ] 未知占位符/接收方不匹配、凭据换版、到期/撤销及未知执行状态明确处理；不记录或返回秘密正文。
- [ ] 真实隔离CLI/worker验证一条env和一条文件执行，焦点填充复用现有合成目标回归；没有真实目标时记录未验范围。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。
