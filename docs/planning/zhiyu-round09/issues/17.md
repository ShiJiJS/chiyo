# T17：授权历史呈现一次授权下的多次操作

状态：draft-awaiting-approval。确认拆分后才发布并添加 ready-for-agent。

## What to build

找到一个授权及其多次使用、文件交付和撤销结果，并从记录回到当前资料或历史快照。

## Specification

[S4](../../../specs/zhiyu-round09/04-flows.md)、[S1](../../../specs/zhiyu-round09/01-domain-and-data.md)；要求：S4-A05、S1-D03、S1-D04。所有票同时遵守 S5-V06、S6 的实现与证据约束。以冻结 Round09 为参照，原型演示数据/假成功不得进入正式代码。

## Acceptance criteria

- [ ] R12区分grant与operation，不把复用次数呈现为重复审批；筛选、分页、时间和状态真实。
- [ ] 展示当时固定字段/版本/接收方和结果原因；对象删除或改名不错误跳到同名对象。
- [ ] 新增模板/条目/关联有可读历史说明，旧记录仍可读；敏感值、临时注入明文不进入审计正文。
- [ ] 多次执行、失败、未知、撤销与到期以及普通文件交付都有合成数据；两尺寸长记录和键盘通过。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。

## Demo

同grant两次使用一次失败→历史筛选→看授权范围与操作→撤销→删除源对象后读历史。

Windows优先，无子Agent、无服务器同步。仅按本票范围开发，不顺手重写全仓或关闭历史父票。实现文件位置由当前代码决定，先阅读规格的模块边界；不是机械照搬HTML结构。
