# T09：插件更新、停用和移除不损坏现有资料

状态：draft-awaiting-approval。确认拆分后才发布并添加 ready-for-agent。

## What to build

插件更新后，新建资料可以使用新版，旧资料不会被偷偷改成另一种格式。停用或移除插件时，已有资料仍能查看和编辑，软件会提前说明影响，不会连资料一起删除。

## Specification

[S2](../../../specs/zhiyu-round09/02-plugin-contract.md)、[S1](../../../specs/zhiyu-round09/01-domain-and-data.md)；要求：S2-P03、S1-D02、S1-D06。所有票同时遵守 S5-V06、S6 的实现与证据约束。以冻结 Round09 为参照，原型演示数据/假成功不得进入正式代码。

## Acceptance criteria

- [ ] 同版本不同摘要拒绝，高版本先展示差异；已存在实例快照和字段身份不变，缺失模板回退通用视图。
- [ ] 停用禁止新建；移除不删资料、附件、凭据、历史或主机信任，影响数量准确且事务失败可重试。
- [ ] 测试旧/新模板共存、缺插件恢复及重装；包降级不触发实例降级，不偷做自动数据迁移。
- [ ] 插件列表/详情/确认弹窗明暗状态和焦点完整，变更保留用户当前资料选择。
- [ ] 提交固定源码、受影响测试、同场景视觉/动效证据及未通过项；实际Windows、离屏和原型证据分开标注。没有业务或布局差异被“编译通过”替代。
- [ ] 无关行为不回退；涉及持久化的新增内容在本票即支持重启和备份/恢复，权限用核心公开接口验证。仅使用隔离虚构数据。

## Demo

v1建资料→更新v2→建新资料→对比旧快照→停用/移除→读旧资料→重装。
