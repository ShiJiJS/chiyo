# 知予 Mac M03：接通真实审批、限定读取与授权失效

## 用户结果与依赖

依赖 M01（#70）、M02（#71）。主人批准或拒绝 AI 的访问请求，AI 仅能读获批字段；主人可撤销，期限到达或会话结束后旧能力不可再用。新界面和 AI 查询端显示同一处理结果。本票首批只接普通信息读取；普通附件领取、凭据执行与整理申请后续单列，不以普通读取授权替代。

## 实施顺序与交接

1. 核对现有核心审批事务，补齐新界面批准、拒绝、撤销所需的版本检查及无正文持久操作回执；新增持久数据同时处理迁移与备份兼容。
2. 接通审批页实际命令：展示并确认字段范围和期限，准确呈现冲突、失败与结果未知；未接通前保持不可用，不能显示示例成功。
3. 接通授权历史、访问记录和原操作查询；页面离开、响应丢失及重启后核对原结果，不重复批准。历史恢复不能恢复读取能力。
4. 与 #71 的独立 AI 客户端联调：待批/拒绝不可读，部分批准只读选中字段，撤销/到期/会话结束后不可再读；同时核对 App 与 AI 查询结果。
5. 将通过的范围、准确源码和剩余问题交给 #73，在同一固定候选中完成真实宿主验收。本票当前仍待实施，不因已有核心能力而标记新界面完成。

## 实现范围

- 复用现有 OwnerAccess、核心访问请求/授权/逐请求鉴权及审计，适配 workspace 审批与授权历史合同，不让新界面直接写授权表或生成临时访问凭证。
- 批准时明确展示实际信息项/字段及固定截止时间；按 ADR0001 固定成员集合，批准后新增字段不进入旧授权。允许纠正后的同身份最新值，替换/删除/恢复遵循核心失效规则。
- 原子核对请求/资料版本、会话有效性和期限。申请过期、已处理、目标删除或并发修改时返回真实冲突，不静默扩大范围或延长期限。拒绝/撤销重复提交不产生相反终态。
- 保存可跨导航/重启核对的无正文操作回执；提交结果未知只查原操作，不自动批准/重放。授权历史和每次访问结果同源；不写被访问正文、秘密或访问凭证。
- 每次读取执行服务端范围、身份、会话、期限及撤销检查。主/子共享只基于已有私密证明委托；不从公开聊天 ID 推导。SessionEnd 仅撤销，恢复聊天和 App 重开都不复活已失效能力；固定期限作为结束事件缺失时的兜底。
- 拒绝、撤销、过期、待处理与已处理状态在列表、详情、历史、AI 端一致；未知或部分失败不伪装成功。现有备份排除活跃能力/待批请求，恢复历史不恢复有效授权。

## 验收标准

- [ ] 独立 AI 客户端在待批/拒绝时读不到正文；主人从新界面选择部分字段批准后，只能读取该集合。
- [ ] 未选字段/另一个信息项/另一聊天/伪造公开会话 ID 均被拒绝；批准后新增字段、恢复身份不扩大旧范围。
- [ ] 撤销、固定到期、主会话结束分别立即阻止后续读取；聊天恢复、App 重启及备份恢复不复活失效能力。
- [ ] 并发处理、资料变化、请求到期、响应丢失及重复提交有真实事务/持久回执验证，无重复批准或静默换范围。
- [ ] 收件箱、授权历史和访问记录能关联同一申请/授权/访问，删除资料后仍保留必要无正文审计，清理遵守既有保留规则。
- [ ] 核心/适配器定向回归与 Mac 构建通过；真实宿主联合证据和交付缺口回填 M04（#73），不借合成状态推进验收。

## 边界

保留主人审批和管理职责，不添加“申请使用”、快速批准演示或伪造执行记录。#66/#67 的 UI 未验项继续留原票；#48 的完整 UI 验收范围不重复关闭。本票补新界面的真实接缝，Windows 适配后置，验证用隔离合成资料。
