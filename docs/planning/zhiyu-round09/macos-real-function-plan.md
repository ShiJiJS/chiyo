## 执行与交付约束

独立 `codex/zhiyu-macos` 分支；不改 main/Windows，不运行 Windows CI。首次实施前核对当前远端和工作区。验证只用隔离合成资料，不自动扩展个人 hooks/信任/资料授权；系统密码和实际输入集中到同一候选，需要本人时列清用途。保留正式技术身份，不用预览 bundle ID 接管个人库；固定位置保留一个当前 App，清理本轮多余 App/dSYM，未知 `.local/` 不动。

本轮只创建/调整任务和计划文档；未改产品代码、未重新测试/打包、未把任何功能验收项标为完成。
