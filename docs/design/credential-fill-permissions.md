# 本机填写权限与授权引导

用户需要知道当前版本是否可以后台填写，以及怎样完成系统授权。沿用现有设置页、UiPalette、DesktopButton、SettingsCard；不改变凭据批准、目标固定或写入保护。

- 原生后台填写以实际 XPC helper 的辅助功能权限为准；焦点兼容方式另外检查辅助功能和事件发送权限。两种逻辑门槛由同一实际 helper 查询。
- Chrome/Ego 表单接口不受这项系统权限门槛控制，连接及具体表单在使用时检查。
- “前往系统设置”才请求权限并打开固定系统页面。正常进入、回到 App 和“重新检查”只读取真实状态；按钮点击不等于授权成功。忙碌时返回产生的一次复核不能丢失。
- 引导显示系统列表中的程序名、当前安装位置、定位当前 App 的入口，以及开关已开但升级后旧授权记录不匹配的处理方法。用户亲自在系统窗口决定；不自动切换开关、重置权限或改变签名信任。
- 辅助程序失联/崩溃与系统未授权分开显示，保留重新检查入口。失败不假装成功、不影响其他填写方式的显示。
- 原焦点兼容方式保留在折叠区，不作为后台填写失败时的自动后备。

权限随版本变化的说明依据 Apple [代码签名要求](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)：本机 ad hoc 签名的身份绑定具体构建，不能承诺跨版本自动保留系统授权。辅助程序仍使用精确包身份与签名校验，不为减少提示而放宽。
