# 信息库与公共控件改版

意图：改进分类操作流程并整理公共控件；阶段：实施。北极星：位置清楚、筛选可见、一次操作一次提交。

## 授权与设计依据

2026-10-21 用户要求依次完成 #52–#60，允许无人值守和 Computer Use。由本任务自主完成可逆设计决策并留存原型，不等待逐页回复；不使用子 Agent。这替代初始票据中需先等待原型确认的执行门槛，不冒充用户已经逐图确认。

Round05 的三栏、四主题、字体角色和其他模块结构继续使用。新版原型在 `prototypes/round-06-library/`，只替换信息库导航、分类流程和本组公共交互状态；旧 HTML 与参考图保留。

## 信息库规则

- 左栏240逻辑像素：标题与信息／凭据切换、全部信息、未分类、目录树；树占剩余高度，回收站置底。中栏340保留，搜索、标签、排序与结果数集中显示，详情使用剩余宽度。
- 目录显示含下级的当前信息数量；中栏数量是实际查询结果。无重复标题总数。默认包含下级，可显式关闭；未分类仅匹配无目录信息。
- 当前目录、关键词、多标签取交集，标签为 AND。切目录保留可见关键词及标签；清除筛选保留目录；全部信息重置三者；跨目录搜索明确改到全部范围。查询变化回到第一页并重核详情。信息／凭据各自保存状态。
- 单级目录名称分开于上级目录；trim 后非空、不超200字符、禁止正反斜杠。同一父目录内名称忽略大小写后唯一，不同父级允许同名；标签名称全局忽略大小写唯一。旧名称只读兼容，不自动拆分或迁移；原名不变的移动允许保留旧斜杠名称。
- 目录创建／重命名／移动单表面完成；移动禁选自身及下级。首版仅删除无当前信息和子目录的空目录，确认前后都验证版本和空状态。
- 标签独立搜索管理，内联创建／重命名，删除原子清理当前信息关联；回收和修订原始快照保留历史分类ID，不重写。回收／修订恢复遇缺失目录落未分类、缺失标签跳过并提示；完整恢复旧备份仍恢复该备份整体状态。
- 编辑信息只选已有分类；不在草稿表单中隐式创建正式目录／标签。归属调整带预期信息版本，一次原子保存；取消和失败不产生部分写入。

## 公共控件

- 状态：默认、轻悬停、按下、选中、选中悬停、键盘焦点、禁用独立定义。160ms过渡。文字按钮保留至少6/4内距；固定图标按钮单独居中、单行高、无文字缩放，使用完整外框作为点击与反馈范围，避免把文字按钮内距挤入26/30尺寸后裁切符号。搜索清除保留18×20槽位以免输入时行高跳动；导航／页签保留下划线并用独立圆角反馈区域，列表选中和悬停共用边界。
- 面向指针与键盘的垂直轨道保留16逻辑像素安全槽，横向同理。轨道不穿过按钮或固定操作区；每个独立滚动表面只放一根滚动条。
- 下拉统一锚定：默认下方6间隔，空间不足整体上翻。长列表有界滚动；Escape／点击外部关闭并恢复触发器焦点，不改变值；菜单打开时清除短提示。
- Tooltip使用纸色、文字色、细边线与轻阴影、8/10内距、6圆角、400ms延迟，与目标保持8间隔。长帮助使用可关闭表面。保留图标按钮辅助名称。
- 设置行统一22上下留白、标题说明间隔7；分组外容器负责首尾边距，不依赖维护项插入前的旧 first 标记。
