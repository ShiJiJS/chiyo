# 知予 · Round 09 — 完整工作台

本轮延续 A 的三栏信息库，保留五个一级页面：信息库、访问审批、录入提案、授权历史、设置。设计目标是先看资料，再做操作；模板插件继续放在设置里。

## 查找与排列

- 左侧目录决定查找范围；标签保留为快捷入口。
- 列表顶部直接搜索名称、用途与标签；多个关键词按同时匹配处理。
- 类型与标签各提供一个小菜单。各自单选，可以单独使用，也可以一起限定；选择立即生效。
- 删除条件表单、字段条件、全部/任一逻辑、保存视图入口。新增模板不会增加筛选条件。
- 分组和排序是两个独立的小按钮。分组只有不分组、按类型、按目录；排序只有最近更新与按名称。分组不改变资料的归放位置。
- 点击搜索结果保留当前范围与关键词；空结果可以一键清除。跨范围的关联跳转才重设范围。

例如找日本的生产服务器：全部资料 → 类型选服务器 → 标签选生产环境 → 输入日本。Agent 的发现方式同样以关键词、类型、标签为方向，不设计复杂查询表达式；实际 Agent 接口和 Skill 尚未修改。

## 明亮与黑暗

外观只保留两个选择，不提供主题色或跟随系统选项。旧版颜色选择在显示时归入明亮主题，不重置原型资料。

- 明亮：浅灰画布、白色内容面板、深灰正文、克制的紫色强调。
- 黑暗：深灰画布、分层灰色面板、柔和浅色正文和较亮的紫色强调。不是简单把整个页面反色。
- 服务器、应用、文件和凭据保留低饱和的类型识别色，类型同时有文字说明。
- 同一套语义色应用到列表、详情、审批、历史、设置、表单、菜单、提示与交互状态。简历等文档预览保留文档本身的纸张颜色。
- 主题选择保存到当前浏览器的原型存储，刷新后读回。

## 原有流程与边界

31 项初始虚构资料。新增/修改提案会更新本浏览器的虚构目录；旧版本保留。分类整理先授权固定范围，Agent 自动应用并记录结果，不加第二次审批。

审批包含普通字段与文件、环境变量、SSH 临时文件、本机焦点填充和分类整理。当前会话及授权期限内复用；整理授权最长 30 分钟。

原型不连接正式软件、真实数据库、CLI 或 Agent。普通文件只保存文件名等元数据，凭据输入不保存原文；不要录入真实秘密。备份、恢复、通知、退出、SSH 导入及材料维护只有流程预览。目录重设父级、复杂批量提案和文件版本长流程仍待深化，详见 guide.html。

## 验证

主 Agent 自检，遵循用户要求没有使用子 Agent，未独立评审。检查使用独立临时浏览器，结束即关闭；8807 预览服务保留给用户。

evidence/check.cjs 覆盖关键词/类型/标签、结果范围保留、分组/排序、空结果、资料修改/版本/移动/回收、提案、审批与撤销、设置持久化、插件安装、录入、两种桌面尺寸和保存失败保留草稿。主题覆盖两种模式切换与刷新读回。

视觉检查：1440 × 900 与 1280 × 800，明暗信息库、外观设置、审批及其他主页面。浅色次级文字已加深，消除改动界面的对比度提示。截图工具未报告横向溢出、控制台错误或图片加载失败。离线版本同步更新。

## 知予名称与插件专属设置

原型统一使用「知予」：窗口标题、顶栏、通知预览、内置插件作者和说明文字同步更新；不改正式客户端、安装目录、Skill 或接口标识。保留已有浏览器原型资料与主题偏好。

设置侧栏改为「插件」，取消独立的 SSH 主机信任分类。服务器插件增加可选「插件设置」页签，挂接知予内置的主机信任面板；没有设置能力的插件不显示空页签。服务器详情的连接概览提供单台「主机身份」入口，可跳到插件的全部记录管理。旧 section=ssh 地址跳到新位置。

主机指纹在原型中按地址和端口独立确认与撤销；更改目标不能继承原目标的信任。未取得指纹时不能确认。插件停用后仍能查看和撤销已有信任，重新确认需要启用插件；安装/启用不自动信任。信任记录由宿主保留，和凭据使用授权分别管理。虚构指纹只用于界面演示。

本轮展示宿主内置面板的入口和流程，没有扩大 JSON 包为可执行插件；可选设置声明协议详见 plugin-spec.md。known_hosts 导入仍为流程预览，没有解析或写入真实文件。
