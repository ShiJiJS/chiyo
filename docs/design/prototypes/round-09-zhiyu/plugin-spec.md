# 知予插件包草案：第 09 轮原型

这是用于验证界面与交互的草案，不是已发布的软件插件接口，也不代表任何实际信息访问授权。

## 制作流程

1. 根据用途先复用已有模板；确实没有合适模板时生成 JSON 插件包。
2. 提供虚构样例，说明字段、布局、可选关联及录入规则。
3. 在原型中加载，修正格式检查发现的问题。
4. 安装不写入真实资料。实际信息仍通过软件现有录入提案与授权流程处理。

## 包字段

- id：稳定标识，例如 local.domain；本地包不能覆盖 builtin. 内置标识。
- name / description / author：名称、用途、作者。作者为声明，不代表已验证来源。
- version：三段版本号，例如 1.0.0。
- hostApi：本轮为 1。
- templates：1–10 个模板。详情页优先展示第一个；录入选择器提供全部模板。

## 模板字段

- id：稳定标识，不与其它包冲突。
- name：模板名称。
- icon：server、layers、user、globe、briefcase、book、file、folder 或 key。
- fields：最多 40 个字段，包含 key、label、type、required。
- type：text、url、number、date、multiline 或 entries。
- entries：本轮每段经历含 title、period、detail。
- sections：按顺序描述展示。fields 使用 keys；text、timeline 使用字段 key；relations 使用关联 key；均需 title。
- relations：key、label、targetTemplates。关联可选；空目标数组表示可从全部资料选择。
- instructions：Agent 录入说明，写清来源、去重、字段含义和关联证据要求。
- example：可选虚构样例，含 name、summary、values；不放实际秘密内容。

## 数据约定

- 模板不建立目录，不绑定目录。
- 信息项保存自己的模板版本和定义快照；升级不修改已有快照。
- 实际内容、普通附件、凭据由软件保存，插件包不包含它们。
- 停用或移除插件不删除信息项；缺失模板时使用通用视图。
- 本轮不支持任意脚本、网络请求和命令执行。
- 字段身份不能用于表达新含义来扩大旧授权。
- 关系必须有明确依据，不能从名字或敏感字符串偶然匹配推断。

## 本轮未覆盖

生产 JSON Schema、签名与来源验证、多模板管理详情、外部包升级回滚、历史插件兼容、任意渲染器、真实 CLI 管理接口、Skill 分发、资料迁移。

样例见 domain-plugin.json。验证时只使用虚构数据。

## 可选插件设置（第 09 轮设计补充）

插件可以提供资料模板，也可以声明可选的设置入口。没有设置项的插件不出现空白设置页。包级默认配置属于插件设置；某台服务器的主机、端口与身份状态属于资料详情，两者可以相互跳转。主题、通知、备份与授权策略仍为知予全局设置。

设置内容有两个方向：由宿主生成的普通配置表单，以及挂接宿主已支持的功能面板。本轮原型只实现后者的内置示例：builtin.server 挂接 ssh-trust。此映射由宿主注册，不接受外部 JSON 包自行提交可执行页面、脚本、命令或组件代码。通用配置声明与校验协议尚待细化，不能据此声称外部包已经支持任意设置。

主机信任记录仍由宿主按地址、端口和指纹管理，不存进模板包。插件停用不会删除信任记录或资料；身份确认不等于获得凭据使用权限。服务器详情使用同一份信任状态，不为每个入口另存一份。
