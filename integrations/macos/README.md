# 知予（chiyo）· Mac 联网开发候选

资料统一保存在独立服务器。App 和 AI 的 CLI 都连接服务器；断网时不可使用，不另开本机资料库。服务器可以解密获准使用的内容，数据库加密保存。
这份说明随完整 Mac 包放在根目录，相对链接均以该目录为准。

## 连接

保留完整 `chiyo` 目录，打开 [app/chiyo.app](app/chiyo.app)。运行 App 和随包命令不需要 Xcode、Flutter、Dart 或 Python。
填写服务器 HTTPS 地址和用户接入 Token。使用私人 CA 时，在连接页填写该 CA 的 PEM 证书；正常验证服务器身份和主机名，不关闭证书校验。服务端配置及维护按统一候选中的服务端说明进行。

App 的连接 Token 单独保存在当前用户的私有连接配置中，不交给 AI；外观、通知和窗口偏好也只保存在本设备。请求期限、历史保留策略、模板、资料及审批记录使用服务器的值。本版不需要读取旧单机资料密钥；不会自动迁入旧库。

需要独立连接配置时，从终端运行 `app/chiyo.app/Contents/MacOS/info_desktop --connection-profile <名称>`。名称只接受英文字母、数字、下划线及连字符，最多64字；配置保存在默认私有连接目录的 `profiles/<名称>` 下，资料仍在服务器。未指定时使用默认连接。开发候选的合成检查使用独立名称，不读取日常配置。

## 使用

- 在信息库新建、编辑资料，管理目录、标签、关联和顺序。用户手动编辑直接保存。
- AI 按服务器当前模板整理新增或修改，提交录入提案；你在提案内看类型、内容、修改对比和位置。缺少的人设密码可直接填写、显示或隐藏；整份齐全后一次保存，不分条入库。
- AI 发起资料或凭据使用申请，你在访问审批核对用途、范围、接收程序和期限。保存资料不等于批准 AI 使用；App 没有代 AI 发申请的入口。
- 文件保留版本，获批后下载到 AI 所在设备；SSH、Token 注入等也在该设备运行，不在服务器代执行。本机焦点密码填充保持关闭。
- 授权历史记录批准范围及实际访问结果；回收站支持回收和恢复。恢复历史不会恢复旧许可。
- 运行页面区分服务器的设备报告和此 App 的临时文件。用户另存的文件不受临时副本回收；文件已被外部程序读取的内容无法追回。

默认关闭窗口可按本机设置保留 App 后台。菜单栏、应用菜单及 ⌘Q 可正常退出；退出只关闭 App，不停止服务器、CLI 执行程序或仍有效的聊天许可。服务器普通重启不延长许可，也不单独使其失效；聊天结束、撤销或到期后停止后续访问。

同包 [cli/info](cli/info) 提供 `app status`、`app quit`，只控制同包实例；可用 `--pid` 明确实例，退出超时不强杀。需要停止某次 AI 访问，在 App 撤销或由根聊天结束通知处理。

断线或回复丢失时先核对原操作，不换编号重复保存、审批或执行。App 重连后读取服务器结果；不能把无法查询说成没有保存。

## AI 接入

按 [CODEX-INTEGRATION.md](CODEX-INTEGRATION.md) 生成配套运行材料。App 内还包含同版本 CLI、worker、Skill 模板和清单，独立复制 App 也能核对材料。
生成材料不等于个人 Codex 已安装 Skill 或信任 hooks；本轮不会改个人配置。模板和例子由 CLI 向服务器查询，不写死在 Skill 中。

## 备份与升级

在设置的备份与恢复页面创建并独立保存恢复密钥，再导出完整加密备份。恢复只允许空目标服务器，不覆盖或合并非空库；恢复后重新登记 Agent，旧聊天许可不会恢复。操作结果不确定时先核对原回执。

正式升级与真实资料迁移另行集中进行；此候选不自动替换日常 App。升级前保留可恢复备份、恢复密钥及旧版；服务器停机副本必须连同对应私有密钥完整保管，不能让旧程序强行打开已升级的库。
