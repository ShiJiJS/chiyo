# Application typeface

Noto Sans SC Regular and Medium are bundled so Chinese, Latin text and digits
use the same typeface on Windows and macOS. The application uses only the
actual supplied weights 400 and 500; it does not request synthesized bold.

Upstream: https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/SC

- Regular: https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf
- Medium: https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/SubsetOTF/SC/NotoSansSC-Medium.otf
- License: https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE

The fonts are unmodified upstream files, downloaded on 2026-10-16 under the
SIL Open Font License 1.1. `OFL.txt` is included in the application assets,
runtime license registry and Windows delivery notices. The delivery manifest
records SHA-256 for the actual distributed asset files.
