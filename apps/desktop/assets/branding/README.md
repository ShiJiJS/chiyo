# 知予图标

- `chiyo-original.png` 是名称与图标会话中选定的深蓝底八千代图标原图，保留生成时的完整像素。
- `chiyo-icon.png` 是清理圆角外杂点后的 1024 × 1024 透明背景图，与 Mac App 图标一致，供 README 和其他展示使用。
- macOS 所需各尺寸位于 `../../macos/Runner/Assets.xcassets/AppIcon.appiconset/`。App 顶栏复用其中的 128 像素版本。
- `app-icon.svg` 是早期图标，保留给尚未更新的 Windows 资源生成流程。

源图来自 2026-11-04 的「讨论名称和icon」会话。原图 SHA-256 可通过 Git 中的文件自行核对；运行时不依赖会话目录或临时文件。
